# MORAL_TINT — 색으로 보는 자기 파괴

> **철학 한 줄: "가질수록 나를 잃는다. 회색으로 시작해, 인간을 택하면 하얘지고 돈을 택하면 검어진다. 30억을 쥐었을 때 화면이 무슨 색인지가 진짜 결말이다."**

DE의 "스킬이 말한다"와 무관한 우리 고유 시스템. 추상 메타포 없음 — 플레이어는 그냥 **자기 화면이 식거나 밝아지는 걸** 본다.

---

## 1. 축 (단 하나의 값)

`GameState.moral_tint : float`, 범위 **−100 ~ +100**, **시작값 0(회색)**.

| 값 | 색 | 의미 |
|---|---|---|
| +100 | 새하양 | 인간성을 지킴 |
| 0 | 회색 | 33세, 백지. 아직 아무도 아님 |
| −100 | 새까망 | 돈만 남고 내가 없음 |

플레이어에겐 숫자를 **절대 안 보여준다.** 오직 테마색으로만 느낀다.

---

## 2. 무엇이 미는가 (축적식 — 한 선택이 누적된다)

### 하양 쪽 (+)
| 행동 | Δtint |
|---|---|
| 손해 보는 정직한 선택 | +4 ~ +8 |
| 아버지 찾아감 / 화해 (rushed_to_father, father_reconciled, visited_father) | +10 |
| 사람한테 먼저 연락 / 관계 회복 (다은·현수·지연 재연결) | +5 |
| 도박·착취·사기 제안 거절 | +6 |
| 상철을 끊거나 신고 (sangchul_reported, sangchul_quietly_distanced) | +8 |

### 검정 쪽 (−)
| 행동 | Δtint |
|---|---|
| 사람을 도구로 씀 (used_sangchul_knowingly, sangchul_leveraged) | −8 |
| 약속/전화 무시, 관계 드리프트 방치 | −4 |
| 거짓·배신 (jaehyuk 사기 가담, 거짓말 플래그) | −7 |
| 돈을 사람보다 택함 (chose_money_over_father, sent_money_instead) | −6 |
| **착취로 번 돈** — 자산이 검정 플래그 상태에서 크게 오를 때 가산 | −2 (이벤트당) |

### 영구 얼룩 (scars) — 되돌릴 수 없음
| 플래그 | 효과 |
|---|---|
| `crossed_line` (상철 끝까지 이용·재혁의 방식) | tint 상한 **−20으로 고정**. 다시 양수 못 됨 |
| `chose_money_over_father` (죽음 외면) | tint 상한 **0으로 고정**. 하양 못 됨 |

→ 흉터가 있으면 아무리 착하게 굴어도 *완전히는* 못 돌아온다. 이게 드리프트를 진짜로 만든다.

---

## 3. 되돌림 규칙

- 검정으로 갔어도 인간적 선택으로 **천천히 하양 쪽으로 회복 가능.** 단 회복은 *불완전·느림* (Δ 작게).
- 죽은 사람은 못 돌아옴(상속 비네트는 영구). 흉터는 위 상한으로 영구 제약.
- "되찾을 순 있지만 완전히는 못 한다."

---

## 4. 5단계 밴드 (Codex가 칠할 구간)

| 밴드 | tint | 화면 |
|---|---|---|
| +2 하양 | +60 ~ +100 | 밝고 따뜻. 온기 액센트 살아있음 |
| +1 옅은 하양 | +20 ~ +59 | 약간 맑음 |
| 0 회색 | −19 ~ +19 | 시작 상태. 중립 |
| −1 옅은 검정 | −59 ~ −20 | 채도 빠짐, 메뉴 차가워짐, **돈 숫자만 또렷** |
| −2 검정 | −100 ~ −60 | 어둡고 *틀어짐*(자간·1px 어긋남·멈칫 호버). 돈만 거의 형광 |

**핵심 규칙: 검어질수록 돈 HUD 숫자만 *반대로* 더 밝게 빛난다.** 화면이 유일하게 남은 가치 중심으로 재편되는 시각적 주제문.

---

## 5. 네 칸 엔딩 매트릭스 (tint × 30억) — 기존 엔딩과 매핑

| | **30억 도달** | **30억 못 함** |
|---|---|---|
| **하양** | 깨끗한 강남 — *진엔딩, 극악 난이도* (정공법·무착취). `gangnam_dream` base / `quietly_distanced` 변주. 화면 하양 | `with_daeun` · `late_call`(truth_known) · `sangchul_reckoning`. 강남은 졌지만 나를 지킴. 화면 따뜻 |
| **검정** | `jaehyuk_way`(used_fully 변주). 등기 + 텅 빈 화면. 새까망 | `late_call`(used_fully 변주) — 다 팔고도 빈손. 가장 쓴 결말. 새까망 |
| **회색** | (드문) 회색으로 30억 — 바랜 승리 | `ordinary_life`. 괴물도 성인도 아닌, 바래버린 결말 |

→ **색 시스템은 이미 작성된 엔딩 변주 위에 씌우는 시각 레이어다.** 가지치기는 이미 있음(jaehyuk_way / late_call 2변주 / gangnam_dream 3변주). 이건 그걸 *눈에 보이게* 만드는 것.

**확정 규칙: 하양으로 30억 도달은 *가능하되 극악*.** 정공법으로 5년 안에 아무도 안 밟고 30억 = 거의 불가능에 가까운 진엔딩. "강남 가려면 결국 더러워져야 한다"는 잔인한 질문을 색으로 세운다.

---

## 6. 임계 비네트 (밴드 넘을 때 터지는 짧은 서사 — Claude 저작)

밴드 경계를 *검정 쪽으로* 넘을 때마다 짧은 1~2문단 통지. 숫자가 아니라 장면으로.

- **0→−1 (회색→옅은 검정)**: 밥을 먹는데 맛이 안 났다. 그냥 연료 같았다.
- **−1→−2 (옅은→검정)**: 거울을 봤다. 5년 전 라면 먹던 얼굴을 떠올리려 했는데 — 안 떠올랐다.
- **하양 쪽으로 회복 시 (−→+)**: 오랜만에 통화 끝에 웃었다. 웃는 게 어색했다는 걸, 웃고 나서 알았다.

각 비네트 KR+EN. (구현 시 description 비네트 풀에 추가, 트리거는 밴드 전이.)

## 7. 구현 분담

### Claude (엔진 + 서사 + 밸런스)
- `GameState.moral_tint : float` 선언 + serialize/load + start_new_game()=0
- `GameState.shift_moral_tint(delta)` — clamp + 흉터 상한 적용
- `GameState.moral_stage() -> int` (−2~+2) / `moral_tint_norm() -> float` (−1.0~+1.0, 부드러운 보간용)
- `apply_effects`에 **`tint` 효과 키** 추가 → shift_moral_tint 호출
- 흉터 코드 훅: crossed_line / chose_money_over_father set 지점에서 상한 고정
- 착취-자산 가산: 자산 마일스톤 도달 시 검정 플래그 보유면 −2
- 밴드 전이 비네트 트리거 + 비네트 본문(KR+EN)
- `audit.py` 화이트리스트에 `tint` 키 등록
- 스파인 저작: 상철 아크 / 아버지 아크 / 핵심 돈·착취 선택지에 tint 부여

### Codex (시각)
- `GameState.moral_tint_norm()` 구독 → 테마색 회색↔하양↔검정 보간
- `moral_stage()`로 이산 효과(틀어짐·돈 글로우) 단계 적용
- 엔딩 화면 팔레트를 최종 tint로 결정
- (스펙 핸드오프: `docs/NEW_ASSET_REQUESTS.md`에 요약 추가)

## 설계 원칙 (불변)
- 플레이어에게 **숫자·게이지 절대 노출 금지.** 오직 색으로만.
- 비네트는 **사람의 감각**으로 (맛·잠·얼굴·웃음), 게임 용어 금지.
- 검어질수록 **돈만 밝아진다** — 이 반비례가 시각적 주제문.
- 흉터는 영구. "완전히는 못 돌아온다."
