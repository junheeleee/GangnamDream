## 깊이 3문

1. 이 수행층이 없으면 27개 행동 약속 중 20개가 지원 전송·확정 효과·휴식처럼
   선택 직후 정산되고, 플레이어는 달력에 넣은 일은 기억해도 그 일을 어떻게
   해냈는지는 말할 수 없다.
2. 약속마다 별도 미니게임을 만들면 소설 같은 한 흐름이 장르가 다른 짧은 게임의
   묶음으로 갈라지고, 24주를 240주로 늘릴 때 제작비와 학습비가 함께 폭증한다.
   공용인 것은 `서로 충돌하는 세 요구 중 둘`이라는 내부 문법뿐이어야 한다.
3. 월초에 별도 여력 토큰을 배치하면 사용자가 어렵다고 판정한 계획 UX에 같은
   결정을 한 층 더 얹는다. 달력은 무엇을 할지, 수행 장면은 그 일을 어떻게
   끝낼지만 맡아야 두 화면의 역할이 겹치지 않는다.

## 배치 A — 나흘 야간 재고조사의 2-of-3 수행 장면

- 3개월차 `m3_inventory_shift`만 `instant_effect`에서 공용 `activity_task`로
  바꾼다. 앞선 사흘은 한 문단으로 압축하고 나흘째 `전산 12 / 선반 11`의 불일치를
  한 장면에서 다룬다. 신규 주·제안·사건 카드·재화·스킬·도덕 점수는 0이다.
- 플레이어가 다루는 요구는 `선반 수량 재확인`, `입고·반품 기록 대조`, `차이를
  인계표에 기록` 세 가지다. 보통 교대 전에는 두 가지만 처리할 수 있고,
  방향키·D-pad와 확인만으로 순서를 고른다. 선택은 퀴즈 점수나 A~D 등급이 아니다.
- 두 요구를 처리한 뒤 남은 요구와 그대로 끝냈을 때의 결과를 보여 준다. 셋째까지
  처리하는 `무리해서 마저 한다`는 별도 확인을 거치고 최종
  `+360,000원 / 건강 -6 / 정신력 -3`을 사전에 정확히 표시한다. 먼저 고른
  조합에 따라 달라지는 상대 추가 비용은 고정값처럼 쓰지 않는다. 이 값은
  **[첫 실행 재조정]**이며 시뮬레이션과 사람 판정 전 확정값으로 부르지 않는다.
- 보통 세 결과의 수당은 모두 `+360,000원`이다. 수치 조합은 `재확인+기록 대조`가
  `체력 -6/마음 -2`, `재확인+인계 기록`이 `-4/-3`, `기록 대조+인계 기록`이 `-2/-4`로 평균이
  기존 `-4/-3`과 정확히 같다. 어느 한 조합도 돈·몸·마음 모두에서 다른 조합을
  완전히 지배하지 않는다. 전부 처리하면 `-6/-3`을 후보 기준으로 검증한다.
- 배경은 기존 `warehouse_inventory_night`, 소리는 기존 스캐너·종이·필기 계열을
  사용한다. 웹 카드 세 장처럼 보이지 않도록 창고 장면 위의 선반·기록표·단말기
  작업 대상으로 표현하고, 선택 시 해당 대상과 남은 교대 시간이 물리적으로
  변한다. 960×600과 1280×800에서 중첩 스크롤 없이 읽혀야 한다.
- 선택 중에는 효과를 적용하지 않는다. 선택 순서와 남은 단계는 기존 V2 상태 안의
  단일 세션 영수증이 소유하며, 저장·재구성 뒤 같은 지점으로 돌아온다. 완료할 때만
  기존 `finalize_weekly_effect_action()`으로 AP·효과·축·영수증을 정확히 한 번
  확정한다.

## 배치 B — 한 장면의 결과와 다음 장면이 같은 영수증을 읽는다

- 완료 영수증 하나에 `task_id`, 고른 요구와 순서, 남긴 요구, 무리하기 여부,
  실제 효과와 결과 ID를 기록한다. 각 클릭마다 영구 플래그를 만들지 않는다.
- 수행 화면은 불일치 발견과 처리 순서를 맡고, 기존 `v2_inventory_count_nights`는
  교대 시각 뒤 몸과 사물에 남은 결과를 맡는다. 세 조합과 전부 처리 결과를
  영수증으로 나눠 읽고, 포기한 일을 했다고 쓰거나 원인을 찾지 않았는데 찾았다고
  쓰지 않는다. 수행층 도입 전 저장은 당시 장면이 증명한 재확인·확인 시각·선반
  번호만 별도 레거시 결과로 읽으며 새 조합을 발명하지 않는다.
- 3개월차 수첩의 기존 `이번 달에 한 일` 기록은 항상 실제 결과를 한 줄로 읽는다.
  다음 달 물류 수업에 도달한 경로에서는 같은 영수증이 어긋난 행을 다시 볼 때의
  짧은 기억을 바꾸되, 정답·보너스·합격 보장·새 선택지를 공짜로 만들지 않는다.
  면접 질문 앞에 일반 memory를 덧붙이면 질문 뒤에 회상이 붙는 순서 오류와 정답
  암시가 생기므로 이 슬라이스의 독자로 쓰지 않는다.
- 결과 장면은 별도 수치 카드와 중복 재생하지 않는다. 수행 화면에서 원인과 예상
  대가를 보고, 기존 깊은 결과 장면에서 자신이 실제로 처리한 일을 경험한 뒤 같은
  주를 정확히 한 번 닫는다.
- 이 슬라이스가 통과해도 다른 26개 행동에 자동 확산하지 않는다. 구체 과업,
  충돌하는 세 요구, 두 개 이상의 합리적 조합, 즉시 독자가 모두 있는 약속만 다음
  작업 후보가 될 수 있다.

  CI를 통과한다.
- L2: 실제 재고조사 절차와 `12/11` 숫자, 나흘·수당·날짜, 선택하지 않은 행동,
  결과 장면과 물류 수업 회상, 숨은 정답·도덕 채점·번역투가 서로 모순되지 않는지
  교차 재독한다. 셋 다가 항상 최선처럼 보이거나 한 조합이 무의미하면 실패다.
- L3: 사용자는 같은 RC에서 ① 자신이 실제로 무엇을 처리했는지, ② 무엇을 남겼고
  왜 남겼는지, ③ 그 대가가 왜 생겼는지를 설명한다. 웹 버튼 퀴즈처럼 느껴지거나
  수행과 후속 산문이 두 장면처럼 끊기면 확장하지 않는다.

## 완료 조건

- `m3_inventory_shift`는 의미 있는 입력을 두 번 이상 받고 서로 다른 유효 결과
  네 개를 만들며, 플레이어가 확정 전에 실제 대가를 안다.
- 선택 영수증은 같은 결과 장면과 도달 가능한 후속 표면이 읽고, 신규 상호작용
  플래그 0·효과/AP/주 완료 1회를 지킨다.
- 평균 수치 기준선·한영·저장·패드·두 해상도·24/48/240주·전체 감사·원격 CI가
  초록이며, 규범 승격 또는 일회성 판정을 기록한 뒤 아카이브한다.

## 완료 기록 (2026-08-10)

- 3개월차 재고조사는 창고 배경 위 선반·기록 작업대·인계표 세 지점을 고른
  순서대로 처리한다. 두 칸의 교대 여력이 끝나면 남긴 일과 보통 완료·무리하기의
  최종 수치를 동시에 보여 주고, 무리하기는 셋째 대상의 소리·동작 뒤 확정한다.
- 선택 중에는 효과가 없고 단일 세션이 순서·재개를 소유한다. 보통 세 조합과
  전부 처리 결과는 같은 영수증으로 결과 장면·월말 수첩·다음 달 물류 수업까지
  이어진다. 수행층 이전 저장은 당시 증명된 재확인·시각·선반 번호만 회수한다.

  24/48/240주 수치, KO/EN 960×600·1280×800 렌더와 한영·서사 감사를 통과했다.
- **승격:** 공용 적용 자격·영수증·표면 소유 규칙은
  `docs/CORE_LOOP_V2.md`의 `약속 수행층`, 수치 후보와 장기 생존 근거는
