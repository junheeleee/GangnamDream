- 재현은 재혁이 아니다. 지분10%·옵션·작은 월급 제안은 성공 보장이 아니다.

  급여200만원 차이의 비교 기간을 발명하지 않았다. 프리랜서 일주일·수정3회·30만원은 실제다.
