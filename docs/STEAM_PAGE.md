## 5. Steam 태그 스택
*(순서가 알고리즘 가중치에 영향 — 앞 5개가 가장 중요)*

```
1.  Visual Novel          ← 장르 1차 식별
2.  Choices Matter        ← 구매 의도 필터 (높은 전환율)
3.  Interactive Fiction   ← 장르 보완
4.  Story Rich            ← 내러티브 게임 검색 포획
5.  Life Sim              ← Schedule I / inZOI 관객 연결
6.  Multiple Endings      ← 리플레이 가치 강조 (25개 차별화)
7.  Management            ← 투자/직업 시스템 연결
8.  Drama                 ← 감성 필터
9.  Capitalism            ← Schedule I가 쓴 태그, 한국 경제 드라마와 직결
10. Singleplayer          ← 필수 기본 태그
```

> **입력 방법**: 스팀 파트너 대시보드 → 스토어 페이지 → 태그 편집  
> 위 순서 그대로 입력. 나중에 커뮤니티가 추가 태그를 붙여줄 수 있음.

## 6. 캡슐 아트 방향
*(디자이너에게 전달할 아트 브리프)*

### 핵심 컨셉
**"고시원에서 강남으로 — 둘 사이에 선 한 남자"**

### 메인 캡슐 (460×215px)
```
구도: 좌우 대비 분할
- 왼쪽 1/3: 고시원 방 내부. 좁고 어두운 공간. 책상 위 통장 영수증 "50만원".
  노트북 화면에 투자 차트. 전체 톤: 차갑고 파란 어둠.
- 오른쪽 1/3: 강남 야경. 삼성동 고층빌딩 실루엣. 불빛들. 따뜻한 황금빛.
- 중앙 1/3: 주인공 뒷모습 실루엣. 두 세계 사이 경계선에 서있음.
  양복 재킷 반쯤 걸친 모습 (정석과 비정석 사이).

타이포그래피:
- "강남드림" — Pretendard ExtraBold, 흰색 + 얇은 어두운 테두리
- "GANGNAM DREAM" — 하단 작게, 영문
- "5년. 50만원. 30억." — 오른쪽 하단 작은 크기, 황금색

피해야 할 것: 애니풍 캐릭터 얼굴, 과도한 한자, 너무 밝은 배경
```

### 소형 캡슐 (231×87px) — 검색 결과에 표시됨
```
최소 해상도에서 읽혀야 하는 것:
- "강남드림" 제목 (크고 선명하게)
- 강남 빌딩 실루엣 (우측) + 작은 인물 (좌측)
- "5년 50만원→30억" 텍스트는 생략 (너무 작아짐)
중요: 120×45px로 줄였을 때도 제목이 읽혀야 함.
```

### 라이브러리 헤더 (3840×1240px) — 스팀 앱 라이브러리
```
메인 캡슐을 수평으로 확장한 버전.
좌측에 고시원+주인공, 우측에 강남 파노라마.
제목만 크게 표시 (설명 텍스트 없이).
```
