## 영역 1: 내러티브 아크 & 스토리 구조

### 현황 평가
- 챕터1 (33세): 53개 아크 이벤트 — 밀도 충분
- 챕터2~5 (34~37세): 50개 이벤트 — 절반이 `min_turn:9999` (코드 트리거 전용)
- 챕터 카드 5종: 블랙스크린 시네마틱 구현
- 34세 구간이 재혁·상철 관계 플래그에 의존 — 해당 캐릭터와 관계 없는 플레이어는 이 구간이 비어 보임

### 개선 방향

**즉시**
1. **34세 독립 씬 3개 추가** — 관계 플래그 무관, 무조건 발동
   - `arc_34_two_years_in` (t=48~52): "이제 서울 사람인가?" 자각
   - `arc_34_parents_visit` (t=56~60): 부모가 서울에 오는 날
   - `arc_34_routine_trap` (t=62~68): 루틴이 안전지대가 된 위험

2. **연도 전환 씬 강화** — 챕터 카드 직후 2~3선택지 씬 삽입 (현재: 카드 → 일반 이벤트 풀)

3. **JSON에 `"trigger": "code_only"` 표시 필드 추가** — min_turn:9999 이벤트 파악 용이

**중기**
4. **정석/비정석 루트별 34~36세 아크 분기** — route 포인트에 따라 다른 씬 풀
5. **37세 엔딩 프리뷰 씬** — arc_37_ending_peace 이후 선택이 엔딩 방향 힌트 제공

## 영역 2: 경제 시스템

### 현황 평가
- 투자 18종, 레버리지/마진콜 구현
- 직업 15개 (월 132만~779만)
- **아이템 cost 전부 0 — 버그**: 상점에서 공짜로 아이템 구매 가능
- 투자 자산 drift 전부 0 — 장기 상승 추세 없음 (한국/미국 주식 현실 반영 안 됨)
- 밸런스: 30억 달성 14.8%, 무직 실패율 100% — 적절한 수준

### 개선 방향

**즉시**
1. **아이템 cost 복구 (버그)** — 정상 가격 복원:
   ```
   item_lotto: 25,000원 / item_vitamins: 30,000원 / item_gym: 80,000원
   item_counseling: 150,000원 / item_health_checkup: 300,000원
   item_spa: 500,000원 / item_watch: 5,000,000원
   ```

2. **자산 drift 추가** — 현실감 반영:
   - 한국주식 drift: 0.002~0.004/월
   - 미국주식 drift: 0.004~0.006/월
   - 부동산 drift: 0.003/월 (서울 장기 상승)

**중기**
3. **인플레이션 시스템** — 연간 물가 상승률 3% 적용 (5년간 지출 고정 현실 미반영)
4. **부동산 직접 투자** — 오피스텔 실매수 (3억~) → 월세 수입 루트
5. **세금 시스템** — 소득세(150만 초과분), 투자수익세 간략화

## 영역 3: 스탯 & 밸런스

### 현황 평가
- 스탯: 건강(65시작) / 정신력(60시작) / 지력 / 사회성 / 투자감각 / 평판 / 외모 / 운
- 월간 자동 감소: 건강 -2, 정신력 -3 (무직 시 -5)
- 외모·운 스탯이 게임 영향력 약함 — 플레이어가 해당 스탯을 올릴 유인 없음

### 개선 방향

**즉시**
1. **외모 스탯 영향력 확대**:
   - 면접 성공률 보정 (+1%/외모포인트)
   - 네트워킹 이벤트 선택지 해금 (외모 ≥ 60)
   - 강남 VIP 클럽 입장 조건 (외모 ≥ 50)

2. **운 스탯 체계화**:
   - 운 ≥ 70: 로또/투기 성공률 배수 적용
   - 운 ≤ 20: 재앙 이벤트 가중치 ×2
   - 일부 선택지 결과를 운으로 결정하는 분기

3. **스탯 상한 마일스톤** — 80, 100 도달 시 배지 표시 + 효과 해금 알림

**중기**
4. **스탯 시너지** — 복합 스탯 조합이 새 선택지 해금:
   - 지력 ≥ 70 + 투자감각 ≥ 70: "퀀트 전략" 특수 투자 모드
   - 사회성 ≥ 70 + 평판 ≥ 60: "강남 인맥" 전용 이벤트
5. **스탯 붕괴 임계 강화** — 건강 ≤ 20: 강제 입원 이벤트 (AP 0), 정신력 ≤ 10: 선택지 잠김
