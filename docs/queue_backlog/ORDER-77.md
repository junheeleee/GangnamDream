# Parent Plan: ORDER-77 — 표현·기억·결정과 5장 스노우볼 이관

> 상태: 데모 출시선 뒤 부모 계획. 자식 실행 오더가 아니다.
> 정본: `docs/CHOICE_CONSEQUENCE_SYSTEM.md`, `docs/SCENE_TIER.md`.

## 목표

현재 흩어진 V2 영수증, 본편 flags, 최근 16건 약속, 단순 지연 큐, route/tint,
관계 단계와 엔딩 우선순위를 하나의 5장 인과 계약으로 이관한다. 모든 선택을
영구 분기로 만들지 않고 표현·기억·결정 세 층으로 나눈다.

## 깊이 3문

1. 지우면 1장의 선택이 5장에 돌아온다는 작품 약속을 자동으로 증명할 수 없다.
2. 모든 선택을 플래그로 만들면 조합 폭발과 번역·QA 비용이 감당되지 않는다.
3. 정확한 사실, 인과 영수증, 반복 습관을 분리하면 기존 콘텐츠와 저장 ID를
   보존한 채 작은 대답과 큰 결정의 무게를 다르게 만들 수 있다.

## 자식 오더 생성 순서

### 1. 전수 분류·기준선

- 직접 선택 주차 52회, 보스 7회, 챕터 마감 5회, 엔딩 35개가 실제로 읽고 쓰는
  flags/route/tint/관계/후속을 원장화한다.
- 각 선택을 표현·기억·결정으로 분류한다. 독자 없는 flag, 원인 없는 후속,
  마지막 엔딩이 읽지 않는 챕터 결정을 별도 부채로 출력한다.
- 과거 32-root `PASS`를 기능별 T1 프로필로 재분류하되 일괄 산문 확장은 하지 않는다.

### 2. 첫 수직선

- `4주 첫 선 → 24주 첫 청구서 → 48주 첫해 보스 → 2장 첫 장면`만 공통
  story ledger 후보로 연결한다.
- 기존 8방향 데모 영수증, 이벤트 ID, 효과, 저장 호환을 보존한다.
- 48주 보스가 이번 장 기억, 더 오래 가져갈 핵심 carryover, 불가역 결정을
  작은 명시 입력 묶음으로 읽고, 2장 첫 장면이 보스 carryover를 실제
  문장·참가자·위협·가용 행동 중 하나로 소비하게 한다.

### 3. 장별 이관

- 한 번에 한 챕터만 다룬다. 이름 있는 미래 독자가 있는 소수의 기억과
  불가역 결정만 선별하고 나머지는 표현 선택 또는 현재 물질 상태로 남긴다.
- 한 장면은 과거 입력 최대 3개만 읽는다. 조합마다 새 이벤트를 복제하지 않는다.
- 각 배치는 KO/EN 같은 선택 구조, 저장 왕복, 미선택 회수, 다음 장 오프닝을
  함께 검증한다.

### 4. 보스·정점 프로필

- 첫 키스·계절, 관계 대전환, 가족·진실, 챕터 보스를 서로 다른 극적 비트·
  장면 기능과 연속성 프로필로 감사한다. 링크·패널·체감 시간은 관측값이다.
- 짧은 장면만 선별 수리한다. 이미 18~30패널과 충분한 체감 시간을 가진
  3링크 장면은 링크 수만 이유로 늘리지 않는다.
- 표현 선택은 고유 반응 뒤 합류하고 수치 보상을 요구하지 않는다.
- 기존 inert 감사가 표현 선택을 실패시키지 않도록 언어 독립
  `choice_kind=expression` 계약 또는 동등한 메타를 만들고, 신규 상태 0·선택별
  고유 반응·장면 안 자연 합류를 직접 검사한다. 공통 follow-up 하나만 붙여
  래칫을 우회하지 않는다.

### 5. 엔딩 계층 이관

- 중단 귀결 → 결과 상태 → 불가역 결정 → 본 결말 가족 → 사람들의 이후·35개
  변주 순서로 판정한다.
- 마지막 관계 bool이나 Moral Tint 임계 하나로 5년을 환원하지 않는다.
- 기존 엔딩 ID·CG·MetaProgression·저장 호환은 보존한다.

## 금지

- 모든 대화 선택에 영구 flag·호감도·Moral Tint를 붙이지 않는다.
- 5장 전체를 한 커밋에서 이관하지 않는다.
- 새 원장이 안정되기 전에 기존 V2 receipt나 본편 flag를 삭제하지 않는다.
- 사용자 정상 속도 판정 없이 `재미 PASS` 또는 `분기 충분`을 선언하지 않는다.

## 완료 증거

- 다섯 장 각각 보스가 선언한 과거 입력과 carryover를 실제 소비한다. 5장의
  carryover는 다음 장 대신 최종 장면·사람들의 이후·에필로그가 소비한다.
- 독자 없는 신규 receipt/fact 0, 소비 원인 없는 scheduled contract 0.
- 표현 선택의 신규 수치/플래그 0, 선택별 고유 반응과 자연 합류 PASS.
- 대표 KO/EN 240주 두 경로에서 챕터 원장·엔딩 가족·사람들의 이후가 실제
  선택과 일치하고 저장 왕복 diff 0.
- 자동 증거와 별도로 정상 속도 사람 플레이에서 1장 선택 두 개를 5장 회수로
  기억하고 설명할 수 있다.
