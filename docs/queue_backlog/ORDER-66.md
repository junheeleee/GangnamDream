## 1. 엔딩 크레딧 — 없다

`credit` 검색 결과가 전부 슬롯머신 `CREDIT` 미터와 신용등급이다. **크레딧 장면도
데이터도 문서도 없다.**

이 게임에서 특히 비어 있는 자리다. 엔딩이 **7종**이고 `ENDING_CONTRACT.md` §4가
`사람들의 이후`를 정점으로 규정했는데, 그 여운을 받는 화면이 없다.

- 엔딩 직후 이어지고 **건너뛸 수 있어야 한다**(두 번째 플레이).
- 외주 0원이므로 사람 이름은 짧다. **그 자리를 무료 자산 출처가 채운다** —
  짧은 크레딧일수록 고지가 본문이 된다.
- `SURFACE_MATERIAL.md`의 물성을 따른다. 크레딧만 다른 세계면 마지막 인상이 깨진다.
- **엔딩별로 다르게 할지 사용자 판단이다.** 기본은 공통 한 벌이며, 7종 변주는
  `ENDING_CONTRACT`가 이미 요구하는 `사람들의 이후`와 중복될 수 있다.

## 2. 게임 버전 문자열 — 없다

`project.godot`에 Godot의 `config_version=5`만 있고 **게임 버전이 없다.**
`RELEASE_NOTES.md`는 있는데 실행 파일과 연결되지 않는다.

**버그 리포트를 받아도 어느 빌드인지 알 수 없다.** 데모를 외부에 돌리는 순간 바로
문제가 된다.

- 단일 출처에서 읽는다. 코드·스토어·릴리스 노트가 각자 버전을 갖지 않는다.
- 시작 화면 구석과 저장 파일 메타에 남긴다. 저장에 남겨야 **어느 버전에서 만든
  세이브인지** 알 수 있고, 이는 `SAVE_POLICY`(`ORDER-61` 단위 6)와 맞물린다.
- 데모 빌드는 데모임이 드러나야 한다(`DemoBuildCheck`가 이미 flavor를 안다).

## 3. 게임 내 고지 화면 — 없다

`AUDIO_THIRD_PARTY_NOTICES.md`는 모범적인데 **오디오만** 덮는다. 폰트·이미지·
라이브러리를 아우르는 화면이 게임 안에 없다.

**외주 0원 = 무료 라이선스 의존이므로 이것은 선택이 아니라 의무다.** OFL과 CC BY는
둘 다 고지를 요구한다.

- 시작 화면 `설정` 또는 크레딧에서 도달한다. 숨기지 않는다.
- 원장(`FONT_LICENSE_LEDGER.md`, `AUDIO_SOURCE_MANIFEST.json`)에서 **생성**한다.
  손으로 옮겨 쓰면 반드시 낡는다.
- **원장에 없는 자산이 빌드에 있으면 실패하는 검사**를 함께 만든다. 고지는
  최신이어야 의미가 있다.

## 4. Steam SDK — 이 오더 밖

GodotSteam 호출이 **0**이다. `steam` 언급은 입력 글리프(`ControllerHints`)와
스크린샷 도구뿐이다. 따라서 업적 15종은 내부에만 있고 Steam 업적으로 올라가지
않으며, 클라우드 세이브·오버레이도 없다.

**이 오더에 넣지 않는다.** GodotSteam 도입은 빌드 파이프라인과 CI를 건드리고,
`ORDER-61` 배치 1의 심의 결과가 스토어 등록 자체를 바꿀 수 있다. **심의 결정
뒤에 별도 오더로 연다.** 지금 열면 결정이 뒤집힐 때 통째로 버려진다.

- 크레딧에 **없는 사람 이름을 적지 않는다.** 외주 0원이므로 참여자는 실제 그대로다.

- 저장 호환을 깨지 않는다. 버전 메타는 **추가**이며 기존 세이브는 `unknown`으로
  읽힌다.
- Steam SDK를 이 오더에서 도입하지 않는다.
