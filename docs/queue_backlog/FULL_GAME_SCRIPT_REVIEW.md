# 본편 대본 정합 검토 계획 (Claude 판독 → Codex 수리)

> 2026-09-26 사용자 지시로 만든 부모 계획이다. 실행 순서의 정본은
> `CODEX_QUEUE.md`가 소유하며, 이 문서는 배치 목록과 판독 기준만 둔다.
> 첫 배치(체험판 M01~M06)의 결과가 `ORDER-302`다.

## 방식

1. **Claude가 읽는다.** 배치 하나의 KO/EN 장면 원문, 셸 문구, 월 전환 요약을
   플레이 순서대로 읽는다. 파일을 고치지 않는다.
2. **판독 결과를 오더로 만든다.** 결함마다 위치(이벤트 ID·선택 번호), 근거
   (충돌하는 두 문장), 수리 방향을 적어 `queue_active/ORDER-N.md`로 발행한다.
3. **Codex가 고친다.** KO/EN/JA/zh 오버레이, 해시 고정 검사, 실제 화면까지
   정합시키고 L1/L2 증거를 남긴다.
4. **판단이 필요한 것은 고치지 않는다.** 서사·밸런스·선택 구조 변경은
   "판단만 남기는 항목"으로 분리하고, 외부 플레이테스트 결과나 사용자 판정 뒤
   다룬다.

## 순서와 조건

- **R1 → R2 → R3 → R4** 순서로 진행한다. 앞 장의 사실이 뒤 장 판독의 기준이
  되므로 순서를 바꾸지 않는다.
- **R5a·R5b**는 5장 HOLD 수리(`ORDER-137/138/148/150/151/156`)가 같은 파일을
  만지는 동안 발행 오더가 충돌할 수 있다. 판독은 진행하되, 수리 오더는 해당
  HOLD 수리가 닫힌 뒤 발행한다.
- **R6**은 R5b 뒤. 엔딩은 5장 결정을 직접 읽으므로 먼저 읽으면 기준이 없다.
- **R8**은 본편 핵심 장면이 확정된 뒤 표본으로만 본다. 전수 판독하지 않는다.
- 각 배치 결과는 결함 0건이어도 기록한다("판독 완료, 수리 없음").
- 이 판독은 외부 플레이테스트와 원어민 검수를 대신하지 않는다. 사람 게이트는
  OPEN으로 남는다.
