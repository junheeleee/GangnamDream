## 왜 지금인가

**두 가지가 이 파일에서 막힌다.**

1. **`ORDER-63` 배치 3(테마 단일 출처).** `add_theme_*_override`가 전 저장소
   2,362건인데 **645건(27%)이 이 파일 하나에 있다.** 19,984줄을 훑으며 테마를
   갈아 끼우면 리뷰가 불가능하고, 되돌릴 단위도 없다.
2. **신규 장면 작업.** 688개 함수와 244개 멤버가 한 이름 공간에 있어, 새 함수를
   넣을 자리를 찾는 것 자체가 매번 비용이다. `signal`이 0이라 모든 결합이
   직접 호출이며, 이는 뜯어내기 전에는 부분 테스트가 불가능하다는 뜻이다.

**그러나 데모보다 앞서지 않는다.** `ORDER-57` E가 데모를 닫는 유일한 작업이고,
이 오더는 화면에 아무것도 더하지 않는다. **`ORDER-57` E 뒤, `ORDER-63` 배치 3
앞**이 자리다.

## 불변 — 이 오더가 지키는 선

- **행동을 바꾸지 않는다.** 순수 이동이다. 버그를 발견하면 고치지 말고 적어 둔다.
  옮기면서 고치면 회귀가 났을 때 이동 탓인지 수정 탓인지 갈라낼 수 없다.
- **저장 호환, 엔딩 ID, `finish_run` 라우팅을 건드리지 않는다.**
- **테마·색·폰트를 건드리지 않는다.** `ORDER-63` 배치 3이 소유한다. 이 오더는
  그 작업이 가능한 크기의 파일을 만들어 줄 뿐이다.
- **파일을 지우지 않는다.** 고아 스크립트(`TradingFloor.gd`·`StatRow.gd`)는
  `ORDER-62` 배치 3이 소유하며 사용자 승인이 필요하다. 중복 소유하지 않는다.
- **`project.godot`은 사용자 소유 변경이다.** 만지지 않는다.
- 콘텐츠·산문·이벤트 JSON은 이 오더 밖이다.

## 검증 — 이동이 아무것도 바꾸지 않았음을 증명한다

배치마다 전부 돌린다. 무행동변화 배치는 **이전과 같은 결과**여야 한다.

```bash
python3 tools/audit_select.py --base main
GODOT=/usr/local/bin/godot ./tools/audit.sh
python3 tools/project_dashboard.py --md docs/STATUS.md   # 낡음 방지
godot --headless res://tools/SimRun.tscn                 # 60턴 완주
git diff --check
```

**SimRun 로그를 이동 전후로 비교한다.** 같은 시드에서 결과가 달라지면 순수
이동이 아니었다는 뜻이므로 되돌리고 원인을 찾는다.

화면을 건드린 배치는 `ScreenshotQA.tscn`에서 해당 scope·KO/EN만 확인한다.

## 하지 않는 것

- **미리 설계한 구조로 통째 재작성하지 않는다.** 측정이 고른 이음매만 자른다.
- **`signal`이 0이라고 이벤트 버스를 새로 도입하지 않는다.** 그것은 아키텍처
  결정이고 이 오더는 이동만 한다. 필요하면 근거를 모아 별도로 올린다.
- **줄 수를 줄이려고 코드를 압축하지 않는다.** 목표는 짧은 파일이 아니라
  **한 사람이 한 번에 읽고 되돌릴 수 있는 단위**다.
