## 0. 핵심 판정: 레일을 버리지 않는다

Codex가 방금 완성한 act-aware ACTION RAIL은 좋은 물건이다. 지도는 레일의 **대체가 아니라 프레임**이다:
장소를 고르면 → 그 장소의 행동들이 **기존 레일 카드 문법 그대로** 시트로 열린다. 재사용률 ~80%, 리스크 최소.

## 1. 단계 설계

### Phase M1 — 컨텍스트 레이어 (싸다, 파괴 없음)
- This Week 카드 위/옆에 **잉크 미니맵 스트립**(가로 밴드): 장소 노드 7개가 점·선으로.
- 이번 주 행동한 장소 노드가 은은히 점등(축 색 문법: 돈=금빛, 사람=온기색). 몽타주 후엔 지나온 주 수만큼 노드 사이 잉크 선이 이어짐 — "시간이 지도 위로 흐른다".
- 조작 불가(순수 표시). 리스크 0. **여기까지만 해도 "장소에서 산다" 체감이 생긴다.**

### Phase M2 — 장소 내비게이션 (본편)
- ACTION RAIL 자리를 **장소 그리드**(노드 7+강남 앵커)로 교체. 장소 선택 → 행동 시트(기존 레일 카드).
- Steam Deck: 좌스틱/십자키로 노드 포커스, A=진입, B=닫기 — 화면당 조작 모델 1개 유지.
- 클릭 깊이 +1 문제의 해결: ①마지막 사용 장소 기억(포커스 복원) ②각 노드에 대표 행동 1개를 롱프레스/X 단축으로.

## 2. 장소 ↔ 행동 매핑 (정본 — Claude 확정)

| 노드 | 행동 | 비고 |
|---|---|---|
| **고시원(방)** | 휴식 · 자기계발(독서/명상) · 이사 | 시작점. 주거 사다리 오르면 노드 이름/아이콘이 승격(원룸→빌라→아파트) — 진행이 지도에 새겨짐 |
| **편의점** | 인연 연락(다은) · 절약 | 다은 로맨스의 앵커. 다은 스테이지에 따라 노드 온도 변화(Codex 재량) |
| **일터** | 근무 상태 표시 · 구직/자소서/면접 · 창업 업무 | 무직이면 "구인 게시판" 명칭 |
| **한강** | 운동 · 콘텐츠 제작 | 회복의 장소 |
| **시내(상가)** | 인맥 · VIP 인맥 · 은행(대출/상환) · 상점 | 도구적 사교의 거리 |
| **지하** | 홀덤 · 스캘핑 | 해금 전 노드 자체가 흐릿/잠김 — 해금이 지도에 보임 |
| **정선行** | 경마장 · 카지노 | 지도 가장자리의 "떠나는" 노드 — 원정 뉘앙스 |
| **강남 (앵커)** | 행동 없음 — 진행도만 | 지도 위쪽에 항상, 처음엔 멀고 흐릿. 자산이 늘수록 잉크가 선명해짐. 클릭 시 "아직 멀다" + 남은 거리. **승리 시 이 노드로 카메라가 이동하며 엔딩 진입** |
| *(폰 오버레이)* | 투자 · 시장 분석 | **장소화하지 않음** — 투자는 어디서든 폰으로 하는 게 한국 리얼리즘. 화면 구석 폰 아이콘 상시 |

- 몽타주 진입("루틴대로 시간을 보낸다")은 지도 하단 상시 버튼 유지 — 장소가 아니라 시간의 행동이므로.
- 스토리/주간 사건은 기존 StoryMode 풀스크린 그대로(지도는 자유 시간의 프레임일 뿐).

## 3. 서사 이득 (이 제안의 진짜 값)

- **다은을 만나러 편의점에 "간다"** — 로맨스가 클릭이 아니라 걸음이 된다.
- 그라인더의 지도는 일터·지하만 닳고 편의점 잉크가 마른다 — **축 시스템이 공간으로 시각화**. tint 수치 노출 없이.
- 주거 사다리·도박 해금·강남 접근이 전부 지도 위 변화로 — 진행의 물리적 증거.
