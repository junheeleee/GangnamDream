## 1. 치명 발견 (CRITICAL — 이것들이 재미를 죽인다)

### C1. 선택에 고민의 재료가 공급되지 않는다 (최대 병소)

여러 렌즈에서 독립적으로 같은 지점이 확인됐다.

- **다중 선택 이벤트의 44.8%(660/1,472)는 어떤 선택지를 골라도 명시적 즉시 비용이 없고, 63.9%(940/1,472)는 무엇을 골라도 플래그 구성이 같다** — 게임이 선택을 기억하지 않는다. 골드 스탠다드 「그 밤」의 정점 선택(`arc_daeun_first_night_decision`)조차 두 선택지 모두 +정신/+호감. 기회비용 없는 선택은 선택이 아니다.
- **240주 전체의 직접 결정이 8개 동사의 재조합** — `GameState.gd` `WEEKLY_COMMITMENT_ACTION_MATCHES` 키가 정확히 apply/resume/side_shift/save/rest/study/contact/invest 8개. side_shift가 압박 프레임 10개 중 6개에, rest가 6개에 중복 등장. NOW/COST/LATER 프리뷰는 대부분 상태와 무관한 고정 문자열이고 세 카드의 COST는 사실상 동의어("이번 주 현금과 준비 시간은 포기" / "이번 주 수입과 실제 지원은 포기"). 3~4번째 결정 주부터 모든 카드를 이미 읽어본 상태가 된다.
- **결정 주의 선택이 Quiet 주의 자동 루틴과 같은 함수·같은 규모** — `_montage_apply_slot`이 수동 행동과 같은 비네트 풀 평균 효과를 적용, save는 수동과 동일한 `30000 + randi()%70000`. 내 손의 선택이 오토파일럿과 구별되지 않으면 뇌는 그것을 진행 버튼으로 분류한다. 5아키타입 3,000런에서 정책 내 우세 엔딩 93~100% — **52번의 주간 선택이 결말에 노이즈라는 것을 자체 시뮬레이션이 증명**한다.
- **"닫힌 두 길"은 표시 전용** — `forgone_ids`를 읽는 코드가 라벨 렌더뿐. 포기한 contact를 해도 다은의 상태는 변하지 않고 다음 로테이션에 contact가 다시 온다. 포기 비용 = 0을 플레이어가 2번째 결정 주에 학습한다.
- **LATER가 회수되지 않는다** — LATER는 확정 순간 이미 공개된 고정 문구("1~3주 · 피로와 생계의 여유")이고, `consume_weekly_commitment_echoes`는 도장만 찍고 반환한다. Echo 주는 이미 본 정보의 재방송 — 시간차 피드백의 정보량이 0비트다.
- 데모의 유일한 진짜 딜레마는 t4 대포통장(`arc_temptation_01`) 하나 — 12초 타이머, 비용이 드는 미덕(거절 mental −8), 즉시 dik 회수. **이 품질의 선택이 24주에 1개.**

**Round 3 "세 카드 중 실제 망설임"은 정보 구조상 발생할 수 없었다.** → 수리: ORDER-36

### C2. 게임의 "기본 목소리"가 최하품질 콘텐츠로 설정돼 있다

콘텐츠가 사실상 두 개의 다른 게임이다. 작성형(~520개, 본문 중앙값 231자)은 소설급인데, 매주 뽑히는 랜덤 풀은 중앙값 80~130자 단문 카드다. **유저는 8주에 한 번 소설을 읽고 나머지 주는 트윗을 읽는다.**

- 콜백 621~629개(전체 40%)의 상당수가 "한때 {name}은 X했었다 → 오늘 또 떠오른다" 골격의 교훈 반추. **그중 422개는 모든 선택지가 비손실 자기긍정** — "게임이 내 선택을 기억한다"가 "복습시키고 채점한다"로 뒤집혔다.
- 격언 종결 습관("괜찮은 사람은 거절을 상처로 안 만든다", "요청하지 않으면 아무것도 바뀌지 않는다") — 자체 정본인 설교 방지 5원칙(DECISIONS 2026-07-07) 1·4·5항의 대량 위반. korea_* 풀 58개는 한국인 주인공이 스스로에게 한국을 해설하는 다큐 시점 이탈.
- 다은 초반 아크(데모 간판, t9~23)에 기계적 괄호 주석이 집중 — "고맙다고, 이름을 묻는다 (인연 시작 / 용기·약간의 거리)". 전체 선택지 3,448개 중 194개. 드라마를 메뉴판으로 되돌린다.
- 산문 총량 ~61만 자(장편 1.5권)는 충분한데 1,565조각(조각당 평균 390자)으로 살포돼 어떤 조각도 감정이 축적될 길이에 못 미친다. **STORY_BIBLE(§ 아크 60+위기 5+앰비언트 40)이 스스로 처방한 정답의 정확히 반대 방향으로 콘텐츠가 자랐다.**
- "왜 30억인가"(R1.5)의 답이 전부 요약 서술 — "그 6년을 한 문장으로 만들 수가 없었다"고 게임 스스로 한 문장 처리. 6년의 빚이 한 번도 장면이 되지 않는다(CODEX_QUEUE 194의 플래시백 계획은 미집행).

→ 수리: ORDER-37

### C3. 재미 엔진 5종이 전부 판정 범위 밖에 있다

데모(t≤24)가 파는 판타지는 "30억 상승 + 영혼이 무너지는 색"인데 실제 데모 경험은 편의점 알바·월세 걱정·불합격 메일이다.

- 다은·지연 2번째 장면 t≥34(데모는 각 1장면), 정선 카지노 초대 t≥76, 투자는 t12 해금이지만 종잣돈 수백만원 스케일, tint는 깨끗한 손 루트에서 거의 비가시.
- 7/15~17 집중 집필된 최고 산문(프로포즈·첫날밤·상철 대면·아버지 병상)은 전부 t24 이후 — **유저는 매 라운드 게임에서 가장 오래되고 가장 약한 콘텐츠로 재미를 판정해 왔다.**

### C4. 입력의 93~95%가 확인 노동

- 데모 67.3분 / 확인 입력 689회 / 의미 선택 36회 — 6초에 1회 넘김. 전체 런은 실결정 1회당 확인 61회. 첫 주에만 171~173회 입력.
- 문단당 입력 문법: 타이핑 완성 1회 + 다음 문단 1회, 본문 전체 수동 넘김(StoryMode). 1시간에 690회를 누르면 뇌는 선택 버튼과 넘김 버튼의 구별을 포기하고, 진짜 선택이 와도 넘김 반사로 누른다.
- Quiet/Echo 주간 표면도 고정 문장("출근, 귀가, 다음 알람…" — 데모 24주 중 11주가 동일 문장) + 진행바 재생. 반복 제거 장치가 새로운 반복 자극이 됐다.

→ 수리: ORDER-38 (자동 재생·병합), ORDER-36 (Echo 재정의)

### C5. 30억 목표 피드백의 구조적 파산

- 중앙값 런 자산: 안전 직장 2.44억 / 사람 중심 0.87억 / 순수 도박 0.07억 — 대부분의 런이 목표 바 10% 미만에서 종료. 퍼센트 포맷이 `%.4f%%`(0.01% 미만 전용 자릿수)인 것 자체가 바가 안 움직인다는 자인.
- 루프의 돈 동사 실효는 "지출 3만~10만원을 막는다" = 목표의 0.001~0.003%. 목표와 수단의 자릿수가 3~5개 차이 나면 진행 바는 시각적으로 정지하고, 플레이어는 "내가 잘하고 있나"의 답을 한 번도 받지 못한다.
- 설계 의도(월급으로 30억 불가, 성실 경로는 다른 가치의 결말)는 정당하나, HUD가 매주 30억 대비 %를 보여주는 한 체감은 "5년 내내 0점짜리 시험지"다. 올바른 스케일의 사다리(HOUSING_DATA 800만→1.3억)가 이미 있는데 모달에 숨어 있다.

→ 수리: ORDER-39

### C6. 프로세스가 이 상태를 유지시킨다 (메타 — 3라운드 수리 실패의 원인)

1. **번역 손실**: R1 "재밌다는 느낌이 안 들어" → "인과 단절+리듬 부재"(파라미터 조정), R2 "감흥이 없다" → "단일 링크 43/46"(링크 수), R3 "재미없어" → "약속/후회 이론"(유저가 말한 적 없는 미시 이론을 구현 가능한 형태로 발명). 지표는 매번 개선됐고(입력 1,008→666) 판정은 3연속 NO-GO — 진단이 원인을 못 짚었다는 직접 증거.
2. **인간 표본이 개발자 본인 3회뿐**: 외부 플레이테스트 키트(ORDER-08, 5~10명·무설명 30분·3-OS 빌드)를 7/13에 완성하고 **한 번도 사용하지 않았다**. 재미는 원리적으로 인간만 측정할 수 있는데 샘플링이 3일에 1비트다.
3. **콘텐츠 동결이 재미의 원료를 봉인**: 동결(7/13)이 첫 인간 플레이(7/14) 하루 전 선언 → 이후 모든 수리가 "새로 쓰기" 없는 편성 수술로 제한. 짧은 카드를 follow_up으로 이어도 각 카드의 문장이 그대로면 체험은 "알림 목록 순서대로 읽기"다.
4. **면책 문구의 의례화**: "자동 게이트는 재미를 증명하지 않는다"를 20회+ 적으면서 매번 자동 지표 작업으로 복귀. 이 프로젝트의 게이트가 잡을 수 있는 것은 결정 가능 속성(도달성·결정론·패리티·회귀)뿐이고, 잡을 수 없는 것은 1인칭 체감 속성(몰입·망설임·산문의 맛·기억) 전부다.
5. **자원 배분 유출**: NO-GO 기간에 4K 업스케일·해상도 장부·모딩 3·4층·일본어 키 정비로 노력이 흐름. "데모 GO 전 주 25~240 확산 금지" 자기 규칙을 7/18에 스스로 해제하고 미검증 문법을 240주 전체에 복제 — 문법이 틀렸다면(3연속 NO-GO가 시사) 수리 비용이 10배가 된 상태.
6. **정체성 충돌 최소 5개**: "지켜보는 게임"(상품 정의) / 라이프심 대시보드 / 카지노 훅 / 인터랙티브 소설 / 로맨스 / 압박 보드게임. 특히 **유저가 원한 것은 "민준으로 살기"인데 상품 정의 자체가 "지켜보기(구경꾼)"를 전제** — R1.5 노트("왜 내가 민준으로 살면서")가 이 충돌의 정확한 증상.

## 2. 주요 발견 (MAJOR)

- **M1. 궤적의 소유권이 편성기에 있다** — 어느 주가 멈추는지·무엇이 압박인지·무슨 카드가 오는지 전부 Pressure Director가 정하고 플레이어는 배급된 3택의 소비자. R1의 480회 잡무와 R3의 52회 배급은 양극단이지만 "플레이어 궤적 소유권 0"이라는 공통 원인을 갖는다. 80 Days·Princess Maker·Chinese Parents처럼 "내 계획"이 먼저 있어야 방해가 드라마가 된다. (→ ORDER-36 §4)
- **M2. 압박이 드라마가 아니라 로테이션 해시** — `posmod(chapter_month + state_offset, families.size())`. 서사적 위급도가 아니라 상태값 나머지 연산이라 아무 일 없는 주에도 몸 압박이 온다. 7가족 중 5가족이 `"urgent": false` 고정. 플레이어는 2~3회 만에 헤드라인이 벽지임을 학습하고, 진짜 위기의 신호가치까지 파괴된다. (→ ORDER-36 §3)
- **M3. 생존 압박이 취업과 동시에 소멸** — 무직 방치 실패 95~100% / 직장 실패 0~2%. 1주차 취업 즉시 월세가 무의미해지고 이후 239주는 "죽지 않는 게임". Papers Please의 도덕 마모가 체감되는 건 부족이 상수여서 선 넘기가 매일 합리적 유혹이기 때문 — 이 게임의 소재(한국의 청구서 사회)가 정확히 이 엔진의 재료인데 미사용. (→ ORDER-39 §2)

## 8. 시스템 렌즈 + 적대적 검증 결과 (재실행분)

### S1. 투자·도박은 실제 돈을 움직인다. 그러나 서사는 아직 그 플레이를 거의 읽지 않는다

- 투자 태그 사건은 210개이며 `has_portfolio` 조건 42개, `min_investment_skill` 조건 9개가 실제 보유·숙련 상태를 읽는다. 거래는 `GameState.money`, `portfolio`, `market_prices`를 사용하고 수수료·배당·레버리지·마진콜까지 실제 잔고에 반영한다. 따라서 투자 화면이 본편 자산과 분리된 가짜 지갑이라는 의심은 기각한다.
- 도박 태그 사건은 87개지만 `min_gambling` 조건은 1개뿐이다. 정선의 바카라·블랙잭·슬롯·룰렛·다이사이·빅휠, 홀덤, 경마, 단타까지 9개 플레이 경로는 모두 `GameState.money`를 직접 증감한다. 미니게임 자금 연동 자체는 통과다.
- 반면 정선 세션의 서사 기록은 입장 전후 잔고를 비교한 `win/loss` 두 상태와 중독도 증가가 대부분이며, 정확한 세션을 회수하는 후속은 `jeongseon_big_loss_bus`, `jeongseon_big_win_urge` 두 건뿐이다. 무슨 게임에서 얼마를 어떤 방식으로 잃거나 땄는지는 인물·아크가 읽지 않는다.
- 투자 약속 원장에는 `asset_id/trade/amount/ratio`가 들어가지만 현재 결과·Echo는 일반 행동명과 공개 스탯 총변화만 말한다. 특정 종목, 매수·매도, 투입액, 실현 손익이 소설의 다음 장면으로 넘어가지 않는다.

**판정:** 경제 단일 원장은 **PASS**, 시스템-서사 통합은 **SHALLOW**다. ORDER-36의 출시 차단 결함은 아니지만 후속 콘텐츠 다이어트 때 일반 투자·도박 카드를 늘리는 대신, 실제 거래·세션 1건을 사람과 청구서가 읽는 회수 장면으로 바꿔야 한다.

### A1. 치명 발견 재검증

- 전체 1,565개 중 다중 선택 1,472개를 분모로 다시 계산해 `명시적 즉시 비용 없음 660(44.8%)`, `선택지 플래그 구성 동일 940(63.9%)`를 재현했다. 랜덤 풀 1,177개 중 follow-up 보유는 24개(2.0%)다.
- ORDER-36 전 `forgone_ids`의 소비자는 표시 라벨뿐이었고 다음 로테이션 재등장을 막지 않았다. 따라서 영구 폐쇄를 뜻하던 `CLOSED PATHS`는 거짓이었다. 구현 후 표면은 `그 주에 놓친 길 / NOT CHOSEN THAT WEEK`로 범위를 정직하게 제한한다.
- ORDER-36 전 `arc_temptation_01`은 4주 Boss 사건을 끝낸 직후 일반 AP 결정을 한 번 더 요구했고 결과를 즉시 설명했다. 구현 후 이 사건 자체가 그 주의 유일한 약속이며 AP를 소유하고, 결과는 8주에 두 분기로 돌아온다. 선택 시점의 `LATER`는 결과를 예고하지 않는다.
- `CoreChoiceSliceCheck`가 `t1 계획 1 / t4 서사 보스 1 / 같은 주 일반 AP 0 / t8 분기 2 / 저장 왕복`을 고정한다. 실제 KO PlayStation과 EN Xbox 24주 경로는 각각 642/646확인, 46사건, 25루트, 21후속, 일반 AP 8회+서사 보스 1회, Echo 4회로 같은 게임 상태와 CTA에 도달했다.

**적대적 결론:** 이번 수직 단면은 “한 주에 결정을 두 번 시키는 결함”과 “결과를 미리 말하는 가짜 시간차”를 제거했다. 그러나 8주 밖의 일반 세 카드가 여전히 익숙한 8동사 재조합이라는 C1의 대규모 병소와, 사람이 실제로 망설이는지는 해결됐다고 간주하지 않는다. 자동 게이트는 구조 PASS이고 재미 판정은 계속 NO-GO다.
