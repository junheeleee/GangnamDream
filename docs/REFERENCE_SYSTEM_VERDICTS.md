# Reference System Verdicts — 무엇을 가져오고 무엇을 버리는가

Updated: 2026-08-11

## 목적과 경계

이 문서는 강남드림이 이미 참조한 작품의 시스템을 전수 분해해 **한국 현실의
구체로 번역되는 구조만** 고르는 판정표다. 작품의 우열표도, 모방 목록도 아니다.
판정 기준은 한 줄이다.

> **한국의 구체적 현실 노동·관계 문법으로 번역되고, 서울 사이클의 주간 여력·
> 노드·클록·영수증 가운데 하나에 붙는가.**

가져오는 것은 정보 구조, 어포던스, 관용, 상태를 드러내는 방식, 규칙의 뼈대다.
아트, 코드, 고유 표현, 상표, 캐릭터, 고유 명칭·주사위·카드덱은 가져오지 않는다.
아래 `가져온다`도 구현 승인이 아니다. 각 후속은 사용자 승인을 받은 별도
1~2배치 오더로만 열린다.

## 판정 문법

- **가져온다:** 기존 네 요소 중 붙을 자리가 있고, 원작의 고유 외형 없이도
  민준의 서울 생활로 구체화된다.
- **보류:** 번역 가능성은 있으나 현재 24주에서 독자·경쟁·대가 중 하나가
  증명되지 않았거나, 25~240주 정본이 먼저 필요하다.
- **버린다:** 원작의 장르·세계·고유 인터페이스가 있어야 성립하거나, 새 덱·
  확률·호감도 문턱·실시간 타이머 같은 다섯 번째 시스템을 요구한다.
- **부착:** `여력`은 한 달에 저장된 네 주간 여력, `노드`는 직업·생계·사람·
  회복의 실제 장소와 일, `진행 클록`은 플레이어가 미는 임계점과 기한,
  `세계 클록`은 민준과 무관하게 도착하는 사건, `영수증`은 원인·비용·놓친 길·
  후속 독자를 가진 기록을 뜻한다.
- **후속 규모:** 모든 `가져온다`는 사용자 승인 뒤 열 수 있는 `1배치` 또는
  `2배치`의 최대 예상치를 적는다. 이미 일부가 구현돼 있어도, 참조에서 더
  가져올 구체 변화와 회귀 증거를 함께 닫는 작은 오더로 추정한다. 여기서는
  오더를 만들지 않는다.

| **A01 · Citizen Sleeper — 사이클 시작에 한정 행동 자원이 전부 보인다** `[CS-1][CS-2]` | 먼저 자기 한계를 보고 중요한 곳에 좋은 자원을 쓰므로, 선택의 대가가 행동 전부터 읽힌다. | 월초 몸·마음에서 고정된 네 주간 여력을 편의점 대타, 지원서, 아버지 통화, 하루 비우기에 배치한다. 주사위와 확률은 쓰지 않는다. | **가져온다.** 부착: `여력+노드`. 후속: **1배치**, 남은 여력·진전·대가·기한의 24주 표면 감사. |

| **A04 · Citizen Sleeper — 약한 결과도 대가가 붙은 전진이다** `[CS-3]` | 나쁜 자원을 버리는 행동이 없어지고, 약한 날도 플레이한 삶의 일부가 된다. | 낮은 여력도 한 주를 쓰고 진전하되 피로, 늦어진 접수, 다음 달 대사 같은 구체적 흔적을 남긴다. 확률 실패는 만들지 않는다. | **가져온다.** 부착: `진행 클록+영수증`. 후속: **1배치**, 25~48주에서 무효 `+0` 없이 실패 전진하는지 감사. |
| **A05 · Papers, Please — 두 자료를 실제로 맞대어 모순을 찾는다** `[PP-1][PP-2]` | 숨은 능력치가 답을 정하지 않고, 플레이어가 본 사물과 손동작이 판단을 소유한다. | `전산 12 / 선반 11`, 입고 기록과 반품 전표, 채용 공고와 제출 서류, 월세 고지서와 계좌 내역을 한 임계 수행에서 대조한다. | **가져온다.** 부착: `노드 임계점+영수증`. 후속: **2배치**, 재고조사 한 장면과 입력·패드·한영 회귀. |
| **A06 · Papers, Please — 낮의 노동 결과가 밤의 생활 장부로 넘어간다** `[PP-2]` | 업무 성과와 가족 책임이 별도 도덕 점수 없이 같은 돈을 놓고 충돌한다. | 편의점·물류 영수증의 돈이 월말 월세·체납·검진·교통비로 어디서 들어와 어디에 쓰였는지 잇는다. 가족 관리 미니게임은 만들지 않는다. | **가져온다.** 부착: `영수증`. 후속: **1배치**, 월말 돈의 출처와 미납 비용의 다음 달 소비자 감사. |

| **A08 · Papers, Please — 실시간 처리량과 건당 급여가 압박한다** `[PP-2][PP-3]` | 서류 확인 자체가 긴장과 숙련의 대상이 된다. | 마우스·스캐너 속도로 편의점 시급을 정하는 구조가 되어 숙고와 접근성을 해치고 `한 주=우선한 시간` 계약과 충돌한다. | **버린다.** 부착·후속 없음. 실시간 할당량과 급여 루프를 만들지 않는다. |

판정표에서 여러 작품이 같은 교훈을 가리켜도 시스템을 여러 개 만들지 않는다.
동일한 변화는 한 후속 후보로 합치고, 서로 다른 고유 외형은 모두 버린다.

| 합쳐서 남길 변화 | 가리키는 단위 | 유일한 소유자 | 함께 버리는 원형 |
|---|---|---|---|
| **유한한 한 달과 읽히는 포기** | A01·A17·B05·B09·B13·B17 | 저장된 네 `주간 여력`과 기존 네 노드 | 하루 슬롯, 활동 포인트, 별도 달력, 분기 지도 |
| **내 진행과 남의 시간 분리** | A02·A13·B02·B19 | `진행 클록/세계 클록`과 known/hidden 미리보기 | 적 의도 UI, 사건 제목 선공개, 실시간 타이머 |
| **실제 장소·일·생활의 물성** | A03·A05·B06 | 이름 있는 `노드 임계 장면` | 상시 서류판, 식사 자원, 카드 테이블, 3D 허브 |
| **약한 주의 실패 전진과 재개 문법** | A04·B02·B03 | `locked/expired/fallback/repeat`와 결과 영수증 | 주사위, Red/White 색, 성공 확률, 하드 재시작 |
| **원인 영수증의 후속 작용** | A06·A07·B01·B07·B10·B18 | 이름 있는 `영수증→노드/선택/결과` | 소셜 스탯, 성향 슬롯, 기억 카드, 패시브 유물 |
| **읽기 전용 수첩과 사실 계보** | A19·A21·A22 | 하나의 영수증 원장과 현재/낡음 상태 | 탐정 답안지, 미래 빈 페이지, 선택 덮어쓰기 |
| **자기 삶을 가진 관계** | B11·B12·B16·B19 | `사람 노드+인물/세계 클록+상호 영수증` | 호감도 랭크, 선물 반복, 전투 보너스, 관계 혜택 자판기 |
| **놓친 뒤 달라지는 같은 서울** | A20·B08·B17 | 만료 영수증과 48주 단위 실제 독자 | 범용 벌점, 엔딩 개수 수집, 여러 정본 노선, 타임루프 |

위 표는 여덟 개 기능을 당장 만들라는 목록이 아니다. 서로 겹치는 채택 단위를
한 소유자 아래 묶은 **금지선**이다. 이후 오더가 열리더라도 한 번에 한 수직
단면만 구현하고, 기존 소유자가 같은 일을 이미 하는지 먼저 감사한다.

### 함께 넣으면 서로를 지우는 조합

- 실시간 할당량·하루 슬롯·활동 포인트를 더하면 `주간 여력`이 같은 시간을 세
  번 계산한다.
- 숨은 사건을 Slay식 의도로 공개하면 Citizen식 세계 클록 소유권과 정본의
  비누설 계약을 깨뜨린다. 보이는 것은 민준이 이미 아는 마감뿐이다.
- Obra Dinn식 사실 원장과 Roadwarden식 저널은 두 화면이 아니라 같은 수첩의
  인덱스와 상태 계층이다.
- Roadwarden식 진행 임계값은 노동·준비에만 쓴다. 관계에 적용하면 Persona식
  호감도 자동 진전이 되살아난다.
- Papers식 물성, Pentiment식 식사, Persona식 공동생활은 한 임계 장면의 서로
  다른 그릇이다. 같은 주에 전경 사건을 추가로 쌓지 않는다.
- 장기 공동체 회수는 범용 플래그나 엔딩 조합기가 아니라, 이미 저장된 이름
  있는 영수증을 48·96·144·192·240주 장면이 읽는 방식으로만 확장한다.

## L1·L2 증거와 L3 사람 판정

- **L1:** 44단위 모두 `무엇 / 왜 작동하나 / 한국 현실로 번역 / 판정` 네 칸을
  채우고, 모든 `가져온다`가 기존 요소와 후속 규모를 가진다.
- **L2:** 번역 칸에 원작의 주사위·카드·학원·수도원·우주정거장·탐정 장부를
  그대로 남기지 않는다. 민준의 사람·장소·기한·금액·물건 중 하나로 다시 쓴다.
- **L3 OPEN:** 사용자가 `가져온다` 중 임의 3개를 고른다. 셋 모두 강남드림에서
  무엇이 되는지 그려지고 서로를 지우지 않아야 한다. 하나라도 아니면 44단위를
  전량 재검토한다. 자동 검사는 이 판정을 대신하지 않는다.
