## 금액 표기
- `format_money()`는 그대로 사용 (자체 처리). 라벨만 번역.
- 억 = "00M" (1억 = 100M), 30억 = 3 billion / ₩3B.

## UI 톤
- 간결한 게임 UI 영어. 마침표 최소화.
- 이모지·BBCode `[color]`·`%d/%s` 포맷 지정자·`\n`는 **절대 변경 금지**, 위치 보존.
- `{name}` `{housing}` 토큰 보존.
- 카페 시나리오의 `김 부장`은 항상 `Manager Kim`이다. `Kim Bujang`을 혼용하지 않는다.

### P-9 영어 장면 산문

- 지금 진행 중인 장면의 서술은 현재시제를 기본으로 한다. 실제 회상이나 명시된
  과거 시간 이동만 과거시제로 쓴다. 한국어 원문이 과거형 서술을 썼다는 이유만으로
  현재 장면 전체를 영어 과거시제로 옮기지 않는다.
- 한국어 수량 관용구를 개수 표현으로 직역하지 않는다. 예를 들어 `커피 한 잔만
  해요`의 `한 잔`은 `one cup of coffee`로 세기보다 제안의 가벼움과 짧음을 살린
  `grab a coffee`처럼 문맥에 맞게 옮긴다. 실제 금액·날짜·횟수·게임 수치는 이
  관용구 예외에 포함하지 않는다.

## 영어 인물 목소리 — 화자→청자

영어의 관계 거리는 한국어 경어를 직역하지 않고 다음 다섯 수단을 함께 써서
만든다.

- **문장 길이·완결성:** 단편은 자연스러운 영어 단편이어야 한다. 어색한
  보조동사 생략이나 잘못된 문장부호를 인물성으로 대신하지 않는다.
- **요청의 직접성:** 친밀도·권력·경계에 따라 명령, 질문, 조건부 제안,
  공동 약속을 구분한다.
- **머뭇거림의 위치:** 취약한 말을 꺼내기 전이나 통제가 깨진 직후에만 둔다.
  말줄임표와 대시를 인물 표식처럼 반복하지 않는다.
- **축약형:** 일상 대화에서는 자연스러운 축약형을 기본으로 하고, 완전형은
  강조·거리·공식 문구에 쓴다.
- **호칭:** 관계를 실제로 드러내는 자리에서만 쓴다. `-ssi`는 영어에서 쓰지
  않는다. 지연의 `oppa`는 연애 확정 뒤에만 허용하므로 24주 데모에서는 0을
  유지한다. `hyung`은 현수→민준의 나이와 관계가 중요한 부름·부탁·작별에서만
  선택적으로 남긴다.

문장 길이, 축약형, 완곡어, 호칭에는 목표 개수나 비율을 두지 않는다. 장면에
필요한 예외는 허용하되 이름을 가려도 화자와 관계가 남아야 한다.

### 전수 적용

24주 데모의 사건 대사, 선택지, 결과, 문자, 활동 대사를 모두 이름을 가리고
다시 읽는다. 화자와 관계 단계가 다섯 영어 수단으로 구별되어야 하며, 한국어의
의미·함축·숫자·날짜·토큰·문단은 그대로여야 한다. 동적 메시지의 중복 문구도
사건 오버레이와 같은 목소리를 유지한다. `oppa`와 `-ssi`는 24주 데모에서 0,
`hyung`은 선택적이어야 하며, 어느 항목도 비율이나 정규식 점수로 합격시키지
않는다.

## 문화 설명 원칙
- `Gangnam`은 고유명사로 유지한다.
- 외국인 초견 구간의 첫 주요 노출에서는 짧게 의미를 풀어준다: `Gangnam, Seoul's status district`, `Seoul's status symbol`, `wealth, status, arrival`.
- 이후 반복 UI에서는 설명을 계속 늘이지 말고 `Gangnam` 또는 `Gangnam Dream`으로 돌아간다.
