# Gangnam Dream IP Bible

This document keeps the game identity consistent across writing, UI, event tone, news, systems, and store materials.

## Current Direction
- Genre: Korean modern-life roguelike text RPG.
- Fantasy: surviving poverty, pressure, debt, relationships, work, and speculation while chasing upward mobility.
- Mood: darkly funny, anxious, sharp, satirical, strategic.
- UI keywords: dark navy dashboard, financial terminal, Football Manager density, visual novel event focus.
- Writing keywords: Korean social pressure, internet culture, financial anxiety, class mobility, absurd realism.

## Identity Rules
- Events should carry emotional, financial, or social consequences.
- Humor should sharpen the social satire without making the game feel random.
- Money systems should feel tempting, risky, and legible.
- Relationships should feel useful, dangerous, warm, or costly depending on context.
- UI should feel dense and strategic, not like a generic mobile menu.

## Open Questions
- Final English/Korean title.
- Main visual symbol for the game.
- Store capsule/icon direction.
- How dark the humor should become.
- Whether the player identity remains fixed or expands through unlocks.

## Avoid
- Random punishment without meaningful warning or counterplay.
- Events that only change one stat without story value.
- UI decoration that reduces readability.
- Financial simulation that feels arbitrary.
