## 1. 두 히로인 — 반전된 거울

| | **김다은** | **한지연** |
|---|---|---|
| 정체 | 편의점 야간, 시골 어머니를 모시려 돈 모음 | 부동산 회사 회장 딸, 자기 것을 가지려 독립(부산 공인중개사) |
| 상징 | 민준이 **떠나온 세계** (소박·진심) | 민준이 **가려는 세계** (강남이 기본값) |

| 민준의 말 | 존댓말 기조 | 존댓말 기조 (그녀만 반말 — 도도함의 비대칭) |
| 시험 | 그녀를 **수단으로 쓰지 않을 수 있는가** | 그녀의 세계에 맞추다 **자기를 잃지 않을 수 있는가** |

## 2. 진행 구조

- **상호배타**: `daeun_romance_started` ↔ `jiyeon_romance_started`. 한쪽 시작 시 다른 쪽 Y5 고백(arc_*_y5_feelings) 게이트가 닫힌다 (MainGame `_next_arc_id` 조건).
- **조기 연애 가능**: Y2부터 플레이어 선택으로 시작 가능 (다은 confession 등). Y5 게이트 단일화 아님.
- **다은 라인**: 편의점 만남(t9)→단골→꿈 이야기→갈림길(t23)→…→고백/연애→**프로포즈(t150+)**→약혼 후 아크(`arc_daeun_married.json`): 우리 집의 의미(t155)→상견례(t168, father_passed 시 스킵)→스드메(t175, 소박 vs 과시)→결혼식(t200, 신랑석=5년간 사람에게 쓴 시간의 결산)→**상철의 시험(t182**, 아내를 서류로 쓰라는 제안)→**최종 선택(t228, 자산 18억~30억 미달 시에만**: 배신→`daeun_divorced`+crossed_line / 거부→`chose_daeun`). 정직하게 30억 도달한 기혼자는 최종 선택 없이 따뜻한 진엔딩.
- **지연 라인**: 재회→진짜 이유(내 거 하나)→부산 독립(Y3)→Y4 서울 방문→Y5 귀환/고백→결혼: **처가 눈높이 결혼식(t205**, 빚내서 맞춤 vs 형편대로)→**심판(t228, 자산 5억 미만 시에만**: "오빠가 이렇게 살 사람인 줄 몰랐어" — 붙잡음=`jiyeon_kept_by_diminishing`+crossed_line(자기를 잃음) / 보냄=`jiyeon_left`(자기를 지킴)).
- **이혼의 거울상**: 다은은 **그녀를 배신하면** 잃고, 지연은 **자기답게 살면** 잃는다. 어느 쪽도 트로피가 아니다.

## 3. 엔딩 라우팅 (finish_run 캐스케이드 순서가 정본)

- **30억 도달 시**: daeun_divorced→`lonely_rich` → daeun_married→`gangnam_dream`(진엔딩 변주) → jiyeon_romance_started(not left)→`gangnam_dream`(그녀 세계 진입 변주) → 이후 crossed_line→jaehyuk_way. **배우자 실이 crossed_line보다 먼저다.**
- **age>=38 시**: daeun_divorced→lonely_rich / jiyeon_left→ordinary_life / with_daeun / jiyeon_man(kept_by_diminishing이면 공허 변주).
- 엔딩 dik 변주: gangnam_dream[`used_daeun_as_means`(실금)>daeun_married>jiyeon_romance_started], lonely_rich[daeun_divorced], with_daeun[daeun_married], jiyeon_man[jiyeon_kept_by_diminishing], ordinary_life[jiyeon_left]. **순서 주의 — 배우자 변주가 항상-매치 키보다 앞.**

## 4. 한국 결혼 문화 = 돈 vs 사람 결정

스드메·예단·하객·청첩장·신혼여행은 장식이 아니라 **강남 자금과 경쟁하는 지출 선택**으로 구현한다. 민준의 텅 빈 신랑석(하객 없음)은 5년간 사람에게 쓴 시간의 결산 — `hyunsu_reconnected` 등 관계 플래그가 하객 dik로 회수된다.

## 5. 성인 콘텐츠 정책

본편=존엄 페이드아웃(성숙하되 명시 없음). 성인 patch slot은 구조만 — Claude는 tasteful 버전만 작성.

## 6. 작성 규칙 (신규 로맨스 콘텐츠 체크리스트)

1. 호칭/스피치 표를 지켰는가 (다은 존댓말·민준씨 / 지연 연애 후 반말·오빠)
2. 새 플래그에 독자(조건/dik/코드)가 있는가 (write-only 0 래칫)
3. 이미 심어진 실(계란말이·카페 약속·시골 어머니·부산 엽서·아버지 공장)을 **회수**하는가 — 발명보다 회수
4. 상호배타 게이트를 건드렸으면 `arc_flow_sim.py` 실행
5. KR+EN 동시 작성, 엔딩 dik이면 EN 패리티 키 확인

### 7-A. 특별 스토리 ① 다은 — 「시골의 이틀」 (2연작, Y3 여름 t100~130)

- **EP2 「어머니의 밥상」 (명장면)**: 시골집 저녁. 어머니는 말없이 밥을 많이 푸고, 민준의 손을 잠깐 본다 — "…고생 많이 한 손이네." 밥상 위 계란말이(심어진 실 회수 — 다은의 계란말이가 어머니의 것이었음이 여기서 무언으로 드러남).

  - **명장면 컷**: 돌아오는 밤 버스, 잠든 다은. 멀어지는 시골 불빛과 다가오는 서울 불빛이 한 창에. 민준 독백: **"30억을 세던 밤들이 있었다. 오늘 처음, 세지 않아도 되는 밤이었다."**

- **발동**: jiyeon_romance_started + 아버지 기록의 진실 국면 이후(`told_jiyeon_about_records` 또는 arc_jiyeon_father_records 후) — 그녀가 흔들린 상태.

### 7-F. 선물하기 — 호감 작업 메커니즘 (유저 지시 2026-07-07)

> 원칙: **가격이 아니라 알아봄.** "비싼 선물=호감"의 환금 공식은 주제(사람을 수단으로 안 봄) 배신 —
> 정답 선물은 그녀의 이야기 속에 심어져 있고, 비싼 오답은 정직한 미지근함으로 돌아온다. 이게 크래프트다.

- **구매**: 상점(생활 카테고리)에 선물 8종 추가(items.json) — 저가(캔커피 세트 8천·양말 1만)/중가(목도리 4만·에세이집 2만·전시 도록 3만)/고가(향수 12만·브랜드 지갑 35만·목걸이 80만).
- **전달**: People 모달의 대상 인물 카드에 "선물하기"(인벤토리에 선물 보유 시) — **1 AP**(만나러 가는 시간), human축 등록 + note_contact. 대상: met + affinity 일정 이상(연애 전 구애 단계부터 가능 — 호감 작업용).
- **반응 테이블 (숨김 — 발견이 콘텐츠)**:
  - **다은**: 실용+마음(목도리·양말·캔커피·에세이집)=명중(+8~10, 전용 대사 "민준씨, 이거 고르는 데 얼마나 서 있었어요?"). 고가 명품=정직한 부담("…이런 거 받으면, 나 뭘 돌려줘야 할지 모르겠어요" +1~2). 
  - **지연**: 이야기 있는 것(전시 도록—그녀가 언급한 전시, 부산 관련 소품)=명중(+8~10, "오빠, 이거 기억하고 있었어?"). 그냥 비싼 것=평범("고마워. …나 이런 거 많아." +2~3, 반말 정본).
  - 명중 힌트는 데이트/아크 대사에 심는다(도록=지연 전시 언급, 목도리=다은 야간 근무 추위) — **정답을 시스템이 알려주지 않는다.**
- **남용 방지**: 인물당 선물 쿨다운 4주(연속 선물엔 "…또요?" 계열 정직 반응 +0). 같은 아이템 반복 명중 없음(첫 회만 전용 대사).
- **명중 기록**: `flags["gift_hits_<pid>"]` 카운트(코드 독자: 프로포즈/고백 dik 변주 "그동안 알아봐 준 사람" + 리캡 후보) — write-only 금지 규율 준수.
- 구현 순서: 데이트 AP(진행 중) → **선물하기**(items.json+상점+People 모달) → 특별 스토리 2종 → 계절 스페셜.

### 7-H. 히든 중의 히든 — 히로인당 1개 (2026-07-07 유저 지시)

> 조건: 우연히는 절대 못 보고, 커뮤니티가 발굴해 공유해야 하는 깊이. 스포일러 방지를 위해 **게임 내 어떤 힌트도 주지 않는다** (업적명도 발동 후에만 공개되는 히든 업적).

**① 다은 — 「새벽의 사람들」 (현실 시간 개입형)**
- **발동**: 플레이어의 **실제 OS 시계가 새벽 0~5시**일 때(`Time.get_time_dict_from_system()`) 다은에게 연락/데이트하면 전용 히든 비네트 풀로 교체.
- 내용: 야간 노동자의 시간을 플레이어가 실제로 살고 있을 때만 열리는 대화 — "민준씨, 지금 몇 신 줄 알아요? …나야 일이지만." / 최심부(새벽 접촉 누적 5회): **"새벽에 깨어 있는 사람들은요, 서로를 알아봐요. 민준씨도 이제 이쪽 사람이네."** — 다은이라는 인물의 본질(새벽의 노동)을 플레이어의 몸으로 체험시키는 장치.
- 발견 시나리오: "새벽 4시에 다은한테 연락해보세요" — 커뮤니티 전파 한 줄이 완성돼 있음.
- 구현: `_ap_date`/`_ap_contact_person`의 다은 분기에서 OS 시간 체크 → 히든 풀 스왑. 누적은 `flags["daeun_dawn_meetings"]` 카운트(코드 독자: 최심부 발동 + 히든 업적).

**② 지연 — 「그녀는 알고 있었다」 (크레딧 후 재독 폭탄형)**
- **발동**: 아버지 기록의 진실을 **끝내 말하지 않고**(not `told_jiyeon_about_records`) 지연과 결혼 상태로 엔딩 도달 → **크레딧이 완전히 끝난 뒤 3초의 암전 후** 무음의 한 컷.
