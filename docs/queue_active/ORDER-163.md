## Foreshadow의 한정된 검사 수리

작성 대상4 leaf:
`arc_jaehyuk_mirror_decision.choices[1].foreshadow`,
`arc_father_ng_call.choices[1].foreshadow`,
`arc_sangchul_confrontation.choices[0].foreshadow`,
`arc_sangchul_ng_meet.choices[0].foreshadow`.

공식 DataRegistry choice overlay는 해당 문자열을 merge하고 MainGame 결과 화면은
이를 읽는다. StoryMode 직접 표시와 외부 언어팩 sanitizer 지원을 이 증거에 섞지 않는다.
`i18n_coverage_check`의 choice text 계약이 필드를 거부하는 것이 실제 막힘이다.
존재한 번역은 같은 원문 choice의 nonblank string에 엄격히 결속한다. 타입/빈칸/
다른 인덱스/없는 원문/추가 gameplay/선택 배열 길이·토큰·source hash 변조를 거부한다.
미작성은 inventory missing으로 남겨, EN과 기존 공개 번역에 새 문장을 강제하지 않는다.
`ja_translation_pipeline.CHOICE_TEXT_FIELDS`를 넓혀 중복 수집하지 않는다.

원문6개의 분모는 그대로다. 나머지 공개 `arc_temptation_01.choices[0/1].foreshadow`
2개는 세 준비 언어에서 미작성이고 이번 수정 소유권 밖이다. 공개 기존6 leaf를
유지하고 잔여에 기록한다. EN6개도 별도 미번역이며 EN bytes는 불변이다.
validator 지원과 번역 채움·실제 화면 GO를 별도로 계측한다.

**2026-09-07 원문 수집기 소유 보강 선언:** `full_body_translation_scope`도
foreshadow를 수집하지 않아 새 정확 receipt를 '지원 원문 없음'으로 거부한다.
그 수집 필드와 정확 원문 계측·fixture를 함께 보강한다. 추가6 leaf/기존 leaf
변경0·삭제0을 입증하고 source snapshot 수치/hash만 실측으로 갱신한다.
공개 target baseline108/100/100·재사용8·그 지문은 변경0이다. 이는 누락된
원문 분모를 복구하는 검사 수리이지 무승인 번역을 허용하는 baseline 완화가 아니다.
