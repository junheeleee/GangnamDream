# Active Queue Spec: ORDER-112

> Canonical status and execution order are indexed in `docs/CODEX_QUEUE.md`.

#### [~] ORDER-112 [P0·서사 원고] 마지막 해의 career 경로를 한 직장·한 문서·한 사람의 비용으로 완주한다

**사용자 지시 (2026-08-18):** “이제 이어서 작업해.” 빈 fallback 수를 늘리는 대신,
현재 실제 삶에서 벌어지는 한 사건이 다음 달의 종이와 사람을 바꾸는 세로줄을 먼저
완성한다. career와 startup을 얕게 병렬화하지 않고 career 한 경로를 처음부터 마지막
주까지 쓴 뒤 startup은 다음 별도 배치가 소유한다.

## 깊이 3문

1. 현재 M49~M60의 기준 원고는 investment/property와 상철·다은에 맞춰져 있다.
   career 원문·현재 상사·직장 검토·self-only 접수·직책 실행 receipt가 없어서,
   broad fallback을 열면 직업 경로에도 부동산 열쇠와 접수번호 227이 붙는다.
2. 이번 경로의 질문은 하나다. 현수의 회계 전문성과 이름을 외부 수치 검토자로 빌려
   발령을 앞당길 것인가, 그 칸을 `NOT USED`로 만들고 발령 지연·책임수당 축소·예산
   축소 중 하나를 민준 자기 이름으로 감수할 것인가. 민서는 환수 상한과 종료일을
   읽는 검토자이고, 현 팀장은 승인 기한을 책임지는 거래 상대다.
3. 신규 16개는 author-only exact reference다. 이번에는 story map·StoryLedger·
   dispatch·`finish_run`을 고치거나 도달 가능하다고 주장하지 않는다. 같은 문서의
   버전과 실제 손실을 산문으로 먼저 끝낸 뒤 routing과 startup, endings를 각각 별도
   배치에서 다룬다.

## 고정 배우·문서·손실

- 구조 actor ID는 `boss`, `minseo`, `hyunsu`다. `team_lead`는 표면 호칭·portrait일
  뿐 actor ID가 아니다. `proposer=counterparty=boss`, `reviewer=minseo`,
  `protected_person=hyunsu`이며 세 사람은 서로 다르다.
- 현재 직업과 현 팀장이 실제로 남은 career-compatible 경로만 이 reference를 쓴다.
  퇴직·창업 exit 뒤 boss를 소환하지 않는다. `partner=none`이며 career의 self-only
  명의는 연애 상태 enum을 바꾸지 않는다.
- C0는 12개월 TF 책임자 부속합의다. 월 책임수당 45만원, 12개월 전에 나가면 회사가
  부담한 교육비 600만원을 돌려줘야 한다는 조항, 외부 수치 검토자 빈칸, 외부 이름을
  넣으면 승인 기간을 15영업일에서 5영업일로 줄인다는 문장을 같은 원문에 둔다.
- C1은 이름을 빼는 대신 회사가 내놓은 세 수정안이다: 발령 10영업일 지연, 월
  책임수당 45만원→30만원, TF 집행 예산 20% 축소. M55에서 셋 중 하나만 C2의 고정
  손실이 된다.
- reference C2는 `external_reviewer=NOT USED`, `self_only`, 월 책임수당 30만원,
  환수 종료일을 가진 미서명 수정본이다. M55는 공개 약속과 수정 지시만 만들고,
  M57 reference 선택이 실제 접수 도장과 document ID를 만든다.
- reference C3는 C2를 실행한 부속합의다. M59 서명과 함께 TF 착수 준비비 30만원이

  물건을 읽을 뿐 배지를 다시 받거나 활성화하지 않는다.

## 장면·선택 원칙

- M55는 “이름을 뺄까”를 접수까지 끝내지 않는다. 세 사람 앞에서 수정 조건과 고정
  손실을 받아들이는 공개 약속이다. M57은 아무도 대신 결정하지 않는 창구에서 그
  약속을 실제 지킬지 배반할지 실행한다.
- 현수는 보호 보너스가 아니라 회계사로서 평판·확인 범위·근무시간을 잃는 당사자다.
  민서는 도덕 해설자가 아니라 숫자와 종료일을 찾는 검토자다. boss는 악당이 아니라
  승인과 기한을 책임지는 사람이다.
- 현수에게 종이를 보여 주는 장면만 반복하지 않는다. M50은 회사에 경계를 긋고,
  M51은 승진 뒤 삶을 묻고, M57은 접수 증거를 건네고, M58은 현수의 판정을 듣고,
  M60은 실제 새 업무를 자기 이름으로 맡은 뒤 연락한다.
- 결과는 현재 확보한 물건, 잃은 돈·시간·신뢰, 열린 질문을 회수한다. 답장·용서·
  승진 성공·해고·건강·엔딩을 보장하지 않는다. 계약을 지켰다는 작가 보고 대신
  빈 칸·도장·전송 시각·접힌 배지·통장 한 줄 같은 물성으로 쓴다.
- KO가 정본이며 EN은 배우·문서 버전·숫자·시간·손실·말투를 그대로 보존한다.
  placeholder는 `{name}`만 사용한다.
