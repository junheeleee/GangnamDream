## 2. 배치 2 — 물성 정본 `docs/SURFACE_MATERIAL.md`

폰트·모서리·여백·전환·타격음을 **취향으로 고르지 않고 원천에서 파생한다.**
원천은 새로 만들지 않는다. 이미 셋이 있다.

| 원천 | 소유 문서 |
|---|---|
| `Gangnam Ink` — 무채색 잉크 필름 | `GANGNAM_INK_ART_DIRECTION.md` |
| 유리 너머의 삶 — 분리와 반사 | `IP_VISUAL_IDENTITY.md` |
| 2013~2015년형 저가 안드로이드 단말 | `CLAUDE.md` 현재 상태, `ORDER-57` |

`SURFACE_MATERIAL.md`는 이 셋에서 화면 물성이 어떻게 나오는지만 적는다.
**파생 관계를 문장으로 설명할 수 없는 표면 결정은 채택하지 않는다.**

### 폰트 3역 분리

한 패밀리로 전부 처리하는 것이 밋밋함의 직접 원인이다. 역할을 셋으로
가르되 **본문은 건드리지 않는다** — 읽힘은 이미 검증됐다.

| 역할 | 방향 | 파생 근거 |
|---|---|---|
| 본문 | Pretendard 유지 | 변경 없음. 가독성 회귀를 만들지 않는다 |
| 제목·화자명·장 카드 | **명조/세리프 계열** | 종이·서류·잉크 = `Gangnam Ink`의 필름 |
| 숫자·날짜·잔고·시세 | **등폭(monospace)** | 화면·단말 = 2013년형 폰. 자릿수가 흔들리지 않는다 |

숫자를 따로 떼는 것이 이 게임에서 특히 중요하다. **돈이 주제인데 잔고가
본문과 같은 얼굴을 하고 있다.**

**[첫 실행 재조정]** 역할을 셋으로 가른다는 것과 각 역할의 파생 근거는
설계 가설이다. 실제 화면에서 세 서체가 같이 놓인 것을 보기 전에는 검증되지
않았다 — 셋이 과할 수도, 명조가 이 톤과 안 맞을 수도 있다. 폰트 1종이라는
진단은 실측이고, 셋이라는 답은 추정이다. 첫 화면이 나오면 재조정한다.

### 라이선스 규율 (사용자 결정에 따른 강제 조건)

- **SIL OFL·CC0 등 임베딩과 재배포가 명시적으로 허용된 것만** 쓴다.
- `무료 상업 이용 가능`과 `폰트 파일 임베딩 가능`은 다르다. **라이선스
  원문에서 embedding·redistribution 조항을 직접 읽고 인용을 남긴다.**
  요약 페이지나 이 오더의 서술을 근거로 삼지 않는다.
- 채택 서체는 `assets/fonts/FONT_LICENSE_LEDGER.md`에 출처 URL, 라이선스
  전문 경로, 버전, 해시를 기록한다. 오디오가 이미 하는 방식과 같다.
- 라이선스를 확정하지 못한 서체는 후보에서 제외한다. **애매하면 쓰지 않는다.**

## 3. 배치 3 — 단일 출처 구현

**이 배치가 실제로 화면을 바꾼다.**

1. `.theme` 리소스를 도입하고 `UIStyle.gd`가 그것을 소유하게 한다.
2. `StyleBoxFlat` 직접 생성 256회를 테마로 흡수한다.
3. 위 `배치 3이 확인할 것`의 이모지 아이콘 id를 자산 아이콘 또는 타이포그래피로 정리한다.
4. 타입 스케일과 여백 스케일을 확정하고 그 밖의 값을 금지한다.

**범위는 데모 화면 우선이다** — 휴대폰 표면, `StoryMode`, `StartMenu`,
`CoreLoopPlanner`. 미니게임 4종은 이 오더에서 열지 않는다. `ORDER-57` E가
진행 중이고 `ORDER-61` 배치 1의 심의 결과가 미니게임 범위를 바꿀 수 있다.

각 화면은 개별 단위다(`WORK_UNIT.md`). 한 커밋에 여러 화면을 섞지 않는다.
