#### [ ] USER-P0N [P0·연출] 데모 장면 연출 문법 240주 전 구간 확산

## 사용자 지시

데모에 구체적으로 적용한 오디오뿐 아니라 장면 전환, 카메라, 날씨와 공간 이펙트,
기억·통화·Moral 연출도 본편 전체에 확산할 작업으로 남긴다. 데모 24주의 통과를
240주 5개 장의 완성으로 간주하지 않는다.

## 목표

화면을 계속 흔들거나 입자를 늘리는 작업이 아니다. 사건의 장소, 시간 경과, 대화
채널, 감정적 중요도와 플레이어 선택을 읽어 필요한 만큼만 움직이는 하나의 연출
문법을 만든다. `ORDER-43`의 장소음·폴리·음악 전환과 같은 장면 경계에서 화면도
함께 바뀌어야 한다.

## 불변 규칙

- `same_location`은 새 장면처럼 와이프하지 않는다. 텍스트·표정·초점만 이어진다.
- `time_cut`, `explicit_move`, `memory_cut`, 전화·영상·메시지, 결과 배경,
  미니게임 진입·복귀, 엔딩은 서로 다른 물리와 시간을 가진다.
- 흰 가로·세로선 스윕, 상시 입자, 과도한 블러·줌·흔들림, 모든 클릭의 플래시는
  금지한다. 연출이 반복되면 장면 정보가 아니라 장식 소음으로 판정한다.
- 비는 아래로 내리고, 눈·안개·불꽃·도시광·반사는 실제 장소와 계절, 카메라 축,
  실내외 조건을 따른다. 배경에 없는 날씨나 광원을 이펙트가 발명하지 않는다.
- MORAL_TINT는 버튼 색 변화가 아니라 사람층, 공간 깊이, 공기, 잔상, 재질과
  카메라의 인식 변화다. 숨은 점수나 선악 판정을 화면에 노출하지 않는다.
- 초상·CG의 얼굴, 손, 시선 목표와 핵심 소품을 전환 레이어나 캡션이 가리지 않는다.
- 모든 연출은 스킵 가능하고 입력을 가두지 않는다. Reduce Motion에서는 정보와
  타이밍을 보존한 정적 페이드·컷으로 대체한다.
- Godot 네이티브 Tween, AnimationPlayer, 셰이더, 입자와 레이어를 우선한다.
  반복 사건을 영상 파일로 덮어 빌드 용량과 로딩을 늘리지 않는다.

## 적용 범위

1. **전환 원장:** 1,565개 사건의 실제 노출 경계를 전환 없음, 같은 장소 연속,
   시간 경과, 명시 이동, 회상, 원격 통신, 활동 진입·복귀, 피날레로 분류한다.
   미분류 전환과 기본 와이프 폴백은 0이어야 한다.
2. **장면 생동감:** 1~5장 배경에 의미 기반 날씨·계절·도시광·공간 깊이, 절제된
   카메라 호흡과 초상 반응을 배치한다. 일반 장면과 정점 장면의 강도를 분리한다.
3. **정점 연출:** 챕터 보스, 아버지, 상철, 재혁, 현수, 다은, 지연의 대표 체인은
   정적, 카메라, 초점, 날씨, 오디오 진입을 링크별로 설계한다. 같은 효과를
   복사해 감정을 대신하지 않는다.
4. **주간 루프:** Quiet/Echo/Decision/Boss, 월말 결산과 주거·직업 변화가
   웹 페이지 교체가 아니라 같은 서울에서 시간이 흐르는 장면으로 이어져야 한다.
5. **활동:** 투자, 카지노, 홀덤, 경마, 직업 미니게임은 진입 시 메인 HUD를 숨기고,
   종료 시 원래 장면·오디오·패드 초점으로 자연스럽게 복귀한다.
6. **엔딩:** 35개 전용 CG는 피날레 페이지와 크레딧으로 넘어갈 때 결말의 여운을
   보존한다. 승리/실패 공용 플래시나 동일한 전환으로 의미를 평준화하지 않는다.

## ORDER-43 결합

화면과 소리는 별도 타이머로 추측하지 않는다. 하나의 장면 추적 결과가 배경 교체,
초상 채널, 전환 종류, 환경음 소유권, 음악 진입 문단과 물리 폴리를 함께 기록한다.
명시 이동에서는 영상과 환경음이 같은 경계에서 크로스페이드하고, 같은 장소
후속에서는 둘 다 재시작하지 않는다.
