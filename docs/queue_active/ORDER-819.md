#### [~] ORDER-819 · 카페 인물 이름표 현지화

부모157/C5. `ImageRegistry.get_person_info`가 이미 조회하는
`카페의 남자` 한 키의 JA/간체/번체 사전과 공식 수용 원장만 소유.
초상·원격 전화의 이름표에서 아직 드러나지 않은 실명·직함을 붙이지 않는다.
같은 카페의 김 부장, 사람 ID·색·채널·입장/선택, KO/EN·공개 데모·저장 불변.
공식 1키×3·바이트 역복원·격리 이름표와 독립 전독.
표준 본편 경로의 실제 플레이·실화면·원어민·출시는 별도. 일회성.
