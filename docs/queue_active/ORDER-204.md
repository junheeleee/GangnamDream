# Active Queue Spec: ORDER-204

> Canonical status and execution order are indexed in `docs/CODEX_QUEUE.md`.

#### [ ] ORDER-204 [P1·큐 신호] 도달 불가능한 L3에 묶인 번역 오더 44건의 종결 규칙을 바꿔 큐가 다시 남은 일을 가리키게 한다

**[ ] 미착수 · 근거는 `DECISIONS.md` 2026-09-08:** 원어민 검수를 받지 않기로
했으므로 “원어민 L3 표본 통과”를 종결 조건으로 둔 오더는 **영원히 닫히지 않는다.**
조건을 바꾸지 않으면 큐가 계속 자란다.

## 판정 증거 (`fe7fe0f` 실측)

| 구분 | 건수 |
|---|---:|
| 활성 큐 행 | 66 |
| **기계 작업 완료·사람 표본만 남음** | **44** |
| 5장 human REJECT 계열 | 4 |
| 선행 대기 | 9 |
| 사용자 GO 대기 | 4 |
| 미착수·기타 | 5 |

- 30일 넘게 방치된 `[~]`는 **0건**이다. 큐는 게을러서 쌓인 게 아니다.
- 66건 중 63건이 `[~]`이고 사람 게이트는 46건 중 1건만 닫혔다. 병목은 작업량이
  아니라 **판정할 사람이 하나**라는 사실이다.
- 44건은 전부 `L1/L2 PASS · L3 OPEN`이다. 그 L3는 JA·zh 원어민 표본이며
  사용자는 해당 언어 원어민이 아니다. **설계상 도달 불가능한 조건이다.**

## 깊이 3문

1. **이걸 지우면 무엇이 깨지는가?** 큐가 신호를 잃는다. 66행 중 44행이 영구
   대기면 실행자는 맨 위부터 읽어도 실제로 할 수 있는 일을 못 찾는다. 5장
   REJECT 수리 같은 진짜 남은 일이 44행 뒤에 묻힌다.
2. **고른 플레이어와 안 고른 플레이어가 뒤에 다른가?** 해당 없음. 이것은 제품이
   아니라 운영 오더다. **번역 품질은 1도 좋아지지 않는다.** 이 오더가 사는 것은
   품질이 아니라 남은 일의 가시성이다. 진척으로 보고하지 않는다.
3. **같은 자리에서 무엇과 경쟁하는가?** 아무것도 아니다. 새 번역 배치와도,
   5장 수리와도 파일이 겹치지 않는다.

## 배치 A — 종결 규칙과 44건 정리

1. **번역·현지화 오더의 종결 조건을 다시 쓴다.** 새 조건은
   `L1/L2 전수 대조 PASS` + `ORDER-203의 미검수 고지가 제품에 있음`이다.
   원어민 표본은 종결 조건에서 뺀다. 규칙의 정본 소유자 한 곳만 갱신하고
   다른 문서에 복사하지 않는다.
2. 새 조건을 만족하는 44건을 `[x]`로 닫고 `docs/queue_archive/`로 내린다.
   `CODEX_QUEUE_L3_PENDING.md`의 해당 행도 함께 비운다.
3. **`ORDER-165`, `ORDER-161` 두 건은 닫지 않는다.** 사양에 L1/L2 통과 근거가
   없어 새 조건을 만족하는지 확인되지 않았다. 근거를 확인한 뒤 닫거나, 남긴다.
4. **`human_gates.json`의 원어민 게이트는 그대로 OPEN이다.** 오더를 닫는 것과
   “검수하지 않았다”는 사실을 지우는 것은 다르다. 게이트를 건드리는 일은
   `ORDER-203`이 소유하며 이 오더는 원장을 수정하지 않는다.
5. 닫는 44건의 목록과 각각의 L1/L2 근거를 아카이브 기록에 남긴다. 나중에
   원어민을 세우면 이 목록이 그대로 검수 대상 목록이 된다.
6. 큐 인덱스의 순번을 다시 연속으로 맞춘다. `CODEX_QUEUE.md` 예산 13,000
   bytes 안에 들어와야 하며, 줄어든 자리를 새 오더로 즉시 채우지 않는다.

## 배치 B — 증거

1. `python3 tools/queue_consistency_check.py`와
   `python3 tools/queue_index_self_test.py`가 통과함을 보인다.
2. 정리 뒤 활성 큐 행 수와 `[~]`·`[ ]` 분포를 적는다. **남은 행이 실제로 할 수
   있는 일만 가리키는지**를 한 줄로 판정한다.
3. `python3 tools/human_gates.py`에서 원어민 게이트 일곱 건이 여전히 OPEN이고
   `done`이 0건 늘었음을 보인다.
4. `python3 tools/context_manifest_check.py`와 `git diff --check`를 통과한다.
   문서만 바뀌므로 전체 감사 대신 `tools/audit_select.py` 표적 감사를 쓴다.

## 하지 않는 것

- 번역 문구를 고치지 않는다. 이 오더는 원고를 한 글자도 만지지 않는다.
- 사람 게이트를 닫거나 삭제하지 않는다.
- 5장 계열·사용자 GO 대기·물리 패드 오더는 손대지 않는다. 그것들은 조건이
  도달 불가능한 게 아니라 **아직 안 한 것**이다.
