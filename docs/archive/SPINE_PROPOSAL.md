# 척추 제안 (Strawman) — "5년 자산 런 + 정석/비정석"

> 2026-06-21. 단계 ②~③ 방향 정렬용 **제안서(strawman)**. 구현/삭제 아님.
> 유저가 "이거다 / 아니다"로 반응하면 그때 실제 작업 착수.
> 역할: 루프/밸런스/서사 = Claude · UI/연출/카지노 메커니즘 = Codex.

## 한 줄 정의
> **"사회가 정한 길로 갈래, 네 방식으로 갈래 — 5년 뒤 통장이 답한다."**
> 5년(240주) 안에 통장 50만원 → 강남 30억. 매주의 배분이 복리로 돌아오는 한국 계급 드라마 + 경제 런.

## 3층 구조

### 1층 — 척추(코어 루프): 5년 자산 런
- **매주 결정:** 한정된 AP·현금을 어디 배분? (투자 / 커리어 / 관계 / 자기계발 / 도박)
- **누적:** 선택이 복리·평판·스탯으로 쌓여 궤적을 만든다.
- **압박축 3개:** (a) 시간 240주 고정 (b) 시장 변동 (c) 건강·정신 = 소모 자원.
- **결산:** 5년 후 자산·정체성으로 엔딩 분기(이미 34개).
- **재미의 출처:** "이번 주 레버리지를 당길까 / 안전하게 갈까"의 매주 긴장. 글 없이도 손이 가는 부분.
- **이미 있는 것:** InvestmentSystem(레버리지/마진콜), 턴/달력, 난이도, 런 테마, NG+, 엔딩 34. → 척추의 ~70%는 구현됨. 없는 건 "런답게 보이고 읽히는" 가시화(주로 UI=Codex)와 루프 밸런스 튜닝(=Claude).

### 2층 — 껍질(정체성/마케팅): 정석 vs 비정석
- 같은 30억도 *어떻게* 갔는가가 다르다: route_orthodox/unorthodox 누적 → 엔딩·인물반응·칭호 분기.
- 현재는 숨은 카운터 → **가시화하면 마케팅 후크가 된다.** (게이지/정체성 라벨은 UI=Codex, 분기 규칙·밸런스는 Claude)
- 한 줄 피치의 근거. 한국 정서(계급·불안·"남들처럼 vs 내 방식")에 직격.

### 3층 — 질감: 스토리/인물
- 이벤트 = 런의 분위기·도덕·기억. 인물(상철/재혁/지연/다은/현수/아버지)은 런에 색을 입힌다.
- **다이어트 기준이 여기서 나온다:** "척추(런의 긴장)에 기여하는가?"
  - 기여 O = 보존 (선택에 스탯/돈/관계 stakes, 핵심 아크, 엔딩 경로)
  - 기여 X = 절단 후보 (순수 무드 필러 157, 저빈도 callback 에코, 중복 비트)

## 이게 풀어주는 것
- **"단순 스토리게임 같다"** → 척추가 경제 런이라 시스템이 주인공이 됨.
- **"무겁고 방대한데 재미없으면?"** → 경제 런은 구조 자체에 긴장. 다이어트로 페이싱 타이트.
- **"공수 대비 안 팔리면?"** → 재활용률 높고, "경제 로그라이크 × 한국 계급 드라마" 조합이 시장에서 신선.
- **다이어트의 목적** → "중복 제거"가 아니라 "척추에 안 붙는 살 제거".

## 필요할 수 있는 "작은 새 요소" 1개 (선택)
- 새 시스템 7개째를 얹지 말 것. 척추를 *증폭*하는 한 가지만:
  - 예) **주간 배분 보드 + 시장/궤적 가시화** — 런의 심장을 보이게. (UI=Codex, 루프/밸런스=Claude)
  - 또는 **"30억까지의 궤적" 게이지** — 매주 내 위치가 보이는 긴장.

## 검증 계획 (단계 ④로 이어짐)
- 전부 갈아엎기 전에 **가장 작은 척추**로 "재밌나?"를 실플레이어 5~10명에게 확인.
- 그 전엔 되돌리기 어려운 대량 삭제/리빌드 금지.
