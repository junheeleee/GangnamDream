# 척추 루프·밸런스 설계서 — "5년 자산 런" (2026-06-21)

> 단계 ③. **루프 설계·밸런스·데이터 = Claude / 가시화 UI·연출 = Codex.**
> 합의된 척추: 경제 5년 런 + 정석/비정석 껍질. 이 문서는 "어떻게 매주를 긴장시킬까"의 설계.
> 구현은 유저 확인 후 가장 작은 조각부터.

## 1. 현재 루프 (코드 기준)
- 매주(턴) AP 2개를 5개 카테고리에 배분: 💼일·커리어 / 📈돈·투자 / 📚자기계발 / 🤝사람·관계 / 🏠생활(무료). (`_render_action_cards`)
- 월말에 시장 갱신(`InvestmentSystem.process_month`)·월급·승진·고정지출.
- 매주 랜덤 이벤트 1개(`get_next_event`) → 다음 주.
- 종료: age≥38(240주) 또는 자산 30억/파산.

## 2. 밸런스 사실 (balance_check 기준)
- 무직 방치: 실패 100% (mental_break).
- 성실 직장(무베팅): 자산 중앙값 **9,615만** — 1억도 못 넘음. **월급만으론 강남 불가.**
- 직장 + 가끔 베팅(25%): 30억 도달 **14.8%**, p90 39억. **리스크를 져야만 강남.**
- → 척추의 핵심 갈등은 이미 데이터에 있다: **"안전하면 1억, 강남 가려면 도박."** 좋은 토대.

## 3. 문제 — 경제 긴장이 묽은 이유
1. **투자가 4분의 1짜리 옵션.** 매주 study/network/rest와 동급으로 묻힘 → "경제 런"인데 경제가 주인공이 아님.
2. **시장이 월 단위로만 움직임.** 주(週)는 평평하게 느껴짐 → 매주의 "지금 살까/팔까" 긴장 없음.
3. **30억까지의 궤적이 안 보임.** 지금 내가 페이스에 맞는지, 뒤처졌는지 매주 체감 안 됨 → "이번 주 한 방?" 압박 미발생.
4. **리스크 결정(레버리지)이 스킬 게이트 + 서브모달 깊숙이** 숨음 → 척추여야 할 결정이 곁가지처럼.

## 4. 설계 — 매주를 긴장시키는 4가지 (Claude 영역)

### (A) 궤적/페이스 시스템 ★최우선·최소위험
- 데이터: 매주 `목표(30억) · 현재자산 · 남은 주 · 필요 복리율(pace)` 계산.
- 상태 도출: **앞섬 / 정상 / 뒤처짐 / 위험** (예: 필요 CAGR이 현실 한계 초과면 "도박 없이는 불가" 경고).
- 효과: "뒤처졌다 → 이번 주 리스크를 질까"의 *매주 결정 압박*을 만든다. 경제 런의 심장.
- 구현: `GameState.get_run_pace()` 순수 로직(테스트 가능). **UI 게이지/카피는 Codex.**

### (B) 주간 시장 맥박
- 월 단위 시장을 *주 단위 신호*로 보강: 매주 "이번 주 시장 분위기"(상승/하락/변동성↑) 표시 + 소폭 주간 틱.
- 효과: 매주 "지금 들어갈까/뺄까"가 살아남. (월말 일괄 정산 → 주간 의사결정)
- 밸런스 주의: 변동성 총량은 유지(월 결산 합이 기존과 같도록 분할). 밴드 재검증 필수.

### (C) 리스크 결정의 전면화
- 레버리지/타이밍을 곁가지에서 *돈·투자 카드의 핵심*으로. "이번 주: 안전 보유 vs 공격 진입"을 명시 프레이밍.
- 밸런스: 도박이 진짜 리스크지만 회복 가능하게(현재 베팅 30억 14.8% 밴드 유지가 기준점).

### (D) 정석/비정석 = 궤적의 *방식* 가시화
- 같은 자산도 "월급·저축으로(정석)" vs "투자·레버리지·도박으로(비정석)" 어떻게 쌓았는지 궤적에 색.
- route_orthodox/unorthodox(이미 존재) → 정체성 라벨·엔딩·인물반응. **한 줄 피치의 근거.**

## 5. Codex 분담 (참고, 여기서 안 만듦)
- 궤적 게이지/30억 진척바, 주간 시장 맥박 시각화, 돈·투자 카드의 리스크 프레이밍 UI, 런 결산 화면.

## 6. 밸런스 가드레일 (불변)
- audit 밴드 유지: 무직 실패 95~100% · 직장 실패 0~2% · 베팅 30억 8~25% · 직장 중앙값 5천~1.5억.
- 모든 루프/수치 변경은 `balance_check.py` 재검증 후 커밋. 의도된 변경이면 BALANCE.md 기록.

## 7. 가장 작은 첫 조각 (제안)
- **(A) 궤적/페이스 순수 로직만 먼저**: `GameState.get_run_pace()` → {target, current, weeks_left, needed_cagr, status}. UI 없이 함수+테스트만. 되돌리기 쉽고, Codex가 바로 게이지로 붙일 수 있음.
- 이게 "재밌나?"의 핵심 — 페이스 압박이 매주 결정을 살리는지 가장 싸게 확인.
