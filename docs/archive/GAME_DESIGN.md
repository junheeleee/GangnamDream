# Gangnam Dream — 게임 설계 바이블

> ⚠️ **[구버전 — 보관용]** 이 문서는 초기 *로그라이크*(20세 시작·65세까지·자산 20억) 설계다.
> 게임은 이후 **인터랙티브 드라마**(33세 백수·38세까지·자산 30억 강남 입성)로 피벗했다.
> **현재 설계 기준은 [`docs/STORY_BIBLE.md`](STORY_BIBLE.md)** 와 `CLAUDE.md` 다. 이 파일은 역사 참고용으로만 본다.

## 1. 게임 정체성 (한 문장)

> 서울 고시원에서 시작해 강남드림을 향해 달리는 동안, 사회가 원하는 길을 따를 것인지 나만의 길을 갈 것인지 — 그 선택이 쌓여 결국 어떤 인생이 됐는지를 보여주는 게임.

이 문장이 흔들리면 게임이 흔들린다. 모든 기능은 이 문장에 기여해야 한다.

---

## 2. 코어 루프

```
월 시작
  │
  ├─ 행동력(AP) 3개 소비
  │     ├─ 📘 정석 루트: 공부/취업/인맥/저축
  │     └─ 🔥 비정석 루트: 투자/부업/연애/자유시간
  │
  ├─ 이벤트 발생 (조건+가중치)
  │     └─ 선택 → 결과 → 플래그 → 다음 달 이벤트에 영향
  │
  ├─ 월 결산
  │     ├─ 수입 - 지출 = 순이익
  │     ├─ 스탯 변화 (스트레스, 건강, 정신력)
  │     └─ 칭호/업적 체크
  │
  └─ 다음 달
        └─ (반복, 65세까지)
```

**한 턴 = 한 달 = 한 줄의 인생.**

---

## 3. 중심 긴장 (Core Tension)

### 정석 루트 vs 비정석 루트

| | 정석 | 비정석 |
|---|---|---|
| 대표 행동 | 공부, 취업, 인맥, 저축 | 투자, 부업, 연애, 자유시간 |
| 단기 효과 | 안정적, 예측 가능 | 변동 크고 리스크 있음 |
| 장기 효과 | 안정 엔딩, 사회적 인정 | 극단적 성공 or 파산 가능 |
| 칭호 | 엘리트 코스, 착실한 청년 | 위험한 몽상가, 이단아 |

**핵심**: 어느 쪽이 "정답"이 아님. 플레이어가 선택하고 결과로 배운다.
**금지**: "정석이 항상 안전하다"는 설계. 정석도 번아웃 위험이 있어야 함.

### 동적 칭호 시스템

- 초상화 패널에 표시되는 **현재 칭호** = 지금 이 인생이 어떤 상태인지 한 줄로
- **수집 칭호(29개)** = 리플레이를 통해 채우는 도감
- 칭호는 플레이어에게 "나 지금 이런 사람이구나"를 느끼게 하는 거울

## 4. 시스템 존재 이유

각 시스템이 "왜 있는가"를 명확히 한다. 이유 없는 시스템은 추가하지 않는다.

| 시스템 | 존재 이유 |
|---|---|
| **스탯** (건강/정신/스트레스) | 무한정 달릴 수 없다는 현실감. 쉬지 않으면 번아웃. |
| **투자 시스템** | 돈이 돈을 버는 구조 + 레버리지 리스크 체험. 강남드림의 실제 경로. |
| **직업 시스템** | 월수입 = 생존의 기반. 직업 없으면 서울에서 버틸 수 없다. |
| **하우징 시스템** | 거주지 = 성공의 시각적 척도 + 매달 받는 압박/보너스 패시브. |
| **관계 시스템** | 서울은 결국 사람. 혼자가 편할 수도 있고, 연인이 버팀목이 될 수도 있다. |
| **이벤트 시스템** | 내 선택이 초래한 결과가 나중에 돌아온다. 서울 생활의 무작위성과 연속성. |
| **루트 시스템** | 행동의 축적이 정체성이 된다. "나는 이런 사람이었구나". |
| **메타 진행** | 반복 플레이 유인. 이번 런에서 못 본 칭호/업적을 다음 런에서. |

## 5. 하우징 단계와 의미

| 단계 | 이름 | 월세 | 의미 |
|---|---|---|---|
| 1 | 고시원 | 40만 | 시작점. 냄새, 소음, 협소함. 스트레스 +2/월 |
| 2 | 원룸 | 60만 | 첫 자립. 작지만 내 공간. 패시브 없음 |
| 3 | 아파트 | 120만 | 중산층 진입. 평판 +1/월 |
| 4 | 강남 아파트 | 200만 | 목표 근처. 스트레스 -1/월, 평판 +2/월 |

이사는 AP 소비 없음 — 돈으로 하는 결정.

## 6. 기능 추가 기준 (Feature Gate)

새 기능을 추가하기 전 이 질문에 YES가 나와야 한다:

> **"이게 없으면 다른 시스템이 재미없어지는가?"**

YES → 추가.
NO → 다음 단계로 미룬다.

추가로 체크:
- 코어 루프 (월→행동→이벤트→결산) 내에 자연스럽게 들어가는가?
- 정석 vs 비정석 긴장을 강화하는가, 아니면 무관한가?
- 게임 정체성 한 문장에 기여하는가?

---

## 7. 절대 하지 않는 것 (Design Boundaries)

설계 논의 결과 명시적으로 배제된 것들. 이걸 다시 제안할 때는 충분한 근거가 있어야 한다.

- ❌ **"엄마 미소 지수"류 단일 도덕 지표** — 너무 직관적, 선택의 무게 감소
- ❌ **이벤트만 계속 늘리는 방향** — 이벤트 숫자가 재미의 원인이 아님
- ❌ **어느 루트가 명백히 유리한 구조** — 정석과 비정석 모두 위험과 보상이 있어야 함
- ❌ **외부 서비스 연동 (소셜, 랭킹 등)** — 단일 플레이어 경험 집중
- ❌ **3D 그래픽, 복잡한 애니메이션** — 텍스트 RPG 정체성 유지

---

## 8. 엔딩 철학

엔딩은 "결과"가 아니라 "거울"이다.

| 엔딩 | 메시지 |
|---|---|
| 강남드림 | 꿈을 이뤘다. 근데 그 다음은? |
| 번아웃 | 너무 열심히 살았다. 쉬는 것도 선택이었다. |
| 평범한 행복 | 평범함도 하나의 성취다. |
| 파산 | 서울은 냉정하다. 다음엔 다르게. |
| 고독한 부자 | 돈은 있지만 비어있다. |

**규칙**: 어떤 엔딩도 "나쁜 플레이"의 결과처럼 보이지 않아야 한다. 다 하나의 이야기다.

---

## 9. 톤 가이드

- **현실적이되 잔인하지 않게** — 서울 생활의 고단함, 하지만 희망도 있음
- **공감 우선** — 플레이어가 "나도 이런 상황이었는데"라고 느껴야 함
- **유머는 건조하게** — 웃기지만 슬픈 유머. 한국 직장인 밈 감성
- **설교하지 않기** — 정석/비정석 어느 쪽도 "맞다"고 하지 않음
