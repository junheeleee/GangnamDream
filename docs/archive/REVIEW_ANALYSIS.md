## 개선 항목 — A. 즉시 구현 가능 (코드/콘텐츠)

### A-1. 관계 감각 강화 ⭐
**문제**: affection/trust 수치가 오를 때 숫자만 변한다. 관계의 "감각"이 없다.  
**해결**: 관계 상호작용 후 인물별 리액션 텍스트 1~2줄 추가.  
예: `지연 호감 +5` → `"지연이 짧게 웃었다. 오랜만에 보는 표정이었다."`  
**구현 위치**: `systems/RelationshipSystem.gd` + `content/events/relationship_events.json`  
**상태**: `[ ]`

---

### A-2. AP 즉각 피드백 강화 ⭐
**문제**: 잘못된 AP 사용의 결과가 10턴 후에야 드러난다. 학습 루프가 너무 길다.  
**해결**: 월말 요약 로그에 이번 달 AP 사용 패턴 코멘트 삽입.  
예: AP 3개 모두 도박 → `"이번 달은 도박장에서 살았다. 스탯은 그대로다."`  
AP 3개 모두 자기계발 → `"꾸준한 한 달이었다. 조금씩 달라지고 있다."`  
**구현 위치**: `scenes/MainGame.gd` — `_advance_month()` 월말 처리 부분  
**상태**: `[ ]`

---

### A-3. 도박 경고 연출 강화
**문제**: addiction 임계값(50/70/90)에 로그만 있고 시각적 경고가 약하다.  
**해결**:
- addiction 50 돌파 → 화면 테두리 붉은 glow 효과 (1회)
- addiction 70 돌파 → "당신은 지금 문제가 생기고 있습니다" 팝업 (닫아야 사라짐)
- addiction 90 → 매달 로딩 시 강제 경고 배너  
**구현 위치**: `autoloads/GameState.gd` `modify_hidden_stat()` + `scenes/MainGame.gd`  
**상태**: `[ ]`

---

### A-4. 금융 용어 툴팁 (10대 접근성)
**문제**: 신용등급, 레버리지, 하우스엣지, 마진콜 등 용어 설명 없음.  
**해결**: 대출 패널, 투자 패널, 카지노 허브에 `?` 버튼 → 용어 설명 모달.  
용어 목록: 신용등급 / 변동금리 / 레버리지 / 마진콜 / 하우스엣지 / 배당률 / 포트폴리오  
**구현 위치**: `scenes/MainGame.gd` 대출 패널 + `scenes/JeongseonCasino.gd`  
**상태**: `[ ]`

---

### A-5. 투자 자산 차별화 표시
**문제**: 18종 자산이 "극고변동성" 같은 레이블 하나로만 구분된다.  
**해결**: 각 자산에 특성 태그 3개 표시.  
예: 비트코인 → `[고변동] [무배당] [시장사이클 민감]`  
    삼성전자 → `[저변동] [배당 0.2%/월] [한국시장 연동]`  
**구현 위치**: `content/assets.json` + `scenes/MainGame.gd` 투자 패널  
**상태**: `[ ]`

---

### A-6. 월말 서사 로그 강화 (루도내러티브 보완)
**문제**: 달이 넘어갈 때 기계적 수치 정산만 있고 서사적 감각이 없다.  
**해결**: 월말마다 현재 상태에 따른 1줄 내레이션 삽입.  
예: 무직 6개월째 → `"여섯 번째 달. 통장 숫자가 계속 줄고 있다."`  
    첫 직장 취업 후 → `"처음으로 월급날이 생겼다."`  
    정신력 30 이하 → `"이 달은 버티는 것만으로도 충분했다."`  
**구현 위치**: `scenes/MainGame.gd` `_advance_month()` + 조건별 텍스트 테이블  
**상태**: `[ ]`

## 개선 항목 — B. 설계 방향 판단 필요

### B-1. 타겟 연령 재설정
**현황**: CLAUDE.md에 "대상: 평균 10대 유저"  
**비평**: 10대에게 33세 백수의 서사는 공감보다 거리감 (윤채은)  
**선택지**:
- (a) 타겟을 20대 후반~30대 초반으로 공식화 → 마케팅/튜토리얼 방향 전환
- (b) 10대 타겟 유지 → 금융 용어 설명 강화(A-4)로 진입 장벽 낮추기
**상태**: `[ ]` (유저 결정 필요)

---

### B-2. S등급 엔딩 다원화
**현황**: 진정한 완성 엔딩이 "강남드림(30억+아버지 화해)" 하나뿐  
**비평**: "30억을 왜 달성해야 하는가"를 게임이 묻지 않는다 (최아영, 오지은)  
**선택지**:
- (a) S등급 유지, 하지만 그 엔딩에서 30억의 의미를 질문하는 대사 추가
- (b) "관계는 완성됐지만 돈은 없는" S등급 경로 추가
**상태**: `[ ]` (유저 결정 필요)

### B-3. 루도내러티브 자각 순간 삽입
**현황**: 관계가 숫자라는 것을 게임이 한 번도 반성적으로 보여주지 않음
