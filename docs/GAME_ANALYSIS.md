## 1. 게임 개요 & 핵심 컨셉

### 한 줄 정의
33세 백수 김민준이 통장 50만원으로 시작해 5년(38세) 안에 자산 30억을 모아 강남에 입성하는 한국 사회 리얼리티 인터랙티브 드라마.

### 장르 포지셔닝
- **형식**: 인터랙티브 드라마 / 비주얼노벨 + 경영 시뮬레이션 하이브리드
- **참조 장르**: Papers Please(압박형 퍼즐), 레이튼 교수(내러티브 주도), Project Highrise(자원 배분)
- **핵심 감정**: 초조함, 공감, 자조적 유머, 가끔의 카타르시스

### 승리 조건과 의미
| 조건 | 값 | 의미 |
|------|----|------|
| 승리 | 총자산 ≥ 30억 | 강남드림 달성 — 계층 이동 |
| 시간 리밋 | 5년 = 60턴 | 38세라는 한국 사회의 심리적 마감선 |
| 파산 | 순자산 ≤ -1억 | 부채 나락 — 회생 불가 |
| 번아웃 | 건강=0 or 정신=0 | 몸과 마음의 붕괴 |

### 설계 철학
강남드림은 "게임"이면서 동시에 "거울"이다. 플레이어는 김민준을 조종하지만 그가 내리는 선택의 무게, 매달 줄어드는 통장, 자연스럽게 소원해지는 관계를 통해 현실을 간접 체험한다. 숫자가 아니라 감각을 파는 게임.

## 2. 턴 루프 & 행동 시스템

### 월별 턴 구조
```
[달 시작]
  ↓ 이야기 이벤트 발생 (1개, 조건 기반 선택)
  ↓ 플레이어 행동 선택 (행동력 소비)
  ↓ [다음 달 버튼]
  ↓ 월간 압박 적용 (건강·정신 감소, 수입·지출 정산)
  ↓ 투자 자산 가격 변동
  ↓ 칭호·엔딩 조건 체크
  ↓ 다음 달 이벤트 큐 결정
[다음 달 시작]
```

### 행동력(AP) 시스템
- **기본 AP**: 3/월 (일부 아이템으로 +1 가능)
- **행동 유형**: 자기계발(독서·운동·명상·재테크), 구직활동, 투자, 인맥, 도박, 부업(아르바이트)
- **설계 의도**: AP 3개라는 제약이 "오늘도 시간이 없다"는 직장인·구직자의 감각을 만든다. 모든 것을 다 할 수 없는 구조가 핵심.

### 집중 행동(month_focus)
- 한 달에 특정 카테고리를 집중 선택 시 관련 이벤트 출현 확률 ×1.25 부스트
- 플레이어의 월간 전략에 서사적 의미 부여

### 행동 vs. 이벤트의 비대칭
- 행동: 플레이어가 능동적으로 선택, 작지만 확실한 효과
- 이벤트: 랜덤(조건부) 발생, 크고 예측 불가한 효과
- 이 비대칭이 "준비했는데 운이 없다"는 현실감을 만든다

## 3. 스탯 시스템

### 플레이어 스탯 목록

| 스탯 | 초기값 | 방향 | 역할 |
|------|--------|------|------|
| 건강(Health) | 65 | 높을수록 좋음 | 0이 되면 과로 엔딩 |
| 정신력(Mental) | 60 | 높을수록 좋음 | 0이 되면 정신붕괴 엔딩 |
| 지력(Intelligence) | 55 | 높을수록 좋음 | 직업 진입 장벽, 이벤트 분기 |
| 사교력(Social Skill) | 45 | 높을수록 좋음 | 관계 이벤트, 일부 직업 요건 |
| 외모(Appearance) | 50 | 높을수록 좋음 | 연애 이벤트, 일부 직업 요건 |
| 투자감각(Investment Skill) | 15 | 높을수록 좋음 | 투자 수수료 감소, 이벤트 분기 |
| 운(Luck) | 45 | 높을수록 좋음 | 베팅 성공률, 랜덤 이벤트 가중치 |
| 평판(Reputation) | 5 | 숨겨진 | 창업·연애 이벤트 조건 |

### 단일 심리 스탯으로의 통합
초기 설계는 정신력(Mental) + 스트레스(Stress) 이원 구조였으나, 둘이 사실상 같은 것을 반대 방향에서 측정한다는 문제를 발견. 리팩토링을 통해 스트레스를 정신력에 완전 흡수:
- 이벤트 `stress: +N` → 즉시 `mental: -N` 변환
- 월별 반복 압박은 50% 비율 변환 (거주·연인 패시브 등)
- 스트레스 임계별 cascade 로직 완전 제거
- 결과: 플레이어가 전략을 짤 수 있는 단일 심리 지표

### 스탯 임계값 시스템
특정 스탯이 처음으로 특정 값에 도달하면 새 콘텐츠가 해금된다:
- 지력 60+ → 고급 직업 접근
- 투자감각 50+ → 레버리지 투자 해금
- 운 70+ → 레어 이벤트 가중치 증가
- 중독 성향 70+ → 매달 정신 추가 잠식

## 4. 이벤트 시스템

### 규모
전체 이벤트 파일: **868개+** (50여 개 JSON 파일 합산)

주요 파일 구분:
| 파일 | 개수 | 성격 |
|------|------|------|
| life_events.json | 91개 | 일상 생활 이벤트 (한국 청년 현실) |
| relationship_events.json | 54개 | 인물 관계 이벤트 |
| investment_events.json | 43개 | 투자·시장 이벤트 |
| arc_events.json | 41개 | 주요 스토리 아크 |
| drama_events.json | 39개 | 드라마 연출 이벤트 |
| hidden_events.json | 23개 | 숨겨진 조건부 이벤트 |
| 각종 callback_events | 각 12~23개 | 선택 연쇄 이벤트 |

### 카테고리 분포 (주요)
- **사회(social)**: 최다 — 한국적 인간관계, 눈치, 비교 문화
- **직업(jobs)**: 취업·야근·퇴직·승진 현실
- **가족(family)**: 부모님과의 긴장, 기대, 화해
- **재정(finance)**: 월세·통장·카드값·청약
- **투자(investment)**: 시장 뉴스, 기회, 폭락
- **도박(gambling)**: 한강 카지노·홀덤·경마 사후 이벤트

### 희귀도 설계 철학
- **Common (43%)**: 일상의 반복성. 플레이어가 당연하게 여기는 것들
- **Uncommon (25%)**: 선택의 갈림길. 실질적 분기점
- **Rare (9%)**: 인생의 전환점. 멘토 만남, 건강 위기, 강남 꿈
- **Legendary (3%)**: 거의 일어나지 않는 일. 일어났을 때의 충격이 서사적 자산

### 이벤트 조건 시스템
이벤트는 단순 랜덤이 아니라 20여 개 조건의 교차로 출현한다:
- 자산 범위, 스탯 임계값, 직업 유무/티어
- 플래그 (flag/no_flag): 이전 선택의 기억
- 인물 stage: 관계 단계별 이벤트 분기
- 루트 성향(orthodox/unorthodox), 거주 형태, 시장 사이클
- 쿨다운: 같은 이벤트 N턴 동안 재출현 방지

### 선택의 기억 (Flag 시스템)
각 이벤트 선택지는 `flags` 배열로 플래그를 설정하고, 이후 이벤트의 조건에서 `flag`/`no_flag`로 참조된다. "N달 전 선택이 오늘을 바꾼다"는 설계. 예:
- 선배에게 하소연 → 4달 후 선배가 인생 조언 이벤트로 복귀
- 투자 자랑 → 동료가 조언 요청 이벤트 → 조언 실패 시 관계 손상

## 5. 경제 & 자산 흐름

### 월간 현금 흐름 구조
```
[수입]
  월급(직업별 상이) + 투자 배당 + 부업 수익
  - 주거비(고정 지출)
  - 대출 이자(변동)
  - 이벤트 지출
= 순 현금 변화
```

### 주거 단계별 경제

| 주거 | 월 고정지출 | 패시브 효과 | 진입 자금 기준 |
|------|------------|-----------|--------------|
| 고시원 | 65만원 | 정신 -1/월 | (시작) |
| 원룸 | 110만원 | 없음 | 800만원 자산 |
| 빌라 전세 | 90만원 | 정신 +1/월 | 4,000만원 |
| 아파트 전세 | 130만원 | 평판 +1/월 | 1.3억원 |

### 대출 시스템
신용등급(1~10등급)이 한도·금리를 결정하는 변동금리 구조:
- **1금융권**: 월 0.4~0.88% 이자, 소득 6~18배 한도, 7등급 이내만 가능
- **2금융권**: 월 1.28~2.0% 이자, 1,000만~4,600만 한도
- 신용등급 산정: 직업 보유 여부, 근속 개월, 소득 수준, 자산, 부채 종합

### 무직의 경제적 압박
무직 시 매달:
- 수입 0원, 고정지출 65만원+ 계속 나감
- 정신력 -4 추가 압박 (무직 압박 -2 × 2)
- "통장 잔고가 줄어가는 게 느껴진다" 로그
- 30만원 이하 위기 시 정신 -2 추가

→ 무직 방치 시 20턴 내 파산이 시뮬레이션으로 검증됨 (실패율 100%)

## 6. 투자 시스템

### 투자 가능 자산 18종

| 카테고리 | 종목 | 특성 |
|----------|------|------|
| 한국 주식 | 삼성전자·카카오·현대차·KODEX200 | 배당 있음, 월 0.2% |
| 미국 주식 | S&P500·나스닥100·엔비디아·AI반도체 | 높은 변동성 |
| 암호화폐 | 비트코인·이더리움·밈코인 | 극고변동성, 배당 없음 |
| 부동산 | 리츠ETF·강남아파트지분·오피스텔 | 배당 있음, 낮은 변동성 |
| 스타트업 | 친구 시드·AI SAFE | 락업 기간, 고위험 고수익 |
| 레버리지 | 코스피3배·나스닥3배 | 2배 수익·손실 증폭, 마진콜 위험 |

### 가격 변동 알고리즘
```
총변화율 = 사이클 편향 ± 변동성 × 공포지수 편향
         + 랜덤 변동 + 뉴스 영향 + 급락 이벤트 + 0.6% 기본 상승 drift
```
범위 클램프: [-65%, +95%]

### 시장 사이클
- `bear` / `neutral` / `bull` 3단계
- 공포지수(fear_greed) 30 이하 → bear, 70 이상 → bull 전환
- 사이클에 따라 자산별 월간 편향 적용

### 레버리지와 마진콜
- **레버리지 매수**: 1.5% 추가 수수료, 2배 수익/손실
- **마진콜 조건**: 포지션 가치가 원금의 35% 이하로 하락
- **마진콜 결과**: 강제청산 → 원금의 15% 추가 손실 + 정신력 타격
- **설계 의도**: 레버리지는 "빠른 강남 입성"의 지름길이자 "순식간에 파산"의 지름길. 위험 감수의 도덕적 선택.

### 스트레스 → 정신력 투자 페널티
고위험 포지션 보유 시 정신력이 낮으면 거래 수수료가 추가 부과된다:
`수수료 추가 = (75 - mental) / 250` (정신력 75 미만일 때)
→ "불안할수록 더 많이 잃는다"는 리얼리즘

## 8. 미니게임 시스템

### 한강 카지노 (5종 카지노 허브)

**허브 설계 원칙**: 각 게임은 독립 판매 가능 수준의 완성도. 강원랜드라는 실명 대신 "한강 카지노"라는 허구 이름 사용 (상표권 회피).

| 게임 | 핵심 메커니즘 | 하우스엣지 |
|------|--------------|----------|
| 바카라 | 뱅커/플레이어 베팅, 6덱 슈, 로드맵 | 1.06% |
| 블랙잭 | 기본전략 힌트 내장, 더블다운·스플릿 | ~0.5% |
| 슬롯머신 | 3릴, RTP 90%, 777=200배 잭팟 | 10% |
| 룰렛 | 유럽식 0~36, 10가지 베팅 타입 | 2.70% |
| 빅휠 | 54칸 6구역, 조커 45:1 | 11~22% |

**세션 손익 추적**: 방문 시 잔액 기록 → 퇴장 시 세션 P&L 표시 (녹색/빨강)

**사후 이벤트 연동**:
- 50만원 이상 손실 후 퇴장 → `jeongseon_big_loss_bus` 이벤트 (귀가 버스 성찰)
- 100만원 이상 수익 후 퇴장 → `jeongseon_big_win_urge` 이벤트 (재방문 충동)
- 방문마다 `addiction_tendency +3`

### 홀덤 클럽

**설계**: 텍사스 홀덤 5단계 (PREFLOP→FLOP→TURN→RIVER→SHOWDOWN)
- AI 상대방 3명 (Tight/Aggressive/Bluffer 유형)
- 팟 오즈 힌트 표시
- 패 강도 자동 평가 (원페어/투페어/스트레이트 등)
- 연출: 딜 애니메이션, 커뮤니티 카드 순차 공개, 팟 칩 버스트

### 경마 (RaceTrack)

**설계**: 8마리 말, 배당률 역산 기반 베팅
- 3-2-1 카운트다운 → 경주 시작
- 실시간 위치 업데이트 + 선두 교체 실況 중계 ("○번마가 앞서 나갑니다!")
- 결승선 효과: 플래시 + 흔들림 + 수익/손실 배너
- 말 그래픽: 8프레임 아틀라스 스프라이트 애니메이션

### 스캘핑 게임 (ScalpingGame)

**설계**: 제한시간 60초 단타 투자 시뮬
- 실시간 캔들차트 (1초 갱신)
- 매수/매도 마커 차트 위 표시
- 타이머 색상 긴장감: 파랑(>20s) → 노랑(≤20s) → 빨강(≤10s) + 펄스 효과
- 수익률 실시간 표시, 최종 손익 배너

### 트레이딩 플로어 (TradingFloor)

**설계**: 중장기 투자 UI — 종목 선택, 주문 체결, 포트폴리오 관리
- 평단가선 차트 오버레이
- 체결 순간 플래시 효과
- 투자감각 스탯과 연동 (높을수록 수수료 감소)

## 9. 인물 & 관계 시스템

### 핵심 인물 5인

| 인물 | 역할 | 아크 단계 수 | 최종 형태 |
|------|------|------------|---------|
| 지연(Jiyeon) | 직장 선배 / 연인 후보 | 19단계 | honest_together |
| 다은(Daeun) | 첫사랑 / 연인 후보 | 12단계 | uncertain |
| 상철(Sangchul) | 멘토 투자자 | 8단계 | strained |
| 재혁(Jaehyuk) | 친구 / 공모자 | 15단계 | partner_in_crime |
| 아버지(Father) | 가족 / 화해 대상 | 9단계 | connected |

### 관계 수치 구조
각 관계는 `affection`(친밀도)과 `trust`(신뢰) 두 수치로 관리:
- 매월 자동 감소: -1/월 (능동적 상호작용 없으면 소멸)
- 연인 관계 + 외모 60+: 감소 면제
- 소멸 조건: affection ≤ 0 OR (affection ≤ 5 AND trust ≤ 10)

### 관계 유형별 패시브 효과 (affection ≥ 45 시 활성화)

| 유형 | 조건 | 월간 혜택 |
|------|------|---------|
| 연인(romantic) | affection 80+ | 정신 +2, 월 10만원 분담 (15% 확률) |
| 멘토(mentor) | affection 75+, trust 60+ | 투자감각 +1, 지력 +1 |
| 비즈니스(business) | affection 75+, trust 70+ | 평판 +2, 월 15만원 수익 |
| 가족(family) | affection 70+ | 정신 +2, 돈 50만 이하 시 30만원 지원 |
| 친구(friends) | affection 70+ | 30% 확률 사교력 +1 |

### 설계 포인트
관계는 "자동으로 좋아지지 않는다". 매달 감소하는 구조는 "서울에서는 신경 쓰지 않으면 다 멀어진다"는 현실을 게임 메커니즘으로 표현한다. 돈을 버는 데 집중하면 관계가 희생되고, 관계를 챙기면 AP를 쓰게 된다.

- `정석의 정점` — 직장 루트 최고 달성
- `아웃사이더의 승리` — 비정석 루트 중간 성공

- `건강한 은퇴` — 건강 지키며 살았다는 위안
- `공허한 성공` — 성공했지만 의미를 잃음

- 해당 카테고리 이벤트 출현 가중치 ×1.5 부스트
- "이번 런은 도박+투자 테마" → 한강 카지노 이벤트 더 자주 출현

### 재플레이 동기 구조
1. **엔딩 수집**: 18개 엔딩을 모두 보려면 최소 5~6런 필요
2. **인물 아크**: 각 인물의 전체 스테이지를 완주하려면 집중 공략 필요
3. **칭호 수집**: 서로 배타적인 칭호 존재 (정석/비정석, 고독/관계 등)
4. **난이도 도전**: 드라마→현실→지옥고 순서의 자연스러운 계층
5. **시작 프로필**: 백수/알바/직장인/유튜버/코인폐인 — 각각 다른 오프닝

## 12. 밸런스 & 난이도 설계

### 시뮬레이션 밸런스 밴드

1,200런 × 3가지 전략으로 자동 검증 (tools/balance_check.py):

| 시나리오 | 결과 | 허용 밴드 | 판정 |
|----------|------|----------|------|
| ① 무직 방치 | 실패율 100% | 95~100% | ✅ |
| ② 성실 직장 (무베팅) | 실패율 0%, 중앙값 9,615만원 | 0~2%, 5천만~1.5억 | ✅ |
| ③ 직장+25% 베팅 | 30억 도달률 14.8% | 8~25% | ✅ |

→ "성실하면 망하지는 않는다. 하지만 강남은 못 간다. 위험을 감수해야 30억이 열린다."

### 난이도별 경제 차이

| 모드 | 시작 자금 | 월간 정신 압박 | 베팅 성공률 |
|------|---------|--------------|-----------|
| 드라마 | 200만원 | 낮음 | +4%p |
| 현실 | 50만원 | 중간 | 기본 |
| 지옥고 | 30만원 | 높음 | -4%p |

### 중독 성향 피드백 루프
중독 성향이 높아질수록 더 자주 카지노를 찾고, 찾을수록 더 높아지는 정적 피드백:
- 한강 카지노 방문 → addiction +3
- addiction ≥ 50 → 매달 정신 -1 추가
- addiction ≥ 70 → 매달 정신 -4, "딱 한 번만 더" 강박 로그
- addiction ≥ 90 → 코인망령 엔딩 강제 발동

### 대시보드 구조
단일 화면 구성 (씬 전환 없음):

### 연출 시스템
- **플래시 효과**: 수익/손실 이벤트 시 배경 색상 플래시
- **흔들림(Shake)**: 큰 손실 시 화면 진동
- **펄스(Pulse)**: 긴박한 상황 (건강/정신 위험, 레이스 선두 교체) 시 레이블 맥박
- **플로팅 텍스트**: 스탯 변화 수치가 화면 위로 떠오름
- **스크린 플래시**: 선택 결과 피드백 (녹색=좋음, 빨강=나쁨)

### 튜토리얼 설계 원칙
대상: 평균 10대 유저 (게임 문법 이해도가 낮을 수 있음)

- **`maybe_show()`**: 처음 접속 시 1회만 자동 표시
- **`force_show()`**: ❓ 버튼 누를 때마다 재표시
- **슬라이드 형식**: 긴 텍스트 대신 짧은 핵심 슬라이드 3~4장
- **미니게임별 전용 튜토리얼**: 바카라/블랙잭/홀덤/슬롯/룰렛/빅휠/경마/스캘핑 각각
- **메인게임 온보딩**: 3슬라이드 (목표→대시보드→월간 흐름)

각 미니게임 카드에 "❓ 규칙" 버튼 → 언제든 규칙 재확인 가능.

### 접근성 설계
- Pretendard 폰트 — 한국어 가독성 최적화
- 색상 코딩 일관성: 초록=좋음, 빨강=나쁨, 노랑=경고
- 스탯 바: 건강(초록), 정신(파랑) — 색맹 고려 중복 표시(숫자+바)

### 한국 리얼리즘의 구현
강남드림은 한국 청년 세대의 문화 코드를 의도적으로 활용한다:
- **공간**: 고시원, 2호선, 편의점, 학원가, 강남 부동산, 찜질방
- **관계**: 부모의 기대와 간섭, 선후배 문화, 인맥 정치
- **언어**: 카카오 단체방, 치맥, 통잠, 1+1, 자소서, 면접 대기
- **불평등**: 강남 오픈하우스 이벤트 — 18억 아파트를 보지만 살 수 없는 현실

### 자조적 유머 코드
코미디 카테고리 이벤트들은 쓴웃음을 목표로 한다:
- "AI 관상 앱 — 관상: 부자운 없음"
- "퇴사 유튜브 알고리즘이 자꾸 뜬다"
- "SNS에서 동창이 청담동 카페 인증샷을 올렸다"
이 유머들은 고통의 완충재이며 동시에 현실 비판이다.

### 선택의 무게 설계
강남드림의 선택지는 "옳은 선택"이 없도록 설계되어 있다:
- 부모에게 도움을 청하면 정신적 안정을 얻지만 자존심이 무너진다
- 레버리지를 쓰면 강남에 빨리 갈 수 있지만 한 번에 파산할 수 있다
- 연인을 챙기면 행복해지지만 투자/공부 AP가 줄어든다

### 엔딩의 철학
18개 엔딩 중 단 하나만 진정한 "완성"이다 (강남드림: 30억 + 아버지 화해).
나머지는 모두 "어딘가 부족한 승리"이거나 실패다. 이 구조는 의도적이다 — 한국 사회에서 "완전한 성공"이 얼마나 어려운지를 게임 엔딩 분포로 말한다.

> "강남드림은 자기계발서가 아니다. 그 자기계발서가 왜 잘 팔리는지를 보여주는 게임이다."
