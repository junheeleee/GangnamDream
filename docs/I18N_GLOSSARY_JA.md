| 민준 → 아버지 | `父さん` | 동일 | 일본식으로 관계를 재설정하는 `親父` 남발 |
| 직장 | 직급+`さん` 또는 정본 직급 | 동일 | 한국 직급을 임의로 일본 조직도에 재배치 |

### 부끄러움의 문법

- 다은은 솔직한 수줍음이다. 문장을 끝까지 말하되 작은 머뭇거림은 `……`과 호흡으로 표현한다.
- 지연은 도도의 균열이다. 감정을 직접 설명하지 않고 시선, 귀 끝, 멈춘 젓가락, 반 박자 늦은 대답으로 보인다.
- 민준의 내면은 `俺`를 반복하지 않는다. 일본어가 자연스러우면 주어를 생략하고, 자기혐오는 과장된 애니 독백보다 짧은 관찰로 남긴다.
- 한국어 존댓말 차이는 일본어의 です・ます／タメ口로 재현하되, 모든 문장을 기계적으로 `です`로 끝내지 않는다.

## 돈·투자·도박

- 통화는 모든 언어에서 한국 원화다. `円`이나 `¥`로 바꾸지 않는다.
- 50만원=`50万ウォン`, 1억원=`1億ウォン`, 10억원=`10億ウォン`, 30억원=`30億ウォン`.
- 좁은 UI는 런타임 포매터의 `万ウォン／億ウォン`을 그대로 사용한다.
- `자산`=`資産`, `순자산`=`純資産`, `현금`=`現金`, `부채`=`負債`, `수익률`=`収益率`.
- `주식`=`株式`, `코인`=`暗号資産`을 기본으로 하되 인물의 구어에서는 `コイン` 허용.
- `레버리지`=`レバレッジ`, `마진콜`=`マージンコール`, `강제청산`=`強制決済`.
- `배당`은 주식=`配当`, 도박 payout=`払戻倍率／配当`을 문맥에 맞게 구분.
- 바카라=`バカラ`, 블랙잭=`ブラックジャック`, 다이사이=`大小（タイサイ）`, 룰렛=`ルーレット`, 빅휠=`ビッグホイール`, 홀덤=`テキサスホールデム`.

### 문맥 UI ID

기존 한국어 원문 키 2,730개는 삭제하거나 이름을 바꾸지 않는다. 같은 한국어가
서로 다른 뜻으로 쓰이는 28키만 30개 안정 문맥 ID·37호출로 분리한다. 문맥 ID는
`ui_<code>.json`의 다른 행과 같은 최상위 문자열 키이며, 사건 ID나 gameplay key가
아니다. Batch A는 조회 API와 감사 원장만 두고 제품 호출과 일본어 행은 아직
이동하지 않는다. Batch B가 정확한 37곳과 30행을 함께 옮긴다.

- 일본어 문맥 번역은 각 ID의 실제 KO·EN 인자와 소유 함수에서 판정한다. 같은
  한국어의 legacy 번역을 기계적으로 복사하지 않는다.
- legacy 원문에 붙은 exact 번역 규칙은 문맥 행을 덮어쓰거나 거부하지 않는다.
  예를 들어 legacy `도박장`의 `カジノ`와 장소 목록 제목
  `ui.gambling.venues_title`은 서로 다른 번역 단위다.
- 기존 커뮤니티 언어팩은 한국어 키만으로 계속 작동한다. 신형 팩은 같은 flat
  JSON에 문맥 ID를 추가할 수 있으며, 명시 문맥 행이 있을 때만 그 행이 우선한다.
- 자동 감사의 목표는 Batch B 뒤 `legacy 2,730/2,730 + context 30/30`이다.
  키 수 통과는 일본어 문맥·버튼 품사·badge 온도의 사람 판정을 대신하지 않는다.

## 문장·기호 규칙

- 대화는 일본어 괄호 `「……」`, 장면 안 독백은 `（……）`를 우선한다. 원문의 화자 구분이 무너지지 않게 줄바꿈을 보존한다.
- 말줄임표는 `……`, 강한 단절은 `――`. `...`와 `—`를 일본어 본문에 남기지 않는다.
- `{name}`, `{money}`, `{housing}`, `{p}`, `%s`, `%d`, `\n`, BBCode 태그와 숫자 의미를 절대 바꾸지 않는다.
- `MORAL_TINT`, 도덕 점수, 루트 수치는 일본어 UI에도 직접 노출하지 않는다.
- 선택지는 결과를 미리 설교하지 않는다. 원문의 불편함과 모호함을 번역자가 친절하게 해설하지 않는다.
- 원문 문단 수와 감각 비트는 유지한다. 긴 문장을 줄이는 것은 허용하지만 장면 자체를 요약하지 않는다.

## 고유 정서·마케팅

- 강남은 단순 지명이 아니라 부·계급·도착의 상징이다. 첫 노출만 설명하고 이후에는 `カンナム`이라는 고유명사가 그 무게를 갖게 한다.
- 작품의 질문은 답안으로 번역하지 않는다. `같은 길을 오르면서, 같은 사람이 되지 않을 수 있을까`는 `同じ道を上りながら、同じ人間にならずにいられるのか。`를 정본으로 한다.
- `돈을 따라갈수록 무엇이 남는가`처럼 결말을 미리 해설하는 홍보 카피는 금지한다.
- Moral Tint 변화는 선악 게이지가 아니라 민준의 지각과 인간성 붕괴다. 일본어도 `善悪値`, `カルマ`로 명명하지 않는다.
