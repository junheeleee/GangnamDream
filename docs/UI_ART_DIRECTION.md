# 강남드림 UI Art Direction

Updated: 2026-08-21

## 목적

`강남드림`의 이미지 에셋은 이제 배경/포트레이트/CG 레이어 분리와 정합성 기준을 갖췄다. 다음 품질 병목은 UI다. 이 문서는 버튼, HUD, 아이콘, 모달, VN 대화창, 미니게임 화면을 하나의 상업 게임처럼 보이게 만들기 위한 UI 아트 정본이다.

이 문서는 신규 UI/아이콘/이미지 작업의 기준이며, `CLAUDE.md`, `docs/GANGNAM_INK_ART_DIRECTION.md`, `docs/CANON_MAP.md`, `assets/CHARACTER_VISUAL_BIBLE.md`, `docs/ASSET_CONTINUITY_CHECKLIST.md`와 함께 확인한다.

## 비주얼 목표

- 장르 인상: 한국 사회 리얼리티 인터랙티브 드라마 / 비주얼노벨 / 라이프 시뮬레이션.
- 감정 톤: 좁은 고시원, 젖은 아스팔트, 늦은 밤 계좌 화면, 멀리 보이는 강남의 차가운 빛.
- UI 인상: `Gangnam Ink` 무채색 표면. 조용하고 날카로운 도시형 인터페이스. 화려한 카지노 UI나 모바일 캐주얼 UI가 아니다.
- 핵심 원칙: 그림은 감정을 만들고, UI는 판단을 돕는다. UI가 그림보다 시끄러우면 실패다.
- 모럴 축: 시작은 콘크리트 회색, 인간성을 지키면 창백하게 선명해지고, 돈을 위해 무너지면 잉크처럼 검어진다.

## 현재 UI 문제 진단

- 많은 버튼과 HUD가 이모지(`📈`, `💼`, `🛍`, `🏆`, `🃏`, `⚡`)에 의존한다. OS/플랫폼별 렌더가 달라지고 상업 게임보다 프로토타입처럼 보인다.
- `UIStyle.gd`가 있지만 MainGame, StartMenu, StoryMode, 미니게임들이 각각 `StyleBoxFlat`을 직접 만들어 화면 언어가 갈라진다.
- 메인 화면은 정보량이 많아 플레이어가 "이번 달 무엇을 해야 하는지"보다 시스템 목록을 먼저 본다.
- 미니게임 UI가 각각 별도 툴처럼 보인다. 홀덤, 경마, 스캘핑, 알바 시프트가 같은 게임 안의 모드처럼 보여야 한다.
- 시작 화면/스플래시/Steam 키아트의 타이틀 체계가 아직 완전히 통일되지 않았다.

## 팔레트

`Gangnam Ink` 이후 팔레트는 금색/초록/남색 브랜드가 아니라 회색/검정/흰색을 기본 언어로 삼는다. 색은 의미 신호로만 제한한다.

| 용도 | 색 | 사용 |
|---|---|---|
| Concrete base | `#0d0d10` | 전체 배경, 딤 베이스 |
| Panel black | `#111216` | 기본 패널 |
| Panel raised | `#181a20` | 선택/강조 패널 |
| Cold border | `#30343a` | 기본 1px 경계 |
| Text primary | `#e6e8ec` | 본문/주요 수치 |
| Text secondary | `#9aa1a8` | 보조 설명 |
| Text muted | `#5f656b` | 비활성 설명 |
| White clarity | `#f3f7ff` | 인간성 회복, 선명도 |
| Black ink | `#020303` | 자기 붕괴, 표면 burn |
| Black money | `#ffd45a` / `#e4c376` | Deep/Light Black에서 현금·총자산·목표액만 금속성으로 남길 때 |
| Emergency red | `#ff4f5e` | 건강·파산·게임오버급 위급 상황 |

금색/초록/파랑은 브랜드색이 아니다. 카지노 칩, 투자 수익/손실, 위험 같은 좁은 의미 신호로만 허용한다.

## 타이포그래피

- 기본 폰트: Pretendard Regular.
- 강조/버튼/숫자 핵심: Pretendard SemiBold 또는 Bold.
- 화면 제목: 28-34px.
- 섹션 제목: 15-18px.
- 본문: 14-16px. 1280x800/Steam Deck 기준으로 13px 이하는 신규 핵심 UI에 쓰지 않는다.
- VN 대사: 19-21px.
- 배지/보조 정보: 12-13px. 장식·스파크라인 등 비핵심 텍스트만 예외적으로 10-11px 허용.
- 숫자는 오른쪽 정렬을 기본으로 한다.
- 버튼 텍스트는 한 줄을 우선한다. 불가피하게 두 줄일 경우 높이를 고정하고 두 번째 줄은 보조색으로 처리한다.
- 버튼 기본 글자는 15px 이상, 버튼 높이는 46px 이상을 기본으로 한다. 상단 HUD처럼 항상 노출되는 좁은 영역만 14px/40px 압축을 허용한다.

## PC/Steam Deck 공통 가독성

- PC 기본 UI도 Steam Deck 1280x800/7인치 기준으로 먼저 읽혀야 한다.
- 화면이 넓다고 작은 정보를 빽빽하게 노출하지 않는다. 핵심 판단 정보 → 행동 버튼 → 상세 설명 순서로 배치한다.
- 모든 핵심 버튼은 패드 포커스 상태에서 멀리서도 보이는 3px급 금색 테두리를 가진다.
- 패드 UX는 `모든 버튼을 포커스 가능하게 만들기`가 아니라 `화면마다 하나의 명확한 조작 모델을 제공하기`다. 버튼이 12개를 넘는 화면은 탭/모드/커서 구조로 접는다.
- 카지노처럼 베팅 선택지가 많은 화면은 `docs/CONTROLLER_UX_STRATEGY.md`를 따른다. 다이사이/룰렛은 raw button focus rail이 아니라 betting mode 또는 board cursor model이 기본 방향이다.
- 긴 모달은 정보를 모두 펼치기보다 상단 요약 카드와 하단 상세 스크롤로 나눈다.
- 룰렛 숫자 매트, 투자 자산 목록, 상점/관계 리스트처럼 촘촘한 UI는 향후 탭/페이지/확대 선택 모드로 분리하는 것을 기본 방향으로 한다.
- 적용 현황(2026-06-22): 룰렛 숫자 매트는 58×34 버튼과 상태 배지로 확대했고, 투자 자산 목록/상점 목록/우측 정보 패널의 관계·소지품·스토리 탭, AP 세부 카테고리 모달은 카드형 구조로 전환했다. 이후 새 촘촘한 UI도 같은 크기·포커스·카드 기준을 따른다.
- 1280x800 ScreenshotQA에서 상단 HUD, 모달 첫 화면, 선택지, 주요 미니게임의 텍스트 잘림을 반드시 확인한다.
- 영어판은 주 타깃 표면이다. ScreenshotQA는 한국어뿐 아니라 영어 메인 HUD, 영어 행동 모달, 영어 정보 패널을 함께 캡처해야 하며, 로고/날짜/금액/주거명/인물명/로그 라벨이 한국어로 새지 않는지 확인한다.

## 형태와 밀도

- 기본 코너 반경: 6px.
- 큰 모달/대화창: 8-10px.
- 내부 카드 반복 요소: 6px 이하.
- 경계선: 1px 기본. 강조는 left border 3-4px 또는 bottom border 2px로만 사용한다.
- 그림자 사용은 VN 포트레이트/모달 정도로 제한한다.
- UI 카드 안에 또 카드가 들어가는 구조는 피한다.
- 페이지 섹션은 떠 있는 장식 카드가 아니라 명확한 레이아웃 영역이어야 한다.

### 첫 달 약속 선택판

새 저장의 M01~M06은 관리표가 아니라 **한 달 에피소드의 약속을 고르는 장면**으로
보여야 한다. 구 24주 저장의 계획판은 호환 표면으로만 유지하며, 현행 독립
체험판의 시각 정본으로 역수입하지 않는다.

- M01~M05의 세 후보와 M06의 네 후보를 2열 한 화면에 고정한다. 카드 첫 면은
  구체 행동과 짧은 기한만
  읽히고, 출처·종류·상태·효과를 여러 줄 배지로 겹치지 않는다.
- 상세는 포커스/호버한 한 장의 전용 영역에서만 연다. 후보 카드가 동시에 긴
  산문을 펼치거나 카드 안에 상세 카드를 다시 넣지 않는다.
- 선택 순서는 카드 앞의 `중심·함께` 역할과 명도·선 두께 변화로 표시한다.
  첫 번째는 중심, 두 번째는 함께 챙길 약속이며 무지개 카테고리색·금은동·
  좋고 나쁨의 등급처럼 보이면 실패다.
- 진행은 `0/2`, `1/2`, `2/2`와 단일 **이달 시작**만 쓴다. 주차 네 칸,
  루틴 설정, 다중 확인 레일을 이 화면에 축소 복제하지 않는다.
- W3 현수 첫 만남과 W4 고정 위기는 장식 실루엣, 잠긴 카드, 모르는 번호,
  툴팁으로도 선공개하지 않는다. 세계가 끼어든다는 원리만 튜토리얼이 말한다.
- 960×600에서 네 카드·상세·확정이 내부 스크롤 없이 보여야 한다. 1280×800은
  카드 수나 보조 문구를 늘리지 않고 여백과 배경 물성에 쓴다.
- M01~M06 독립 체험판의 후보는 밝은 포스트잇이나 빈 텍스트 박스가 아니라,
  약속이 열 장소·소품·시간 압력을 보여 주는 **무인 장면 이미지**를 전면에 쓴다.
  인물·답장·합격/거절·계약 완료·미래 관계 결과는 선택 전에 그리지 않는다.
- 카드 위 텍스트는 축·마감·구체 행동·미룸/기한만 남기고, 반투명 잉크 띠 위에
  올린다. 별도 inspector나 카드 안의 작은 앱 카드로 되돌리지 않는다.
- 포커스/마우스 호버는 같은 상태다. 표면은 최대 2px만 들리고 장면 이미지는
  1.8% 안에서 천천히 밀려 들어오며, 어두운 잉크막이 걷혀 소품이 선명해진다.
  눌림은 55ms 동안 내용이 정확히 1px 내려간다. `Reduce Motion`에서는 이동과
  확대만 없애고 테두리·명도·눌림 표시는 유지한다.
- 표면은 `Gangnam Ink`의 콘크리트·무광 잉크·실제 서울 공간을 쓴다. 네온
  카테고리색, 밝은 포스트잇, 모바일 앱 타일, 유리광택 패널로 만들지 않고,
  포커스·선택·확정만 제한된 명도와 선 두께로 구분한다.
- W4의 중심 약속 회수는 별도 결과 카드나 팝업이 아니라 기존 장면 본문에
  붙는 한 문단이다. 계획판이 회수 결과를 미리 예고하지 않는다.

### 전체 UI 통일 순서

M01~M06 선택판은 전역 스킨을 한 번에 덮는 작업이 아니라 `Gangnam Ink` 상호작용
문법을 먼저 판정하는 기준 표면이다. 사용자 L3가 이 표면을 승인한 뒤 아래 순서로
옮긴다.

1. 공용 토큰과 컴포넌트: 색·간격·46px 조작 높이·포커스/눌림/Reduce Motion,
   단색 기능 아이콘, 장면 이미지+잉크막 컴포넌트를 `UIStyle`과 선택적 Theme로
   모은다. 스토리 ID나 저장 상태는 시각 컴포넌트가 소유하지 않는다.
2. 첫인상과 서사: Splash, StartMenu, Opening, StoryMode를 같은 타이포·무광
   프레임·장면 전환으로 통일한다.
3. 반복 선택: CoreLoopPlanner, Phone, CommitmentTask, SeoulCycleBoard에
   동일한 장면 카드와 포커스 물성을 적용한다.
4. MainGame은 HUD→행동 카드→모달 순으로 나눠 이관한다. 카지노·미니게임은
   공용 프레임과 입력 상태만 맞추고 고유 테이블 색은 유지한다.
5. 사용자가 이미 승인한 월 마감·회고·완료·엔딩은 마지막에 별도 사람 판정을
   거쳐 토큰만 교체한다. 선택판 작업이 그 레이아웃·문구·계산을 바꾸면 실패다.

모든 텍스트 박스에 배경 그림을 넣지 않는다. 이미지가 플레이어의 장소·사람·행동
판단을 실제로 돕는 선택 표면에만 장면을 쓰고, 저장·설정·영수증·결과 정리 같은
행정 표면은 조용한 무광 패널과 활자 중심으로 남긴다.

## 아이콘 규칙

### 원칙

- UI 버튼과 HUD에서 이모지를 신규 사용하지 않는다.
- 기존 이모지는 단계적으로 `assets/ui/icons/`의 통일 아이콘으로 교체한다.
- 로그/이벤트 텍스트 안에서 감정 표현용 이모지는 임시 허용하지만, 최종 UI 컴포넌트에는 쓰지 않는다.
- 아이콘은 1초 안에 역할이 읽혀야 한다. 한국어를 모르는 유저도 저축/투자/건강/스트레스/관계를 구분해야 한다.

### 스타일

- 어두운 UI 위에서 읽히는 단색 라인 아이콘.
- 기본 stroke: 2px 기준.
- 기본 캔버스: 64x64 또는 SVG viewBox 24x24.
- 모서리와 선 끝은 둥글게 처리한다.
- 채움 아이콘은 돈/위험/성공 같은 핵심 상태에만 제한한다.

### AP 행동 이미지

- HUD, 저장, 뒤로가기처럼 즉시 조작을 뜻하는 요소는 단색 기호를 유지한다. 매주 반복해서 고르는 AP 행동은 기호만으로 축약하지 않고 `Gangnam Ink` 오브젝트 중심 미니 일러스트를 쓴다.
- 주간 대표 카드는 112x84, 하위 행동은 108x56 가로 크롭을 기본으로 하며 사람·글자·로고 없이 한 장면과 2~4개 핵심 소품만 둔다. 작은 사각 아이콘 프레임이 아니라 카드 높이를 쓰는 장면 스트립이어야 하며, 1280x800에서 1초 안에 행동이 읽혀야 한다.
- 대표 의미: 일·커리어=이력서/사원증, 돈·투자=시세 화면, 자기계발=책/노트/운동 도구, 휴식=고시원 창/이불/물컵.
- 같은 그림을 의미가 다른 하위 행동에 반복하지 않는다. 투자·시장분석·부업·절약, 구직·자소서·면접, 독서·운동·명상·투자공부, 경마·홀덤·스캘핑·카지노는 각각 별도 사분면을 소유한다. SVG 기호는 HUD와 작은 기능 조작 또는 진짜 아트 폴백에만 남긴다.
- 미니 일러스트도 `MORAL_TINT` 세계 레이어에 포함한다. Black에서는 탈색과 잉크 손상을 받고 White에서는 원본 색과 재질을 회복하지만, 카드 크기와 포커스 위치는 변하지 않는다.

## 버튼 시스템

### 공통 상태

모든 버튼은 normal, hover, pressed, focus, disabled 상태를 가져야 한다.

- Normal: 어두운 패널 + 얇은 경계.
- Hover: 배경 10-15% 밝게, border 강조.
- Pressed: 배경 10% 어둡게.
- Focus: 금색 또는 파랑 2px 링. 컨트롤러 사용자가 현재 위치를 즉시 알아야 한다.
- Disabled: 색이 죽어야 하지만 텍스트는 읽혀야 한다. 잠금 사유가 있으면 보조 텍스트로 표시한다.

### 버튼 유형

| 유형 | 사용 |
|---|---|
| Primary | 다음 달, 확인, 새 이야기 시작 |
| Secondary | 정보 패널, 저장, 시스템 메뉴 |
| Action | 구직, 투자, 자기계발, 휴식 같은 AP 행동 |
| Danger | 레버리지, 손절, 중독 위험, 삭제 |
| Free | 이사/상점처럼 AP를 쓰지 않는 행동 |
| Modal option | 이벤트 선택지, 세부 행동 선택 |

### 행동 버튼 구조

행동 버튼은 단순 텍스트 줄이 아니라 다음 구조를 가진다.

`[상황 썸네일 또는 기능 아이콘] [행동명] [AP/무료 배지]`
`보조 설명 / 위험 태그 / 해금 조건`

예:

- 구직활동: job icon, AP 1, "수입 0원 탈출".
- 투자: invest icon, AP 1, "매수/매도", locked state if first paycheck not received.
- 휴식: rest icon, AP 1, "스트레스 회복".
- 생활: housing/shop icon, Free badge.

## 메인 HUD

상단 HUD는 다음 우선순위를 따른다.

1. 날짜/남은 시간.
2. 행동력.
3. 위험 바이탈: 건강, 정신, 스트레스.
4. 현금/총자산.
5. 정보/저장/메뉴/다음 달.

돈과 목표 진행도는 항상 숫자와 시각 진행바를 함께 제공한다. 색만으로 상승/하락을 전달하지 않고, `+`, `-`, 화살표, 아이콘을 같이 사용한다.

영어 HUD는 1280x800 폭에서 버튼이 밀리지 않도록 금액 라벨을 압축한다. 예: 한국어는 `현금 350만원 | 자산 730만원`, 영어는 `KRW 3.5M | KRW 7.3M`.

## 메인 화면 정보 위계

메인 화면은 "이번 달 판단"이 중심이다.

- 1순위: 이번 달 상황, 추천 행동, 선택 가능한 직접 행동.
- 2순위: 30억 목표 진행, 월 수입/지출, 건강/정신/스트레스 경고.
- 3순위: 뉴스, 관계, 인벤토리, 로그, 도감.

우측 정보 패널은 보조 정보다. 기본 화면이 우측 패널 없이도 플레이 가능해야 한다.

## VN 대화창

- 배경은 장면의 감정이다. 대화창이 배경을 과하게 가리지 않아야 한다.
- 대화창 뒤는 전체 화면 dim보다 하단 영역 gradient/mask를 우선한다.
- 포트레이트는 "액자 사진"보다 "장면 위에 서 있는 인물"처럼 보여야 한다.
- 이름표는 작고 선명하게. 인물의 사회적 위계가 필요할 때만 색을 다르게 쓴다.
- 선택지는 화면 중앙 하단 위에 띄우되, 배경/포트레이트 얼굴을 가리지 않는다.
- CG 장면은 이미 특정 컷이므로 별도 포트레이트 프레임을 띄우지 않는다.

## 모달과 패널

- 모달 헤더: 제목, 닫기 아이콘, 필요 시 소형 설명.
- 본문: 14px 기준, 과한 줄글은 섹션으로 나눈다.
- CTA 영역: 하단 고정. 확인/취소/위험 버튼은 위치와 색을 일관되게 유지한다.
- 정보 패널 탭은 아이콘+한글 라벨을 쓰되, 이모지가 아닌 통일 아이콘을 쓴다.
- 탭은 선택 상태를 bottom border 2px로 표시한다.

## 토스트/피드백

- 토스트는 짧고 숫자가 먼저 읽혀야 한다.
- 수익/손실/스탯 변화는 색과 부호를 함께 쓴다.
- 같은 순간 여러 토스트가 뜨면 최대 3개만 강조하고 나머지는 로그로 보낸다.
- 중독, 파산, 건강 위기 같은 경고는 일반 토스트보다 더 무거운 경고 모달/비네트로 처리한다.

## 시작 화면과 브랜드

- `SplashScreen`과 `StartMenu`는 같은 키아트/로고 체계를 써야 한다.
- 캐릭터·유리 반사·워드마크의 정본은 `docs/IP_VISUAL_IDENTITY.md`를 따른다.
- 키아트는 textless master를 사용하고, 제목은 로컬 폰트/로고 에셋으로 얹는다.
- 시작 화면은 "강남드림" 브랜드와 50만원/30억/5년이라는 게임 명제를 첫 화면에서 전달해야 한다.
- 첫 상호작용 화면은 포스터다. 저장 슬롯·런 통계·업적 수치는 `이어하기/기록`을 선택한 뒤에만 노출한다.
- `100만원`, `300만원` 같은 레거시 시작 자금 문구는 금지한다. 현재 정본은 통장 50만원이다.

## 미니게임 스킨

### 홀덤

- 실제 Texas Hold'em 테이블처럼 보여야 한다.
- 필요한 에셋: 카드 앞면 52장 또는 카드 렌더 템플릿, 카드 뒷면, 칩 denomination, dealer button, pot area, player seat markers.
- 현재 `card_back.png`는 사용 가능하나, `poker_chip_icon.png`는 중심 문양 정렬 문제로 재생성 전까지 production UI에 쓰지 않는다.
- 카드 앞면을 텍스트 라벨만으로 유지하면 최종 출시 UI로는 부족하다.

### 경마

- 경마장 정보판, 마권, 배당표, 트랙 중계 느낌을 살린다.
- 말 실루엣은 현재 run-cycle용으로는 가능하지만, 최종적으로 말/기수 실루엣 구분성을 늘리는 것이 좋다.
- 정보상/중독 경고는 별도 색과 사운드로 위험하게 보여야 한다.

### 스캘핑

- 금융 터미널처럼 보이되, 초반 일반 투자 배경의 생활 스케일과 섞이면 안 된다.
- 차트는 line chart보다 candle/volume/order hint 구조가 더 설득력 있다.
- BUY/SELL 버튼은 대형, 색상 대비, pressed feedback이 확실해야 한다.

### 알바 시프트

- 텍스트 카드만으로 끝내면 기능은 있지만 장면성이 약하다.
- 편의점, 배달, 사무직 시프트별 작은 배경/아이콘/상황 카드 스킨을 적용한다.
- 선택지는 노동 현장 딜레마가 바로 읽히도록 위험/보상 태그를 붙인다.

## 이미지/배경과 UI의 관계

- 배경 이미지는 UI 뒤 장식이 아니라 서사 정보다. UI가 배경의 핵심 소품을 가리면 안 된다.
- 모든 1280x800 배경은 UI safe zone을 가져야 한다.
- 배경별 metadata 후보:
  - `safe_text_area`: 하단/좌측/우측.
  - `portrait_side`: left/right/none.
  - `dim_strength`: 0.45-0.78.
  - `public_silhouette_ok`: true/false.
- 고시원, 가족집, 병실 같은 private canon 공간은 UI crop QA를 반드시 통과한다.

## 금지 목록

- 신규 UI 버튼/HUD에 이모지를 아이콘으로 쓰기.
- 시작 자금 50만원 정본과 다른 문구 사용.
- 모든 화면을 같은 파란색/보라색 계열로 밀어붙이기.
- 카지노 미니게임처럼 지나치게 번쩍이는 홀덤/경마 UI.
- 포트레이트 안에 배경을 다시 넣기.
- 배경 위에 전경 인물처럼 읽히는 익명 캐릭터를 UI 장식으로 추가하기.
- 버튼 텍스트가 컨테이너 밖으로 넘치는 상태로 방치하기.
- disabled 버튼을 왜 비활성인지 설명 없이 회색 처리만 하기.

## QA 체크리스트

UI 변경 후 아래를 확인한다.

- 모든 버튼에 hover/pressed/focus/disabled 상태가 있는가.
- 컨트롤러 포커스가 현재 선택 위치를 명확히 보여주는가.
- UI에 신규 이모지 아이콘이 들어가지 않았는가.
- 1280x800에서 텍스트가 잘리지 않는가.
- 주요 배경의 인물 얼굴/핵심 소품을 UI가 가리지 않는가.
- 시작 화면, MainGame, StoryMode, 미니게임이 같은 게임처럼 보이는가.
- 돈/손실/위험 정보가 색상 없이도 부호와 아이콘으로 읽히는가.
- 미니게임 UI가 배경/캐릭터 아트의 톤과 충돌하지 않는가.

## 작업 순서

1. 이 문서를 기준으로 `assets/ui/icons/` 통일 아이콘 세트를 만든다.
2. `UIStyle.gd`를 버튼/패널/탭/토스트/배지 컴포넌트 정본으로 확장한다.
3. StartMenu와 SplashScreen의 브랜드/시작 자금 문구를 정렬한다.

6. HoldemClub 카드/칩/테이블 UI를 실제 홀덤 스킨으로 교체한다.
7. RaceTrack, ScalpingGame, ArubaGame을 같은 UI 언어의 전용 스킨으로 정리한다.
8. UI screenshot QA 시트를 만들어 전체 화면을 한 번에 비교한다.
