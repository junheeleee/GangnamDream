> **성격: 논의 문서. 큐 오더가 아니다.** 사용자가 "큐에 넣지 말고 정리만"을 지시했다.

## 0. 이 문서를 만든 이유

사용자 정상 플레이 판정(2026-07-26)이 코어 루프 NO-GO를 냈다. 사용자는 방향을 던졌고
**"쭉 작업해온 Codex의 의견"**을 요청했다.

**Codex는 이미 답을 행동으로 냈다** — `ORDER-57`을 착수해 `docs/CORE_LOOP_V2.md`(290줄)와
`content/meta/demo_core_loop_v2.json` 계약을 만들었고, `CLAUDE.md` 상품 정의까지
"이번 달 누구에게 시간을 쓰고, 무엇을 놓칠지 정한다"로 바꿨다.

동시에 Claude 워크숍이 독립적으로 같은 문제를 설계했다. **결론: 두 설계는 경쟁하지 않는다.**
워크숍이 v2의 데이터 계약(`foreground_slots_per_month: 4` 등)을 그대로 승계하고 그 위의 빈칸을
채웠다.

## 1. 진단 — 계측이 확인한 것

| 사실 | 수치 | 의미 |
|---|---|---|
| 입력 있는 주 | **52/240 (21.7%)** | 167주는 화면조차 만들지 않는다 |
| 주당 확정 결정 | **0.22회** | 사건 포함해도 1.14회 |
| 고를 수 있는 동사 | **9개** | 화면에는 항상 3개만. 어느 3개인지는 디렉터가 결정 |
| 도달 불가 UI | **약 1,056줄** | 데이트·선물·인물 지목 연락·인맥·이사가 한영 완역·패드 대응 상태로 **꺼져 있다** |
| 관계 수치 축 | **1개**(affinity) | 신뢰·이해도 없음 |
| 관계가 여는 콘텐츠 | `cast_stage` 5건 / `min_cast_affinity` 3건 | 반면 `min_turn` **1,322건**. 콘텐츠는 관계가 아니라 달력이 연다 |
| 플레이어 자발 동사 | **0개** | 상태를 바꾸는 자발적 행동이 하나도 없다 |

**결정적 세 가지.**

① **AP 배분 시스템은 이미 꺼져 있었다.** `_demo_pressure_enabled()`가 240주 전 구간에서 항상
true라, 문서가 말하는 "AP 2 배분"은 실제 플레이에 존재하지 않는다.

② **연애의 동사가 빌드에 물리적으로 없다.** "연애 서사가 없다"의 원인은 산문이 아니라
**데이트·선물·인물 지목 연락이 도달 불가 코드**라는 것이다. 남은 관계 동사는 `contact` 하나이고
**상대까지 `_closest_person()`이 정한다.**

③ **"공략감 없음"의 수학.** `contact` 호감 +4 고정, 이벤트 중앙값 +5, 초반 관문 8·12·25 →
**2~3회 상호작용으로 통과**한다.

## 2. Codex 설계(CORE_LOOP_V2)가 정한 것 — 방향 확정

Claude 판정: **이 방향이 맞다.** 사용자 판정에 정확히 대응하는 넷:

- **월간 네 약속 + 배경 루틴** — 매주 AP 허브를 다시 열지 않는다. "계획"이 처음 존재한다.
- **약속의 5조건** — 구체적 사람·장소·기한, 실제 장면 이동, 놓쳤을 때 달라지는 것, 회수,
  미래 비해설. `휴식한다`는 약속이 아니고 `금요일 면접을 준비한다`가 약속이다.
  **이 한 절이 "AP가 얕다"의 정확한 처방이다.**
- **관계 11단계 비트** + "호감도만으로 단계를 넘지 않는다" + "반복 전화·선물 파밍 불가"
  — "내가 꼬셨다는 느낌이 없다"에 대한 직답.
- **동시 추적 주요 인물 최대 2, 같은 달 등장 최대 4** — "인물이 연달아 나온다"에 대한 직답.

추가로 좋은 판단 둘: **30억 조기 달성 = 결과 국면 전환**(1년 만에 30억 플레이 수용),
**해금 미니게임의 메인 메뉴 라운지 자유 플레이**(도박만 즐기기를 경제 붕괴 없이 수용).

## 3. 워크숍이 더한 것 — v2가 비워 둔 칸

### ① 단일 시간 화폐 "블록"
**주 5블록 × 4주 = 월 20칸.** AP·슬롯·폰 시간·도박 시간이라는 별개 화폐를 없앤다.

| 등급 | 비용 | 무엇 |
|---|---|---|
| **T0 열람** | 0블록 무제한 | 폰 열람, 시세·뉴스, 도박 규칙, 라운지. **관계 수치를 한 점도 생산하지 않는다** |
| **TM 메시지** | 0블록, **주 3회** | 먼저 연락. 호감 +1, 취향·일정 probe, 다음 달 제안 만들기. **신뢰 0, 상처·비밀 불가** |
| **T1 루틴** | 1블록 | 비네트 효과만. 전용 장면 없음 |
| **T2 약속** | 2블록, **월 4개** | 실제 장면·미니게임으로 가는 유일한 등급. v2 전경 슬롯 4와 **같은 것** |

**가장 중요한 한 줄: 폰은 시간을 쓰지 않고 의도를 쓴다. 폰에서 시작한 것은 격자에서만 끝난다.**
먼저 다가가기는 공짜에 가깝고(주도권 회복), 깊은 층은 2블록을 요구한다(파밍 차단).

### ② 관계 3축 + 이해도 probe
v2의 11비트가 **사다리**라면 이건 **계단을 오르는 화폐**다.
- **호감/신뢰/이해도** 3축. 이해도는 63개 `fact`(taste 1·routine 1·wound 2·secret 3).
- **폰으로는 취향·일정까지만.** 상처·비밀은 **T2 대면 안에서만** 열리고 선행 조건이 있다
  → **폰만으로는 깊은 이해도에 절대 도달할 수 없다.**
- **호감 캡은 플레이어 행동에만**, 이벤트는 신뢰를 거의 주지 않는다
  → **편성기가 주는 것만으로는 어떤 인물도 `reciprocal` 이상에 도달할 수 없다.**

### ③ 기존 편성과의 접속 — 버리지 않는다
- **52주** → 그 주에 T2를 **미리 배치한 상태로** 격자를 연다. 뺄 수 없지만 *어디에 둘지*와
  *무엇을 포기할지*를 고른다. **아크의 기회비용이 처음 화면에 보인다.**
- **Echo 21회** → 0블록 콜드오픈으로 강등, 횟수 불변.
- **Quiet** → 편성 결정이 아니라 **계획의 창발 속성**. T2 없는 주는 자동 몽타주.
- **1,565사건 JSON은 고치지 않는다.** 제안 생성기가 바깥에서 감싼다(저장 호환).

## 6. 정직한 산수 — "플레이타임 10배"

**이 설계 단독으로는 10배를 주지 못한다. 흐리지 않는다.**
- 실질 결정 52회 → 300~480회(계획) + 최대 240회(약속 배치) = **6~9배**
- 그러나 **체감 플레이타임은 약 2.5~3배**(~5시간 → 13~15시간)
- 나머지는 기둥②(63 fact × probe 분기 = 런마다 다르게 아는 재조합)와 ③(주도권이 만드는
  재플레이 동기)가 만든다.
- **콘텐츠 10배(15,000사건)는 프로젝트를 죽이고, 써도 "읽고→1개 누르고→읽고"는 그대로다.**

## 7. 사용자가 정해야 할 것

### 주 블록 수 — 5블록(월 20칸)인가 4블록(월 16칸)인가
- **선택지:** **A. 5블록** (`wd_day`/`wd_eve_a`/`wd_eve_b`/`we_day`/`we_night`) — 취업이 먹는 시간이 격자에 보이고 연차 시스템이 성립하지만 20칸으로 커진다. **B. 4블록**(평일밤2+주말2, 직업은 격자 밖 상시 점유) — 가볍고 무스크롤이 확실하지만 취업/무직의 시간 차이가 안 보이고 연차가 성립하지 않는다. **C. 5블록 + 병합 렌더** — 재직 중에는 `wd_day` 행을 4칸이 아니라 회사명 가로 띠 1개로 병합, 무직·창업만 4칸으로 펼침.

### 240주 전체에 월 격자를 적용할 것인가, 후반은 접을 것인가
- **선택지:** **A. 전 구간 월 격자** — 60회 계획 화면. 후반까지 전략 깊이 유지, 대신 3년차 이후 피로. **B. 3년차부터 12주 계절 계획** — 계획 화면 60회 → 약 30회. 시간이 접히는 감각(기존 `_montage_week_cap()`의 4년차 처리와 같은 의도)과 맞지만 후반 전략 깊이가 준다. **C. 자산 밴드 연동** — 자산이 일정 수준을 넘으면 자동으로 계절 계획 전환(돈이 생기면 하루하루를 안 센다).

### 첫 프로토타입 범위를 8주로 할 것인가 12주로 할 것인가 (범위 확대 승인 필요)
- **선택지:** **A. 8주(v2 §10 현행)** — 계획 화면 2회만 보게 된다. **B. 12주(3개월)** — 계획 화면 3회. 1개월 계획의 결과가 2개월에 돌아오고 3개월에 그 회수를 보는 최소 사이클. **C. 8주 + 3개월차 요약 재생** — 8주 플레이 후 3개월차를 스크립트로 보여줌.

### 저조 밴드(정신·건강 16~25)에서 밤 블록을 물리적으로 잠글 것인가, 효과만 깎을 것인가
- **선택지:** **A. 잠금(제안)** — 계획 화면에 회복 칸이 강제로 박히고 밤 블록 3개 중 1개만 열린다. 체감이 강하지만 가혹하다. **B. 감쇠** — 배치는 되되 효과 -50% + 실패 확률. **C. 잠금 + 유예** — 잠그되 1~2개월은 밴드 미적용, 그리고 잠긴 칸에 '왜 이 칸이 잠겼는지'를 산문 한 줄로 보여준다.
- **추천:** **C.** B는 사용자 판정의 핵심('정신력 낮으면 쉬기만 계속 눌러')을 그대로 되살린다 — 효과가 깎여도 플레이어는 계속 밀어붙이고 결국 회복을 연타한다. **밴드는 반드시 칸을 물리적으로 잠가야** '내 계획 중 무엇을 버릴까'라는 결정이 생긴다. 유예 2개월과 산문 한 줄이 첫 데모 좌절 이탈을 막는 최소 비용이다.

### 폰 메시지 예산 주 3회가 맞는 강도인가
- **선택지:** **A. 주 3회(제안)** — 월 12회. 인물 2명을 격주로 챙기면 소진. **B. 주 5회** — 여유롭지만 4주 창 감쇠에 걸려 실효는 비슷. **C. 무제한 + 감쇠만** — 예산 없이 4주 롤링 창(1.0/0.6/0.3/0.1/0)에만 의존.
- **추천:** **A.** C는 '먼저 연락하기'를 다시 공짜 파밍으로 만든다 — 효과가 0이어도 플레이어는 누르고, 그 반복 자체가 사용자가 지적한 '플래시 게임 수준의 깊이'다. 주 3회는 **누구에게 쓸지 고르게 만드는** 최소 희소성이고, 여기에 4주 창 감쇠가 겹쳐 '같은 사람에게 매주 보내기'가 자동으로 나쁜 수가 된다. 사람 게이트에서 답답하다고 나오면 4회로 올린다.

### 도박의 '충동 진입'(이미 배치된 약속을 취소하고 즉시 들어가기)을 허용할 것인가
- **선택지:** **A. 허용(제안)** — 도박만이 주 중간 재배치가 가능하고, 취소된 것이 people 약속이면 신뢰 -15 + 제안 8주 정지. 중독을 플레이어가 자기 손으로 누르는 구조. **B. 금지** — 도박도 다른 T2와 같이 월초에만 배치. 안전하지만 '언제든'이 사라진다. **C. 허용하되 확인 2단계** — 취소 대상과 대가를 명시한 확인 모달.

### 빈 칸 0으로 한 달을 마감했을 때 정신 -8 + '이번 달 하루도 내 것이 아니었다' 장면을 넣을 것인가
