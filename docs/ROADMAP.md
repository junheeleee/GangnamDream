> 완료된 항목은 `[x]`, 진행 중은 `[~]`, 미착수는 `[ ]`.

---

## 핵심 설계 원칙

**이 게임의 코어 재미는 하나다:**
> "사회가 원하는 길(정석)을 따를 것인가, 나만의 길(비정석)을 갈 것인가"
> — 그 선택이 쌓여서 결과로 돌아오는 이야기.

**기능 추가 기준:**
> "이게 없으면 다른 시스템이 재미없어지는가?"
> YES → 추가. NO → 다음 단계로 미룬다.

**단계 진행 기준:**
> 각 단계 완료 후 테스터 세션에서 "재밌다"는 반응이 나와야 다음 단계로 간다.
> 안 나오면 방향 재검토. 기능 추가가 아니라 재미 원인 분석이 먼저.

## 1단계: 핵심 루프 완성 ← **현재 단계**

> 목표: 테스터가 "재밌다"는 말을 하게 만드는 최소 구조.
> 이 단계가 통과되지 않으면 2단계로 가지 않는다.

### 1-A. 행동 시스템 개편 (AP 버튼 → 이번 달 집중 선택)
- [ ] 월별 "이번 달 무엇에 집중할 것인가?" 메인 행동 선택 UI
- [ ] 메인 행동 카테고리 정의 (정석/비정석/공통 각 4-5개)
  - 정석: 📚 스펙/공부, 💼 취업 준비, 🤝 인맥 관리, 💰 저축/절약
  - 비정석: 💹 고위험 투자, 🎨 부업/사이드, ❤️ 연애/관계, 🌊 자유시간
  - 공통: 🏠 이사 준비, 🏥 건강 관리, 👨‍👩‍👧 가족 관계
- [ ] 선택한 행동에 따라 이번 달 이벤트 풀이 달라지는 구조
- [ ] 행동이 다음 달에 결과로 돌아오는 플래그 시스템
  - 예: "스펙_쌓기_중" 플래그 → 3달 후 취업 이벤트 확률 상승

### 1-B. 루트 시스템 (행동 누적 → 빌드 형성)
- [ ] 정석/비정석 행동 누적 카운터 (GameState에 추가)
- [ ] 누적 수치에 따라 달라지는 이벤트 풀 가중치
- [ ] 루트 힌트 UI: "현재 당신의 선택은 정석/비정석 방향으로 향하고 있습니다"
- [ ] 루트별 전용 이벤트 최소 각 10개 (총 20개 신규 이벤트)

### 1-C. 하우징 시스템 (거주지 = 생존 압박의 시각적 척도)
- [ ] 거주지 단계 정의 및 GameState에 `housing_tier` 추가
  - 0: 🏚 고시원 (월세 30만, 스트레스+3/월, 수면질 낮음)
  - 1: 🏠 반지하 원룸 (월세 45만, 스트레스+1/월, 여름 습기 이벤트)
  - 2: 🏢 원룸 (월세 65만, 중립)
  - 3: 🏬 투룸/빌라 (월세 90만, 사회성+1/월, 친구 초대 가능)
  - 4: 🏙 아파트 (월세 140만, 인맥 이벤트 접근, 부동산 정보)
  - 5: 🌆 강남 아파트 (월세 300만+, VIP 이벤트, 외모+상시)
- [ ] 이사 이벤트 (보증금 필요, 이사 직후 이벤트 발생)
- [ ] 거주지별 패시브 효과가 매달 적용되는 구조
- [ ] 거주지별 전용 이벤트 각 2-3개 (고시원의 처절함, 반지하 여름 등)
- [ ] 메인 UI에 현재 거주지 표시

### 1-D. 선택의 연결 (기억되는 선택)
- [ ] 이벤트에 `sets_flag` 지원: 선택지가 플래그를 남김
- [ ] 이벤트에 `requires_flag` 조건 활용 강화
- [ ] "N달 전 선택" 참조 이벤트 최소 5개 작성
  - 예: "지난달 야근 알바를 했더니 → 이번 달 단골 편의점 알바생이 말을 건다"

### 1-E. 핵심 캐릭터 3명
- [ ] GameState에 named_characters 딕셔너리 추가
- [ ] 라이벌 캐릭터: 비슷한 출발, 매달 근황 업데이트, FOMO 유발
- [ ] 연인 후보 캐릭터: 만남 → 연애 → 결혼/이별 서사
- [ ] 멘토/압박 캐릭터: 사회 압력의 목소리 (부모님 or 직장 선배)
- [ ] 캐릭터별 이벤트 각 5개 (총 15개)

## 2단계: 콘텐츠 깊이

> 전제: 1단계 테스터 통과 후 진행.
> 목표: 2회 이상 플레이해도 새로운 경험이 나오는 구조.

### 2-A. 인생 단계 1개 추가 — 취준생
- [ ] 취준생 페이즈 정의 (취업 전 단계)
- [ ] 취준생 전용 행동: 자소서 작성, 면접 준비, 스펙 쌓기
- [ ] 취업 성공/실패 분기 이벤트
- [ ] 취업 난이도를 지력/스펙/운이 결정하는 구조

### 2-B. 비정석 세부 루트 2개 완성
- [ ] 창업 루트: 아이디어 → 팀 구성 → 런칭 → 성공/실패
- [ ] 크리에이터 루트: 콘텐츠 제작 → 구독자 성장 → 광고 수익

### 2-C. 엔딩 강화

### 2-D. 이벤트 품질 패스
