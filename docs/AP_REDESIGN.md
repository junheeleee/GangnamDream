# AP 행동 전면 재설계 (A+B+C) — 설계 바이블

> 목표: "2 AP짜리 평면 메뉴가 240주 내내 안 바뀐다"는 반복성 문제를 뜯어,
> AP 루프 자체가 게임의 주제(Question A: 강남을 오르며 나/사람을 잃지 않을 수 있는가)를
> 매주 육화(incarnate)하도록 만든다. 비용이 크더라도 완벽성에 방점.

---

## 현재 시스템 (재설계 대상)

| 요소 | 위치 | 현황 |
|---|---|---|
| AP 값 | `GameState.action_points = 2` (1009 `refill_ap`) | 매주(턴) max로 리필 |
| 소비 | `GameState.spend_ap()` (1002) | 행동당 1 소비 |
| 메뉴 | `MainGame._render_essential_actions()` (4930) | **고정 평면 리스트**, 단순 플래그 게이트 |
| 행동 | `_ap_study/_ap_invest/_ap_free_time/...` (5586~) | 랜덤 비네트 + effects 적용 |
| 턴 진행 | "다음 주" 버튼 | 월간 사건은 풀스크린 VN |

**진단**: 메뉴가 5년 내내 동일. 행동에 축(axis)·누적(accumulation)·진화(evolution)가 없다.

---

## 세 기둥

### A — AP = '돈 vs 사람' 배분 통화 (주제를 루프에 심기) · **영혼**
매주 2 AP를 **돈축**(구직·투자·사이드잡·도박·스펙쌓기)과 **사람·자기축**(휴식·관계·자기성찰·건강)에
나눠 쓴다. 둘 다 돈축에 태운 주간이 누적되면 tint−·정신−·관계 drift+가 서서히 쌓이고,
한 주에 사람축을 한 번이라도 쓰면 그 압력이 풀린다.
→ **매주가 Question A의 축소판**. 240번의 작은 선택이 엔딩 색(tint)·관계·이혼 여부로 누적.

- 균형 플레이어(사람축 섞음)는 순 tint ≈ 0
- 순수 그라인더는 5년간 누적 tint ≈ −20~−30 → "평범한 주들을 어떻게 보냈나"가 엔딩 색에 드러남
- moral_tint 예산(±100) 안에서 완만하게: **연속 그라인드 4주(=한 달)마다 tint−1 + 정신−1**, 사람축 주간이 streak 리셋

### B — 루틴 + 몽타주 압축 (240주 클릭 피로 제거) · **페이싱**
플레이어가 주간 **루틴**(기본 AP 배분)을 설정. 대기 이벤트가 없는 저스테이크 주간은
루틴대로 몽타주로 훅 지나가고, **결정 주간**(이벤트·관계·기회·임계값)에서만 멈춘다.
→ 실제 조작은 ~40-50개 결정 순간. 나머지는 "시간이 흐르는" 연출.
루틴 선택(갈아넣기 vs 균형) 자체가 A의 누적에 장기 영향.

- **가장 위험**(턴 루프 수술). A/C가 안정된 뒤 마지막에.
- 몽타주가 A의 축/누적을 정확히 반영해야 함(루틴=그라인드면 몽타주 중에도 tint drip).
- 안전장치: `_next_arc_id()`·랜덤 이벤트·마일스톤·임계값(파산 근접/건강 위기) 도달 시 몽타주 강제 중단.

### C — Act별 메뉴 진화 + 상태형 액션 (가시적 변주) · **콘텐츠**
같은 화면이 5년 내내 안 똑같도록 Act(Y1~Y5)마다 메뉴가 물리적으로 바뀐다:

| Act | 테마 | 메뉴 |
|---|---|---|
| Y1 (t1~48) | 생존 | 구직·알바·절약·자기계발 (천장 낮음, 피로 큼) |
| Y2 (t49~96) | 확장 | +투자·네트워킹·사이드잡 해금 |
| Y3 (t97~144) | 무게 | +도박장·정보매수·지하 해금 — 효율 액션에 **tint 비용** 부착 |
| Y4 (t145~192) | 균열 | 관계 유지가 AP를 먹는 액션으로 승격 (배우자/부모/친구 vs 딜) |
| Y5 (t193~240) | 엔드게임 | 소수 고위험 액션만, AP 하나가 무겁게 |

+ 반복 액션에 상태(포트폴리오·중독 미터·평판 트랙·인물별 관계 미터)를 둬 같은 버튼도 누를 때마다 다른 결과.

## 재미 3원칙 (2026-07-06 유저 pushback "너말대로 하면 재밌어져?" 반영)

구조(A+B+C)는 *의미/페이싱/변주*를 겨냥하지만, "재미" 자체는 아래 셋에서 나온다.
초안의 A는 '숨은 페널티'였는데, 그건 재미가 아니라 보이지 않는 불안 → 다음으로 교체:

1. **보이는 tradeoff** — 돈 vs 사람이 숨은 tint 드립이 아니라 **내가 지금 포기하는 걸 눈으로 보는 유혹**.
   AP를 한 축에 몰면 "이번 주 못 하는 것"(예: 다은과의 저녁)이 흐릿하게 보여야 한다. 둘 다 갖고 싶은데 하나만 되는 게 재미.
2. **상태형 진행** — 누르면 *내가 신경 쓰는 미터가 눈에 띄게 움직인다*. 두 개의 긴장 바:
   **강남까지(종잣돈)** vs **관계(다은/지연)**. 그라인드는 강남 바를 채우고 관계 바를 비운다 — Question A를 두 바로 시각화.
3. **압축(B)** — 반복 자체를 없앤다. 이 장르(드라마/VN)에서 재미 = 몰입+주체감+**페이싱**이라 B가 큰 레버.
   단, 몽타주가 의미 있으려면 A의 축이 먼저 있어야 함("갈아넣은 3주 = 다은에게 못 간 3주").

**장르 현실**: 아케이드 중독이 아니라 드라마. 목표는 "주 사이가 busywork로 안 느껴지고, 무언가로 누적되는 느낌".

## 불변 원칙
1. 숨은 도덕 수치(tint/route)는 계속 UI 텍스트로 노출하지 않는다 — 색·질감·서술로만 체감.
2. 밸런스 밴드(무직 실패 100% / 직장 0% / 베팅 30억 8~25%)는 각 페이즈 후 유지.
3. 새 GameState var는 serialize + audit SERIALIZE_EXEMPT 등록.
4. Claude=내용/밸런스, Codex=외형. UI 표면 폴리싱은 Codex 몫으로 남긴다(축 인디케이터는 기능 최소선만).
