# 강남드림 중국어 간체·번체 현지화 준비 계약

Updated: 2026-08-10

Status: `zh-CN`과 `zh-TW`는 숨김 준비 언어다. 한국어 원문에서 각각 번역하며,
중국어 본문·UI 번역은 아직 생성하지 않았다. 두 언어 모두 프로젝트 소유 지역
글꼴과 같은 리비전의 원어민 문맥 판정이 없어 Steam 지원 언어로 공개할 수 없다.

## 공통 원칙

- 한국어 사건·선택·동적 표면을 유일한 번역 원문으로 쓴다. 영어·일본어를 중역
  원문으로 사용하지 않는다.
- `zh-CN`과 `zh-TW`는 서로 다른 번역이다. 한쪽 결과를 OpenCC나 다른 문자
  변환기로 바꾸어 다른 쪽 본문을 만들지 않는다.
- 실제 24주 준비 범위는 정적 UI 2,615키와 73사건·465본문 문구·동적 592회/
  585고유 키·시장 자산명 4개·엔딩 0개다. 동적 범위에는 첫 계획에서 반드시
  보이는 3장 튜토리얼의 제목·본문 6쌍이 포함된다. 사건 본문 465개, 동적 고유 키
  585개, 자산명 4개를 합친 번역 소스는 총 1,054개다. 현재 두 언어의 커버리지는
  모두 `UI 0/2,615 · 사건 0/73 · 본문 0/465 · 동적 0/585 · 자산 0/4`이며 이 숫자를
  준비 완료나 출시 가능으로 부르지 않는다. 본문만 채운 뒤 UI를 영어 폴백으로
  남기는 것도 중국어 데모가 아니다.
- 원문의 사건 ID, 선택 순서·개수, 조건, 효과, 플래그, 수치, 장소, 초상, CG,
  오디오와 후속 라우팅은 번역하지 않는다. 오버레이는 번역 가능한 텍스트만
  소유한다.
- 첫 달 `중심/함께 약속`은 좋은 선택/나쁜 선택이나 주·부 퀘스트 등급이 아니라
  플레이어가 고른 순서다. 두 지역 모두 이를 성공 가능성·도덕 등급으로
  번역하지 않는다. 현수 첫 만남과 4주차 위기는 도착 전 제목·이름·보낸 사람을
  밝히지 않고, 중심 약속 회수 네 문단은 실제 물리 흔적만 옮긴다.
- 문장을 짧게 만드는 과정에서 장면을 요약하지 않는다. 인물의 지식 범위,
  관계 거리, 말의 함축, 선택 뒤 정적과 여운을 보존한다. 원문이 판단하지 않은
  선택을 선악 답안으로 해설하지 않는다.
- `{name}`, `{money}`, `{housing}`, `{p}`, `%s`, `%d`, `\n`, BBCode 태그와
  문단 경계를 보존한다. 이름·금액·날짜·횟수의 의미를 바꾸지 않는다.
- 자동 검사는 원화 금액뿐 아니라 부호, 날짜·시각·기간·횟수·차수·번호표와
  한국어 고유어 수사를 의미값으로 대조한다. 다만 중국어의 자연스러운 단수
  분류사와 관용적 수사를 모두 기계 판정할 수 있다고 주장하지 않는다. 자동
  검사가 통과한 뒤에도 지역별 원어민이 원문과 화면에서 모든 수치를 대조한다.
- 달력의 `6월`과 기간의 `여섯 달`, `일곱 번째 달`과 `일곱 번`, 장·채·대·잔·
  줄·켤레 같은 실제 데모 분류사를 서로 바꾸지 않는다. `월 220`, `즉시 200`,
  `보증금 천에 월 오십오`는 문맥상 각각 만원 단위 원화다. 중국어에서 단위를
  명시하되 경제 가치를 환산하거나 생략하지 않는다.

공식 용례는 준비형의 근거이지 문장 자연스러움의 자동 승인서가 아니다. 첫
등장의 설명량, 이후 반복 표기와 실제 대사 온도는 각 지역 원어민이 판정한다.

- 통화명은 항상 `韩元`이다. `50만원=50万韩元`, `1억원=1亿韩元`,

## 데모 시장명 보류형

24주 시장 화면의 네 이름은 양 지역에서 아래 exact 준비형을 쓴다. 세 가상
기업에는 승인된 한자 상호가 없으므로 발음이 비슷한 글자를 임의로 만들지 않는다.

## 공통 금지형

- 영어·일본어 본문을 원문으로 삼거나 `zh-CN↔zh-TW`를 자동 변환한 결과
- 중국어 값의 한글 음절·일본어 히라가나·가타카나, 또는 미번역 영어 문장
- 공식 근거 없는 인명 한자, 중국식으로 바꾼 가족·직장 관계와 선행 애칭
- 원화 금액의 `¥`, `￥`, `日元`, `円`, `人民币`, `人民幣`, `新台币`,
  `新臺幣`, 또는 `元` 단독 표기
- `zh-CN`의 `韓元/萬/億`, `zh-TW`의 `韩元/万/亿` 같은 지역 문자 혼용
- 자동 문자 게이트는 OpenCC 1.3.1의 고정 문자 사전 전체에서 자기 자신으로도
  매핑되거나 양쪽에 겹치는 문맥 의존 글자를 제외한 금지 집합을 사용한다.
  `zh-CN`은 번체 전용 4,093자, `zh-TW`는 간체 전용 3,804자를 검사하며 이
  데이터는 분류에만 쓰고 어느 번역도 변환·출력하지 않는다. `后·干·台·里·系`
  같은 공유 글자의 실제 쓰임은 잠긴 구문 규칙과 지역 원어민 전수 대조가 맡는다.
  CJK 호환 한자와 한자 뒤의 자형 선택 코드는 양 지역 모두 비정규 표기로 거부하며
  자동 정규화하지 않는다.
- `빌라`를 `别墅/別墅`로 바꾸거나, `全租（jeonse）`를 일반 월세·매매처럼
  쓰거나, `考试院/考試院（goshiwon）`을 학원처럼 설명하는 문화 치환
- 원문 문단·선택을 요약하거나 숨은 도덕 점수·미래 결과를 친절하게 해설하는 문장
- 운영체제 글꼴이나 일본어 폰트가 우연히 표시한 공유 한자를 중국어 출시
  글꼴 증거로 사용하는 것

## 사람 판정

자동 엄격 검사는 정적 UI 2,615/2,615, 사건 73/73, 본문 465/465, 동적 키
585/585, 자산명 4/4(총 번역 소스 1,054/1,054), 구조, 고정 문자 데이터와 잠긴
구문, 자리표시자, 원화,
금지형과 프로젝트 소유 글꼴 경로를 확인한다. 공유 글자의 문맥 적합성을 포함한
다음 항목은 자동으로 승인할 수 없다.

- `zh-CN`: 중국 본토 원어민이 한국어 정본과 같은 `demo_rc`의 정상 속도 24주,
  합법 도달 73사건과 모든 선택·결과를 직접 대조한다.
- `zh-TW`: 대만 원어민이 같은 조건을 별도로 판정한다. 간체 검수 결과나 변환
  보고서로 대신하지 않는다.
- 두 사람 판정은 해당 지역의 `zh_translation_audit.py --strict` 전체 통과를
  선행 조건으로 삼는다. 영어 폴백 UI나 일본어 우선 공유 한자를 사람이 대신
  승인할 수 없다.
- 두 판정 모두 인물 목소리, 관계 거리, 함축과 여운, 원화 금액의 체감, 한국
  문화 설명량, 선택 인과, 지역 자형, 줄바꿈과 실제 화면 가독성을 확인한다.

현재 저장소에는 준비 언어가 영어로 직접 들어갈 수 있는 런타임 분기 14곳과,
중국어를 CJK 글자 속도로 읽지 않는 AUTO 경로가 남아 있다. 기본 준비 모드는
이를 숨기지 않고 수치로 보고하며 지역별 `--strict`는 둘 다 실패시킨다. 이는
중국어 본문을 채우기 전에 별도 소형 런타임 오더로 고칠 출시 차단선이지,
영어 폴백을 중국어 번역으로 인정하는 예외가 아니다.

사람 GO는 각각 `claim:zh-CN-demo`, `claim:zh-TW-demo`에 적용되며 둘 다 통합
4개국어 데모 출시도 차단한다. 번역 중에는 한국어·영어 개발 후보를 계속 검증할
수 있지만 공개 데모는 일본어·간체·번체 판정까지 모두 통과해야 한다. 데모 GO는
1,603사건·35엔딩의 중국어 정식판 출시를 승인하지 않는다.
