# Steam Quality Benchmarks

Updated: 2026-07-10

## Purpose

Steam's global top-seller list changes continuously. Gangnam Dream should not imitate whichever genre happens to be selling today. It should match the execution discipline visible in successful games and the best adjacent narrative titles.

The benchmark is not asset quantity or studio budget. It is whether the player can identify the promise, understand the next input, feel the result, remember the cast, and describe why another run matters.

## Live Top-100 Calibration

Steam's Top Sellers list is a commercial signal, not a review score or a fixed quality canon. Valve states that the real-time chart rolls up the previous 24 hours of revenue, gives extra weight to the most recent three hours, and includes base-game, DLC, and in-game spending. Source: https://partner.steamgames.com/doc/store/top_sellers

Therefore Gangnam Dream does not chase the current Top 100's genres. It uses the list to audit commercial execution:

1. A store thumbnail communicates the product before the title is read.
2. The first session reaches the product's signature interaction without input fatigue.
3. Every repeated action has readable anticipation, response, and a reason to repeat.
4. Controller, text size, audio continuity, save trust, and language parity create no refund excuse.
5. The game has an ownable character, object, sound, or transformation that survives outside the store page.

The live chart is refreshed before store/capsule reviews. Surface design remains anchored to adjacent narrative references below, because revenue rank alone cannot tell us how a text-heavy single-player game should play.

## Screen-Level Bar

### Title / Store Capsule

- **Target:** Slay the Princess clarity plus Persona-level identity discipline.
- One crop must retain a face, conflict, title, and tonal promise.
- Gangnam Dream currently passes premise readability but fails final-art uniqueness. The new code composition is a layout prototype, not final key art.

### Weekly AP Loop

- **Target:** Citizen Sleeper decision clarity plus Balatro anticipation/payoff.
- Before confirming, the player sees cost, uncertainty, and desired outcome.
- On confirm, motion and sound communicate commitment.
- Afterward, the result changes this week and promises a later echo.

### Story / Relationships

- **Target:** Slay the Princess transformation ownership plus Hades character recall.
- Each flagship character owns gesture, prop, sound, and scene grammar.
- Repeated meetings must react to remembered behavior, not only affection totals.

### Minigames

- **Target:** A standalone loop that remains readable and satisfying after ten repetitions.
- Rules, state, input, anticipation, outcome, and exit are visually separated.
- Main-game money, risk, addiction, relationships, and callbacks must react afterward.

### Endings

- **Target:** A final image and sound that can be named without reading the ending ID.
- Every ending resolves money, humanity, father, and strongest relationship.
- Tier changes may alter production scope, never truthfulness or emotional closure.

## Release Comparison Rule

For every major surface, capture Gangnam Dream beside at least two reference screenshots at the same physical display size. Compare:

1. Time to understand the next input.
2. Number of simultaneous visual priorities.
3. Smallest required text.
4. Character recognition at thumbnail scale.
5. Feedback layers after one confirm press.
6. What remains in memory after the screen is hidden.

The answer may be quieter than the reference. It may not be less intentional.
