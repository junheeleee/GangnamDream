## 중복군 판정

<!-- reviewed-pair: stable_success|orthodox_pinnacle -->
### 병합 제안 1: `stable_success` + `orthodox_pinnacle`

둘 다 38세·10억 이상·정석 생활의 결산이고 전용 CG가 없다. 현재 차이는 `orthodox_pinnacle`이 정석 우세 15점을 요구하며 조직 순응의 대가를 묻는다는 점이다. 외부 플레이테스트에서 두 엔딩을 받은 사람이 차이를 설명하지 못하면, `stable_success`를 기본 본문으로 두고 정석 우세를 DIK 변주로 흡수하는 병합을 제안한다. **이번 오더에서는 실행하지 않는다.**

<!-- reviewed-pair: investment_master|unorthodox_legend -->
### 유지 제안: `investment_master` / `unorthodox_legend`

자산 5억 구간은 같지만 전자는 반복 가능한 시장 해석 능력, 후자는 정석 밖의 생존 철학이다. 한쪽은 기술, 다른 쪽은 경로이므로 본문은 구분된다. 다만 둘 다 범용 무드 카드라 향후 결산 CG 또는 전용 카드 심벌이 필요하다.

<!-- reviewed-pair: empty_house|lonely_rich -->
### 유지 확정: `empty_house` / `lonely_rich`

둘 다 혼자 남은 강남이지만 `empty_house`는 아버지의 죽음, `lonely_rich`는 관계를 돌보지 않은 선택이 원인이다. 전용 CG도 빈 소파와 네 자리 식탁으로 분리돼 있다.

<!-- reviewed-pair: burnout|career_burnout -->
### 유지 확정: `burnout` / `career_burnout`

이름은 겹치지만 하나는 건강 0의 즉시 실패, 다른 하나는 5년을 버틴 저자산 직장인 결산이다. 명칭 혼동은 있을 수 있으나 감정과 라우팅은 다르다.

<!-- reviewed-pair: bankruptcy|debt_spiral -->
### 유지 확정: `bankruptcy` / `debt_spiral`

-1억과 -2억의 다른 단계이며, 계산을 멈춘 방과 계산기를 뒤집은 방으로 CG도 분리됐다.

2. `second_love` — **본문 수정.** 10억대 현실로: 강남 아파트 베란다 → 강 건너에서 강남 불빛이 보이는 집. 30억 정본 보호.
3. `startup_exit` — **라우팅 현행 유지(30억 분기 우선).** 30억은 이 게임의 단일 승리 정의 — 창업으로 30억을 넘겼으면 "창업으로 이룬 강남드림"이 맞다. 대신 `gangnam_dream`에 `startup_exit`(플래그) 경로 dik 변주 1종 추가(엑싯 서명으로 도달한 강남 — EN 패리티 포함). startup_exit 엔딩은 30억 미만의 엑싯 전용으로 존치.
4. `healthy_retirement`/`early_retirement` — **본문 수정.** 38세 시점+미래 전망 프레임으로("이 속도면 쉰 전에 일을 놓아도 된다" 결) — 55세·50세 현재형 단정 제거.
5. `orthodox_pinnacle` — **본문 수정.** 실제 조건(10억)에 숫자 정렬.
6. 12 무드 카드 — **병합 기각, 전용 결산 카드 심벌 승인.** 우선순위=도달 빈도순: ordinary_life → burnout → mental_break → stable_success 먼저, 나머지는 P1-E 재개 흐름에 편입.
- 병합 제안 1(stable_success+orthodox_pinnacle) — **조건부 보류 확정**: 외부 플레이테스트에서 두 엔딩 수령자가 차이를 설명 못 하면 병합, 지금은 #5 수정으로 차별 강화.
