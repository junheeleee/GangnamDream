## 2026-08-04 (Codex — 월간 계획 UX·전환 입력·고지/표식 수리)

- 챕터 직후 V2 튜토리얼이 이전 Enter/South 홀드·키 반복·마우스 더블클릭을
  받아 연속 통과하던 경로를 release gate로 닫았다. 각 장은 새 입력을 요구하고,
  `tutorial_shown`은 마지막 장 완료 뒤에만 저장되며 취소·부모 종료 시 다시 열린다.
  Q/E와 패드 양쪽 어깨도 튜토리얼이 먼저 소비해 뒤 계획판 탭을 바꾸지 않는다.
  네 입력은 각각 독립된 프레임 뒤 탭·포커스 불변을 검사한다. 계획판 전체
  페이드는 제거해 아래 MainGame이 첫 프레임에 비치지 않는다.
- 월간 계획판을 `선택→배치→최종 확인`의 세 단계로 다시 읽히게 했다. 제안
  종류별 아이콘·색, 선택/완료 수, 상시 루틴 요약·변경 버튼을 넣고 배경 재질을
  복원했다. 제안 선택은 첫 합법 빈 주로 포커스를 옮기며 배치 뒤 다음 제안 또는
  확인으로 이어진다. East는 선택 대기 취소, West는 실제 포커스 주차만 삭제한다.
  추천 루틴 자동 적용과 변경 방법을 명시하고, 현황·사람·루틴·검토·기록의
  읽기 카드를 패드 경로로 연결했다. 미완성 계획은 비활성 확인 버튼을 건너뛰고
  탭으로 순환하며 비일정 탭에 주차 삭제 안내를 띄우지 않는다. 취업 상태에서는
  본업 생계를 주 루틴으로 고정하고 보조 생계 중복을 설명과 함께 비활성화한다.
  최종 검토는 안전한 일정 수정에 먼저 포커스를 두고 350ms+입력 해제 뒤 새
  확인만 받으며 OS 더블클릭 두 번째 edge도 버린다. 960×600에서도 화면 밖
  내용을 포커스로 스크롤한다.
- 제3자 고지 스크롤 안에 좌우 16px·위 10px 여백을 두고 긴 라이선스 본문을
  14px 이상으로 올렸다. V2 테스트 표식은 StoryMode 좌측 전용 슬롯으로 옮겨
  대화 기록·설정·HUD와 분리하고, 정식 빌드 정보가 있는 고지와 조작부가 빽빽한
  계획판에서는 숨긴다. StoryMode HUD는 좁은 폭 밖으로 그리지 않는다.
- Godot macOS ZIP의 한글 앱·실행 파일·PCK 경로가 압축 해제 뒤 서명 원장과
  다른 유니코드 형태가 되던 패키징 결함을 닫았다. Finder 표시명 ‘강남드림’은
  유지하되 내부 세 이름을 ASCII로 정규화하고 ad-hoc 테스트 서명을 다시 만든
  뒤, ZIP을 새 임시 폴더에 풀어 `codesign --deep --strict`와 실행 비트를
  재검증한다. 정식·데모·V2 macOS 빌드가 같은 마감 함수를 쓴다.
- `CoreLoopV2Check`, `TutorialInputCheck`, 첫 진입·플레이테스트 flavor·첫 30초·
  입력 행렬을 통과했다. KO 960×600과 EN 1280×800 계획판, EN 960×600 고지,
  KO 960×600 대화 기록 실제 렌더를 확인했고, KO PlayStation 배열 원시 패드
  이벤트는 키보드·마우스 구조 없이, EN 키보드는 패드·마우스 구조 없이
  각각 여섯 달 24주를 `offer_intents=22`, `week_commits=22`와
  `gamepad_events=1346` / `keyboard_events=1352`로 완주했다. 자동 결과는 실물
  Steam Deck·패드 손맛과 정상 속도 재미를 대신하지 않는다. 두 차례 독립
  읽기 전용 검토에서 최종 제품·검사 P0/P1은 0건이었고, 강화한 독립 입력
  회귀까지 포함한 전체 감사가 `✅ 감사 통과`로 끝났다.

## 2026-08-04 (Codex — V2 타이틀→24주 계측형 GUI raw-event 자동 완주)

- 언어를 미리 지정한 타이틀에서 오프닝·프롤로그·Chapter 1·실제 계획판과 상태를
  바꾸지 않는 3장 튜토리얼을 지나, 네 약속과 두 루틴을 정하는 계획을 여섯 번
  화면에서 확정해 1~24주를 완주했다. 첫 청구서 opening→decision→ledger와
  현수 시험 아침 뒤 turn 25 자동 저장은 정확히 한 번 생성됐고, 완료 CTA는
  저장 바이트를 바꾸지 않은 채 타이틀과 V2 진입점을 다시 열었다.
- KO 경로는 PlayStation 배열 South joypad event만, EN 경로는 key event만
  자동화에서 주입했다.
  일반 버튼의 South 확인 매핑을 제품 InputMap에 복구하고 계획판의 중복 수동
  발화를 제거했다. 하네스가 주입한 마우스·타 장치·의미 action·미상 입력은
  0이며 일정·선택·GameState 직접 조립이나 `pressed.emit()`을 완주 증거로
  쓰지 않았다.
- 로컬 실행기와 CI에 등록한 같은 실행기가 설정·화면·메타·자동 저장·열 슬롯
  14개 경로를 매번 새 절대 임시 루트에 격리한다. 자동 PASS는 제품 화면
  도달성·결과·원장·저장을
  증명하지만 D-pad·방향키 포커스 연결은 별도 자동 회귀, Steam Deck·실물 패드
  손맛과 정상 속도 몰입·재미·연속 A/V는 사람 게이트로 남긴다.
