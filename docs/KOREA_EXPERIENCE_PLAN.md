## 미니게임 설계 브리프 #1 — 인형뽑기 (Codex용)

### 컨셉
지하철 출구·번화가 어디에나 있는 인형뽑기. "두 번이면 될 것 같은데"의 함정.
외국인에게 즉시 읽히고, 조작이 곧 재미. "설계됐는데 될 것 같은" 약오름이 핵심 감정.

### 루프
1. 진입: 한 판 1,000원. 보유 현금에서 차감.
2. 조작: 집게 가로 이동(←→ 정지) → 세로 이동(정지) → 하강 → 집기 → 배출구로 이동.
3. 결과: 성공 시 인형 획득(연출 + SFX), 실패 시 집게 힘 약해 떨어뜨림.
4. 반복/포기 선택. 누적 지출 표시로 "오기" 압박 가시화.

### 밸런스 (Claude 제안 — Codex 튜닝 협의)
- 기본 성공률 ~15~25% (실제 인형뽑기처럼 "거의 될 뻔"). 집게 힘 약화 연출로 "설계된 느낌".
- 럭(luck) 스탯이 성공률에 소폭 보정(+, 최대 +10%p). → 기존 스탯과 연동.
- 1회 1,000원. 천장(예: 10회=10,000원) 도달 시 동정 획득(보장) — 호구방지 + 현실감.
- GameState 훅: `money` 차감, 성공 시 플래그/콜렉션(`plushie_count`++), 과지출 시 가벼운 mental- (오기의 대가). gambling_tendency와는 **분리**(이건 문화 체험이지 도박 아님 — 톤 주의).

### 연출/문화 플레이버 (EN 포함)
- 성공: "한 번에 뽑았다!" 주변의 짧은 부러움. EN: "Got it on the first try!"
- 천장 동정: 점원이 문 열고 꺼내줌 — "이것도 한국 인심" 식의 따뜻한 한 줄.
- 과지출: "천 원짜리 인형이 만 원짜리가 됐다" 자조 — 강남 꿈과 라임.

### 트리거/배치
- 기존 텍스트 `kx_claw_machine`를 미니게임 진입점으로 승격하거나, 자유시간/번화가에서 호출.
- 미구현 동안은 텍스트 `kx_claw_machine`가 폴백.
