# 강남드림

**인터랙티브 드라마 / 인생 시뮬레이터 — Godot 4.6 (GDScript)**

당신은 김민준, 33세, 백수, 통장 잔액 ₩500,000.  
목표: 5년(60턴) 안에 자산 30억을 모아 강남에 입성.

---

## 이 게임은 어떤 게임인가?

매달의 선택 하나하나가 결과로 돌아오는 한국 사회 리얼리티 이야기.  
매 턴 커리어·투자·인간관계·부업·리스크 중 하나의 이벤트를 선택한다.  
선택들이 쌓여 캐릭터의 정체성이 만들어지고, 결국 25가지 엔딩 중 하나로 귀결된다.

대시보드 전략 레이어가 있는 비주얼 노벨처럼 플레이된다.

---

## 핵심 시스템

| 시스템 | 설명 |
|---|---|
| **월별 이벤트 루프** | 턴당 이벤트 1개, 가중치 풀(395개 이벤트)에서 추첨 |
| **성향 시스템** | 직장 / 투자 / 창업 — 행동이 정체성으로 누적, 시작 특성 없음 |
| **루트 시스템** | 정석 vs 비정석 선택이 레이트 게임 이벤트와 엔딩을 가름 |
| **투자 시장** | 변동성·공포탐욕 지수·버블·폭락·레버리지를 가진 자산 18종 |
| **아크 시스템** | 5개 스토리 아크 (임상철·한지연·재혁·다은·아버지) + 분기 결말 |
| **스토리 모드** | 핵심 장면을 초상화 + 배경이 있는 비주얼 노벨 씬으로 연출 |
| **주거 진행** | 고시원 → 원룸 → 빌라 전세 → 아파트 전세 (비용 + 패시브) |
| **런 테마** | 매 런마다 무작위 카테고리 부스트, 또는 프리셋 테마 선택 |
| **메타 진행** | 수집 칭호 39개, 런 히스토리, 런별 통계 |
| **세이브 시스템** | 자동저장 + 수동 슬롯 3개 |

## 실행 방법

1. Godot 4.6 이상 설치.
2. `project.godot` 열기.
3. **F5** 실행.

빌드 스크립트: `./tools/build.sh linux` / `./tools/build.sh windows`
