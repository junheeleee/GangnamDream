# 강남드림

**인터랙티브 드라마 / 인생 시뮬레이터 — Godot 4.6 (GDScript)**

당신은 김민준, 33세, 백수, 통장 잔액 50만원.
목표: 5년 안에 자산 30억을 모아 강남에 입성.
그 밑에 깔린 진짜 질문: *그 사다리를 오르면서, 같은 사람이 되지 않을 수 있을까?*

---

## 이 게임은 어떤 게임인가?

한 주 단위로 플레이하는 한국 사회 리얼리즘 드라마 (240주, 33세→38세).
매주 제한된 시간을 돈에 쓸지 사람에 쓸지 고르고 — 게임은 그걸 조용히 기억한다.
선택이 정체성이 되고, 정체성이 **34개 엔딩** 중 하나가 된다.

비주얼노벨 + 라이프심 대시보드의 결합이며, 화면 자체가 등장인물이다:
선택이 어두워질수록 세계의 색이 실제로 빠져나간다
(숨은 **moral tint** 시스템 — 숫자로는 절대 안 보여주고, 느끼게만 한다).

## 핵심 시스템

| 시스템 | 설명 |
|---|---|
| **주간 루프 + 몽타주** | 1턴=1주. 무사건 주는 "루틴대로 시간을 보낸다"로 접어 흘려보내고, 무언가 — 누군가 — 가 필요해지는 순간 반드시 멈춘다 |
| **돈 vs 사람 축** | 모든 행동이 한쪽에 시간을 쓴다. 사람 없이 한 달을 갈아넣으면 조용히 마모된다 |
| **Moral tint** | 숨은 −100..+100 축을 셰이더로 칠한다. 선을 넘으면 색이 빠지고, 어떤 흉터는 끝까지 안 지워진다 |
| **발견 레이어** | 진실을 알고 나면 같은 장면이 다르게 읽힌다 (`description_if_known`) |
| **스토리 아크** | 상철(아버지를 무너뜨린 남자), 다은과 지연(반전된 거울인 두 사랑), 재혁, 현수, 아버지 |
| **로맨스와 결혼** | 결혼은 잃을 수 있다: 다은을 배신하면 이혼당하고, 작게 살면 지연이 떠난다 |
| **투자 시장** | 가상화된 자산 18종, 장세 사이클, 공포/탐욕, 레버리지, 폭락 |
| **카지노 스위트** | 바카라·블랙잭·슬롯·룰렛·다이사이·빅휠·홀덤·경마 — 중독/회복 서사 포함 |
| **엔딩** | 34종, 배우자 인지 라우팅, NG+ 지식 변주, 엔딩 도감 |

## 콘텐츠

이벤트 ~1,200개 (KR 소스 + EN 완전 오버레이) · 엔딩 34 · 직업 15 ·
자산 18 · 아이템 28 · 주요 인물 아크 5 · Steam 데모(첫 6개월 분량).

## 실행 방법

1. Godot 4.6+ 설치.
2. `project.godot` 열고 **F5**.

빌드: `./tools/build.sh linux` / `./tools/build.sh windows`
정적 감사(커밋 전 필수): `./tools/audit.sh`
