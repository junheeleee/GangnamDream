Runtime crops each square into a 76x48 covered thumbnail. Sources are intentionally dark, object-focused, person-free, and free of meaningful text so they survive Steam Deck scale and Moral Tint grading.

Do not map this art by broad stat category. Every key belongs to one action fantasy; never substitute `money` merely because an action affects money. New submenu actions keep distinct SVG fallbacks until they receive dedicated illustrations.
