# Gangnam Dream UI Icons

First-pass unified line icons for production UI.

- Canvas: 24x24 SVG.
- Stroke: 1.8px, rounded caps/joins.
- Default stroke color: `#e8eaf0`; tint through theme/modulate where needed.
- Use these icons in buttons, HUD, tabs, and minigame panels instead of emoji glyphs.
- Event prose and logs may keep emoji temporarily, but reusable UI components should use this folder.
